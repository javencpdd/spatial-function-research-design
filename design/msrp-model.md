# MSRP 的候选域、可行性与最优性

本轮设计适用于 D01、D02 已定义的单个通道义务修订和一个选定 RobotProfile，采用有限动作目录与离散时序。数学模型、伪代码与纸面案例共同界定规划结论的适用范围。

## 1. 规划要取得的证据

S4 冻结义务、要求谓词、证据模板及空间和时间范围。S5 根据当前已知证据、动作产证条件和执行约束，判断是否存在能够满足指定采证要求的完整路线。每次规划记录以下输入。

| 输入 | 精确内容 |
| --- | --- |
| 义务及采证目标 | Obligation/Requirement/Template Revision，待测属性、所有必需组与槽、见证份数、独立性及共享额度、目标域和时效要求。 |
| 采证范围 | 初次判断采用 D02 的全通道空间与时间域 $D$。有局部缺陷候选时，S4 可以明确授权在 $B\subseteq D$ 复测共同反例。该范围、目的和可支持的结论随规划输入保存。 |
| 精确快照 | 地图、图、分区、变换、关联、S3 状态、S4 义务、S6 能力及 S8 策略/标定修订，当前知识切点、管理许可和执行范围。 |
| 候选生成条件 | 有限位置、动作及时间参数，起点、允许终点、起始时点、规划截止、预算、时间步长和生成规则，记录未解析或未覆盖输入。 |
| 证据与产证依据 | 已有证据的来源和有效期，各动作预计形成的见证及覆盖、误差、采样时间、共同原因和独立性依据。外部测量须有可读取的已有结果或已固定的供给安排。 |

本轮采用结果未知的采证规划。路线的采证资格检查能否取得所需范围、质量和独立性的测量，不提前填入净宽读数。达到采证条件的证据可能落在阈值一侧，也可能跨阈值或存在冲突。S4 根据实际内容给出 PASS、FAIL 或 NOT_DETERMINED。若请求的是“保证取得确定业务结论”，还需有覆盖所有允许测量结果的论证。本轮的采证可行性不能单独支持这项保证。

全域测量沿用 D02 的两个独立、各自完整覆盖的见证要求。授权的局部复测要求两个独立见证测量同一个 $B$。实际反例只有在重合子域上获得合格反证后才能用于 FAIL。如果测量转而支持局部达标，S4 继续处理全通道尚缺的范围。S5 保留路线产生的全部合格证据及冲突，验收时按 S4 的提交策略消费。

## 2. 有限候选域与完整性

固定有限位置集合 $V$、有向路径段和有限参数化动作目录 $A$。时间域为 $t_0,t_0+\Delta,\ldots,t_0+H\Delta$，其中 $\Delta>0$，$H$ 为有限整数。每个移动、等待、采样动作至少占一个时间步，执行时刻只取网格点。允许终点集合 $V_{end}$ 显式声明。结束操作仅在允许终点执行一次。已位于允许终点时可以考虑零动作候选。

定义 $\Pi$ 为在上述域内从起点出发、按时序相接、经过有限个动作并结束的所有候选。每个完整候选最多含 $H$ 个正时长动作，所以即使位置图有环，$\Pi$ 仍然有限。等待和重复采样也要占用时间及资源。路线末端若不在 $V_{end}$，应补齐允许的结束路段后才成为完整候选。

这套生成规则有以下要求。

- 逐条枚举所有允许动作及等待起点，或者给出覆盖等价候选的证明。启发式挑出的若干路线是一份候选清单，其完整性需另有依据。
- 对整条路线固定动作顺序和采证时刻。同一动作集合的不同顺序可能有不同可达性、时效和成本，不能仅按动作集合去重。
- 正式证明无解前，需证明候选清单覆盖声明域内的全部路线。一个动作资格未知时，保留尚可能成立的分支。未经证明的剪枝会留下候选覆盖缺口。
- 离散化只定义本轮比较域。真实连续时间中间的出发时刻、表外测点、其他机器人或传感器不自动包含在 $\Pi$。需要扩展时生成新域，并重新比较。
- 缺失路径或动作目录、端点无法界定、外部测量安排不明时，保存缺口。即使当前列表已遍历完毕，也无法仅凭列表得出声明域内无解。

可以比较“当前已列路线中的最佳方案”，并明确该清单范围。声称相对于上述动作/时间生成域最优，则需完整候选覆盖或对遗漏部分的有效界。任意截去一批路线后不能继续沿用同一个完整域声明。

## 3. 完整路线与硬约束

候选路线记为 $p=(v_0,t_0,a_1,\ldots,a_n,v_n,t_n)$。动作绑定起止位置、时间、模态和资源。依次检查位置衔接、时间顺序、能力、管理许可、路径安全、有效依据、预算及截止时点。采样点和移动路径均须有各自的执行依据。若某区域状态尚待复核，只能使用已有安全依据支持的到达和观测方式，未证的安全输入进入未知分支。[D06](observation-bootstrap.md) 进一步固定观测站、独立安全依据、三值观测关系和周期预留：不能用本轮待得证据支持到达，提前路线的完整耗时上界须能避开下一周期预留。

总路线时间和能耗为

$$
T(p)=t_n-t_0,\qquad E(p)=\sum_{j=1}^n E(a_j).
$$

等待、采样和结束路段计入总时长，等待及设备工作能耗计入总能耗。若能耗采用区间，则预算资格按其上界检查。提交、传输与 S4 验收另有已固定的延迟区间，由此形成预计验收时点范围 $I_{eval}(p)$。本轮成本使用上述路线时长，验收延迟用于校验证据在使用时是否有效以及是否赶得上业务截止。

已有证据在 $I_{eval}(p)$ 内重新检查时效和适用性。新采样时刻、所支持的业务窗口和验收时刻分别记录。D02 连续域的要求要有已验证的时间支撑，单次采样加有效期不足以填补其余时段。首轮按 [D07](spatiotemporal-support.md) 使用保守几何包络及受控保持区间；预计采样、验收和任务窗口各自核验，未来动作不能凭尚未生效的保持指令冒称已取得物理保证。未知采样误差、时效或延迟的方案只能保留为可能可行。

零动作候选要求起点已属于允许终点，已有证据及全部门禁在预计验收时仍成立。需要返航或移动至规定终点时，必须包含对应路段。两个候选可分别满足不同条件，但结论需要一条同时满足条件的完整路线。要把两条路线接起来，需把串联结果作为新候选并重新核验全过程。

## 4. 见证分配与确定、可能资格

每条路线使用自己的可获得见证集合 $E_p$，其中包含当前可重用的证据和该路线按目录可产的见证。一个见证可由多个连续采集记录组成，按 D02 核验其联合覆盖。没有该路线或明确外部供给支持的见证，不进入分配。

对槽 $s$ 和见证 $e$，定义资格 $q_{se}\in\{T,F,?\}$。它包括模态、属性、采证目标、覆盖、质量、时效和用途。另记录每对见证的独立性资格、共同原因额度及各项执行约束。T、F、? 分别表示已有依据支持、已有依据否定、尚待判断。未来动作必须有适用的产证条件和质量模型支撑，普通期望值不能直接作为已证资格。规划记录这些模型假设及适用域，当前缺少标定依据的输入保留 ?。

确定分配只允许选择全部资格为 T 的见证、组合和路线。乐观分配额外容许尚未被否定的 ?。两者均尊重明确的 F、已知共因限额和能力限制。把未知项暂当可能时可能产生彼此无法同时成立的组合，这种松弛可用于排除证明，不能用来确认可行。

令 $z_{se}$、$y_s$ 为二元分配变量，$d_s$ 为该槽见证份数。对固定路线要求

$$
\sum_{e\in E_p} z_{se}=d_s y_s,\qquad
z_{se}\le h_{se},\qquad
\sum_{s\in S_g} y_s\ge k_g.
$$

其中确定检查的 $h_{se}=1$ 仅对应 T，乐观检查对应 T 或 ?。$k_g$ 按 ALL、ANY、K_OF_N 选择 $|S_g|$、1、K。显式必填槽固定 $y_s=1$。每槽见证数、同一见证的共享上限、共同原因额度和需独立的见证对也必须同时满足。首轮 D02 采用两个不同独立槽，同一见证及同一受限共因在组内额度为 1。

模板中的每项共享限制可写为 $\sum_{(s,e)\in B}z_{se}\le b_B$，其中 $B$ 是受限槽位与见证配对集合，$b_B$ 是允许份数。一个见证及其共同原因可以分别进入多项限制。对要求独立、但尚未证明独立的见证对 $e,e'$，确定检查在相应槽对上加入 $z_{se}+z_{s'e'}\le1$。已证明相关且违反模板额度的组合，在乐观检查中同样禁止。多个必需组使用一份联合分配。分别求出的各组最大满足槽数不能替代联合分配，因为它们可能争用同一见证或资源。

## 5. 三值判定与伪代码

记 $F^-$ 为已证满足路线全部硬约束及证据采集分配要求的候选集合。记 $F^+$ 为声明域中尚可能满足这些要求的候选上界集合。在目录、候选及见证上界均完整时，任何真正可行候选都应在 $F^+$ 中，并有 $F^-\subseteq F^+$。

| 结果 | 需要的依据 |
| --- | --- |
| FEASIBLE | $F^-\ne\emptyset$，至少给出一个完整路线及联合见证分配。其他候选未查完时仍可报告该路线可行，并保留最优性待证。 |
| INFEASIBLE | 在声明域覆盖完整的前提下 $F^+=\emptyset$，或有覆盖整个声明域的同等有效无解证明。逐条失败记录或界证明要可追溯。 |
| UNKNOWN | 尚无已证可行候选，并且有可能候选未排除，或目录/生成覆盖/资格上界仍有缺口。 |

显式矛盾的要求模板、版本不兼容等属于输入问题，记录原因并要求修正。在三值接口中无法建立有效求解上下文时返回 UNKNOWN。声称无解须针对有效且已声明的域。

```text
冻结义务、模板、快照、动作/时间生成域及资源预算
校验输入，保存生成覆盖依据和缺口
逐条生成或读取完整路线 p：
    核验全部路段、等待、采样、结束条件及预计验收时点
    在本路线可提供的见证内构建确定和乐观分配
    若确定硬约束及联合分配均可证：加入 Fminus 并保存证据
    若能证明乐观条件也不可满足：保存排除理由
    否则保留为可能候选或未决项
若存在已证可行候选：返回 FEASIBLE，继续核验成本排序与最优性
否则，若有覆盖声明域的共同无解证明，或域覆盖完整且所有可能分支均已排除：返回 INFEASIBLE
否则：返回 UNKNOWN，列出尚缺条件
执行完成后，S4 用实得证据、实际时点和当前义务修订重新验收
```

有限枚举和有限见证分配最终会终止。确定候选均有逐项资格及联合分配支撑。无解结论则依赖覆盖证明和所有乐观分支的排除。截止或超时后还有未处理候选时，保留其可能性。纸面设计已给出这些判据，实际候选数、资源消耗和运行时限待后续实现与研究验证。

## 6. 成本顺序与最优性声明

使用同一起始时点及成本模型，对已证可行方案按 $C(p)=(T(p),E(p),ID(p))$ 词典序比较。ID 的稳定全序由候选规范表达固定，消除同成本下的选择歧义。安全、证据充分性和硬预算先验通过，才能进入成本比较。

已遍历清单的最小成本候选是“当前已证可行方案中的最佳”。若还有可能可行的更短路线、同时间更省能耗路线或更优先的同成本 ID，最优性保持待证。成本本身仅有区间时，使用对整个区间成立的比较，不能仅凭预计均值定序。

在指定生成域中证明候选 $p_*$ 最优，可以完整评价所有候选，也可以对所有其余可能候选建立成本的词典序下界 $LB(p)$，并证明

$$
C(p_*)\preceq_{lex} LB(p)\qquad
\text{对所有其他尚未排除的候选 }p.
$$

下界必须对该候选所有可能可行实例成立。当前候选覆盖有缺口时，遗漏部分也需有这样的界。首轮时间成本若无误差可直接用精确值。能耗预算采用上界而目标又存在区间时，须注明是在优化保守成本，或等待实际成本比较，避免把上界选择说成实际能耗最优。

词典序目标没有天然的单一百分比最优性间隙。若可证时间下界为 $L_T$、可行方案时间为 $U_T$，可以报告时间差 $U_T-L_T$，但能耗优劣只有在最小时长已确定后才在同时间候选之间比较。下界为零或没有合格下界时，不给出百分比差距。对一般连续路线或域外动作的最优性需要额外论证。

## 7. 失效、验证与交接

义务或证据修订、图/地图/关联/变换、机器人能力、执行许可、安全快照、预算、行动时窗和产证模型发生相关变化时，重新判断影响。原计划失去必要依据后生成新修订。S5 负责 ReviewPlan，S4 处理提交回执和 Task，S6 负责执行及本地安全。S4 在实际验收时重新检查 D02 的证据内容、独立性、有效窗口和冲突。

[D10 地图消费实例](map-consumption.md) 将地图更正后的已有效证据交给本模型：保留 A 的完整支持和 B 的局部支持，选取能与 A 联合满足原必需槽的合格作业 C。重锚定不是新的采集收益，完整旧资料足够时可直接验收，误差或安全资格未明的路线不能为补齐地图例而放宽准入。

### 7.1 连续补证的继续与停止

首轮具体策略已由 [D09 多轮复核策略](multiround-review-policy.md) 固定：先重评，再在已证完整采证和有据完整供给等待中，按最晚验收资料时点、增量能耗上界和稳定 ID 选择。没有完整候选才有界等待前提或保留被动唤醒；不得为局部信息收益放宽现行提交的必需槽。该保守派工排序与 §6 的单轮路线成本分别记录。

一次有限求解结束后，实际读数可能仍跨阈值。对同一通道义务的受控试验，S4 记录尚缺的范围/槽、最近一次验收依据、下一次有望补足缺口的来源或时点，以及剩余的复核机会、时间和能耗。S5 在给定的剩余条件下选择下一条完整路线。复核机会数在实验前按场景能力与资源确定，并在同等对照中冻结。

| 情形 | 本轮处置 |
| --- | --- |
| 已有新资料或可采用另一项合格观测 | 先用新资料重做联合分配。仍有缺口且有预算时，可选新的独立测量、不同覆盖范围，或模板预定且可能增加信息的重复测量。记录预期能解决哪项缺口。每次新派发扣一次机会，实耗含失败、等待及必需结束路段。 |
| 输入与缺口相同，只收到重复回执或同源重算 | 关联原记录；同一输入触发的重放不重新派工。没有可增加信息的动作时，保留待定及唤醒条件，例如独立标定到齐或新观测角度可用。 |
| 采证路线已证无解、仅能证明可能可行，或剩余资源耗尽 | 分别保留规划结论及证据缺口。S4 按原义务策略等待、到期或转交有权人员。风险和授权要求即时升级时依原策略处理。S7 对当前任务按仍有效的证据判定，单纯耗尽采证预算不能证明通道受阻。 |
| 新证据或版本随后到达 | 校验原义务、谱系、时窗和当前许可。仍有效时重评，要求已变则依生命周期建立或关联后继义务。同一试验的原截止、已耗资源及失败记录随修订保留。 |

在固定试验内，最多派发预先给定的有限次数。每次实际重派消耗一次机会，等待有共同观测截止，故一次试验的自动补证可以收束。业务义务可以继续处于未决状态，待新事实后再评。

该停止性质不保证未决义务最终可确认，也不证明多轮总时长或总能耗最优。D06 已固定无初始线索时的周期核验与独立安全观测入口；D09 已固定实质签名、重试次数、常规决策时点和在途处理；同一过程的原截止、机会和已耗账随修订保留。[D08 联合可靠性](joint-evidence-guarantee.md) 已明确确定性界的逐次适用性及统计家族规则：有限补测次数不自动修复单次置信界，按结果改变测点/方法时须核验实际取数过程；重开义务不重置同一主张的置信账。具体缺口和反例见[全线复审 §6](review-baseline.md)。

例如，仅剩一次补测机会，派发时资格有据，但执行后才得知第二次观测与第一份共用失效标定。此次测量记实耗，证据仍不足；若事前已知该问题且无法满足模板，则不得以确定可行派发。此时保持未决，保存所需独立来源，截止前未确认按原实验计分。若截止前已有新的独立合格记录到达，即使派发机会为零，S4 仍可直接验收。截止后才取得依据时，在后续知识切点记录结果，原试验超时仍保留。

纸面案例集中在 [MSRP 案例](../validation/msrp-cases.md)。原八例保留并补齐候选完整性和证据资格前提，另有等待/采样成本、结束路段、证据过期、未证最优、跨组争用和测量结果未决等边界。D04 将采证可行率、业务确认率与代价分别定义，样本保留实际未决结果。D05 已将开题报告 §3.4 的原生公式与文字同步为完整路线及联合见证分配，并统一 §3.9 的最优性和三值描述，见[研究设计终审](review-baseline.md)。

本轮采用离散时序、结果未知的采证规划和词典序成本，延续既有单义务与单能力配置范围。数值依赖与产证模型的标定计划见 [D02](corridor-evidence.md)。来源为 [逻辑架构 §6.1](https://app.notion.com/p/41280c1f02208119a944debf8b5ca294) 与 [S4 MET §10–12](https://app.notion.com/p/41280c1f022081febf3ae621f1e7c71a)。
