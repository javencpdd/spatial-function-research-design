# D08 全证据链的联合可靠性

设计完成日期：2026-11-20。本轮连接 D02 的证据槽、D07 的时空支持和 E5 的条件可用性。首轮净宽证据采用**有界误差下的确定性集合推导**：只有适用误差、几何完整性和物理保持等前提均有依据，才向下游传递对应支持。多份材料通过准入、两个槽填满、结果重复出现，均不自动产生某个正确概率。

这里完成模型选择、联合推导、预算和停止规则。实际误差界、公共前提资格、统计校准及研究效果仍需取证；纸面假设不等于真实场地已经满足。

## 1. 明确首轮采用与保留的分支

| 项目 | 本轮决定 |
| --- | --- |
| 净宽与几何 | 使用覆盖实际单次状态、整个声明子域的有界误差集合，经 D07 内外包络保守传播。保留共享误差变量，不假设误差互相独立。 |
| 连续与未来支持 | 使用 D07 的受控保持、时间误差和用途资格。误差小不能替代全域覆盖，统计置信高不能替代物理保持。 |
| 两份见证 | 仍按 D02 的来源与共因资格、各自全域通过或共同反例验收。槽位独立性是一项准入要求，不是错误概率相乘的许可。 |
| 多轮与选优 | 每个实际使用的确定性界须对其实际测量、域和误差模型成立。可在合格材料中选择，但不删除合格冲突；新数据和新域重新核验。 |
| 统计证据 | 采用 §5 的有限预定家族准入规则；其预算只能组合已经有效的单项覆盖。尚无单项构造或适用依据时，不借预算表宣称合格。首轮不靠它替代净宽的确定性集合模型。 |

本轮确定性结论始终相对于明确的允许误差与状态集合。没有符合条件的测量资料时，结果为未决；不是因为选了“确定性”就获得现实零风险。

## 2. 每份依据的最小说明

沿用现有 Evidence、Calibration、Model、Policy、Map/Transform、ReadSet 引用，补充研究记录语义，不另签 Wire Schema。

| 项目 | 必须说明 |
| --- | --- |
| 证明对象 | 实际单次几何/净宽、平均参数、未来状态、风险概率或实验效应；对象不能互换。 |
| 数学类型 | 对所有允许误差成立的集合界，或在明确随机试验下具有覆盖保证的统计界。区间形式本身不区分两者。 |
| 适用域 | 完整空间/高度/时间、对象与要求、版本、设备/作业/批次、环境条件及允许动作。 |
| 前提与依赖 | 测量误差、尺度/配准、未知体积、物理保持、时钟、来源和用途；哪些有依据、哪些未知或仅为纸面假设。 |
| 联合范围 | 只覆盖一点、一整份几何包络，还是全部候选/轮次；上下两尾是否已包含，是否允许选择及停止。 |
| 共因身份 | 同一原始数据、共享标定/变换/保持依据的精确修订及其实际影响，不凭设备名称判断独立。 |
| 失败与版本 | 越界、撤销、迟到更正、预算不足及范围扩展时如何失效；保留原知识切点与后继修订。 |

例如，关于平均测量偏差的 95% 置信区间既不是每个新读数的误差界，也不是整个通道的同时覆盖带。统计预测区间也不能直接支持 D07 之外的任意未来环境。

## 3. 确定性联合推导

### 3.1 同一个现实、同一组共享变量

令 B 为本次明确声明的背景模型和适用条件。令 z 同时表示真实几何、时间以及所有独立或共享误差变量；同一标定偏差只出现为同一个变量。将全部已采纳约束组成允许现实集合

$$
\mathcal K=\{z:B(z)\ \text{且所有适用的测量、覆盖、保持与时间约束成立}\}.
$$

必须先确认输入相容、$\mathcal K\ne\varnothing$，且每个必要前提有其所需资格。空集合属于冲突或无效上下文，不能用“所有允许现实都通过”的空真命题验收。仅用作纸面条件的 B 必须明确标注，不在现实验收时默认通过。

对见证 e，令 $\mathcal K_e$ 只由其自身采集链和合格公共依赖形成，不偷用另一槽的测量作为自身独立支持。输出包络须包住这些允许现实：内集合包含于 $\bigcap_{z\in\mathcal K_e}O(z)$，外集合包含 $\bigcup_{z\in\mathcal K_e}O(z)$。允许可计算的保守近似，不要求精确求出所有现实。由此，对声明域 $D_e$ 保证

$$
\forall z\in\mathcal K_e,\ \forall(x,t)\in D_e,\quad
O_e^-\subseteq O(z)\subseteq O_e^+,\qquad
\ell_e(x,t)\le W_z(x,t)\le u_e(x,t).
$$

这里的集合包含在声明几何域内解释，输出的界必须由可用资料取得，不能依赖未知真实 z 的有利取值。有限盒、坐标变换、投影及净宽计算沿 D07 处理；数值舍入向外，不以格中心采样代替整格覆盖。

在全部前提成立、输入相容时，D07 的集合包含与覆盖检查推出每份声明在其域内正确。D02 再要求两个合格独立槽各自支持全域 PASS，或共同位置/时段的 FAIL。S7 仍查全部任务硬条件和证明资格。该蕴含链不需要任何测量之间的概率独立假设。

不能先把 A 的区间 [0.98,1.04] 与 B 的 [1.02,1.10] 相交，再给两个槽都填写 [1.02,1.04]。A 自身仍未证明 1.00 的阈值，B 的信息不能伪装成 A 的独立支持。约束交集用于相容性和明确授权的推导，不用于增加独立见证。

### 3.2 误差如何沿链传递

以某横向边界的研究简式说明，真实坐标满足

$$
y=\hat y+b_{\rm cal}+b_{\rm tr}+\eta_e,\quad
|b_{\rm cal}|\le c,\quad |b_{\rm tr}|\le d,\quad|\eta_e|\le r_e.
$$

无其他相关约束时，保守边界为 $[\hat y-(c+d+r_e),\hat y+(c+d+r_e)]$。重复测量不自动缩小 c 或 d；没有概率模型时也不把 $r_e$ 除以平方根样本数。实际非线性变换须对整个误差集合取外覆盖；本简式不能替代旋转、尺度或复杂几何传播。

若两端坐标确实共享同一个平移变量，该变量可在差值中代数抵消；必须证明变量身份和作用相同。只因两次记录引用同一地图，不能推断误差抵消。公共依赖去重只是避免重复登记，不删除它对各几何边界的影响。

沿用 D07 右侧实心障碍的示意，固定同一坐标下通道左边界为 0，本例将该边界的误差取零。障碍左边界读数 1.10 m，测量、变换、标定半宽分别为 0.02、0.03、0.01 m，其保守净宽下界为 1.04 m。若遗漏后两项会误报 1.08 m。另一见证读数 1.08 m、同等总半宽 0.06 m，则下界为 1.02 m；两者能支持 1.00 m 的属性要求，前提是各自覆盖、来源及公共依赖资格均已给定。现实通道边界也有误差时必须一起传播。这个例子没有证明实际设备具备这些界。

### 3.3 共因与未知前提

把证据推导及其前提表示为有限有向无环依赖图，叶节点为实际输入，内部节点为有明确规则的保守推导。原记录复制、裁剪和重复读取保留同一来源身份；公共标定、坐标或保持证明只登记一次，并列出所有受影响结论。

- 两个设备共享未受控制且可能改变结论的误差，按 D02 不能填两个确定独立槽。
- 共享前提有保守界，并不自动使两条采集链成为独立来源；还须完成模板规定的共因控制和来源核验。
- 前提未知时不赋“低概率失败”，也不当作零误差。依赖它的相应支撑未决，未受影响且有不相交依据的子域可保留。
- 只含“输入可信，因为输出正确”的循环不是证明。D06 的观测安全也不得引用本轮尚未产生的证据。

若某份材料仅有统计覆盖，整条链不能继续以无概率的确定性保证发布；按 §5 明确改成相应统计范围，或保留缺口。

## 4. 四类预算分别记账

| 账本 | 量与单位 | 当前规则 |
| --- | --- | --- |
| 物理误差与支持 | 几何误差 m、时钟误差 s、覆盖域与保持条件 | 首轮采用集合最坏界。无有效有限界或完整支撑时，相关用途未决。它不是置信失败预算。 |
| 证据覆盖失败 | $\alpha_{\rm evid}$，概率预算 | 只有采用统计证据时启用，覆盖其完整预定家族及公共前提。确定性模型不需要这个预算，不因此声称现实失败率为 0。 |
| 任务风险与风险界 | $\epsilon_q$ 为 E5 不利事件风险上限；$\alpha_{\rm risk}$ 为相应界的置信失败预算 | 两者分开。候选与执行域必须完整，支持输入的统计不确定性不得遗漏；同一失败事件不重复算成独立保证。 |
| 研究效果 | $\alpha_{\rm effect}$，整体检验预算 | 现有协议的 0.05 只分配给预定研究效应端点，不能同时充当所有测量、保持和风险模型的保证。 |

时间、能耗、派工机会仍按 MSRP 的资源账核算，与以上置信预算分开。

分别报告各类结论时须注明各自条件和预算。若提出一个需要它们同时成立的联合概率主张，应先给出共同的失败事件语义并锁定 $\alpha_{\rm evid}+\alpha_{\rm risk}+\alpha_{\rm effect}\le\alpha_{\rm total}$ 或有效的去重分配；现有各项分别为 95% 不等于整体也是 95%。不能把 $\alpha_{\rm evid}$ 或 $\alpha_{\rm risk}$ 直接解释为一次任务的事故率，亦不能无模型地将它们与 $\epsilon_q$ 互换。

## 5. 有限统计家族的准入、选择与停止

### 5.1 先有有效单项，再做联合

对统计分支，事前固定有限家族 $\mathcal F$，涵盖会被用于主张的子域、候选、来源、轮次、上下尾及公共前提。每个 i 的事件 $G_i$ 明确表示“该项对原声明目标及全域正确覆盖”。在同一个明确背景 B 和实际取数设计下，必须先有

$$
P(G_i^c\mid B)\le\delta_i,\qquad
\sum_{i\in\mathcal F}\delta_i\le\alpha_{\rm evid}.
$$

则无需事件独立，已有

$$
P\left(\bigcap_{i\in\mathcal F}G_i\mid B\right)
\ge1-\sum_{i\in\mathcal F}\delta_i
\ge1-\alpha_{\rm evid}.
$$

这是有限同时覆盖的并集界；不等式依据见 [NIST Bonferroni 方法](https://www.itl.nist.gov/div898/handbook/prc/section4/prc473.htm)。将事件绑定到本项目的完整证据域是本设计的应用选择。预算不能修复错误的单项区间构造、错目标或遗漏的物理保持。

若全部非统计前提及推导规则也成立，则在该家族保护范围内，有限轮次中“曾发布错误属性断言”的事件包含于 $\bigcup_iG_i^c$，其概率上界不超过 $\alpha_{\rm evid}$。这一步依赖全域支持和正确推导，不能由预算数字单独得出；受保护的属性断言也不等于整个任务无事故。

若单项证明另条件于其父节点正确，不能直接充当上述无额外条件的边际界。可在有限无环图中定义“父节点均正确而本节点失败”的首次失败事件，逐项证明这些事件在共同背景下的概率界后再求和；无此证明则不准入。未计入的背景假设依然是结论条件，不得藏成已经覆盖的现实失败率。

### 5.2 冻结家族和允许操作

本轮统计接入只允许以下范围：采集对象、时段、方法、有效区间构造和数据依赖关系事前冻结，并证明对该取数设计全体同时有效；或输入本身已经带有覆盖完整允许选择过程的同时保证。按读数临时改变测点、时间、方法或状态条件的取数不自动属于固定设计，即使给新记录补一个预留编号也不够。

全家族同时正确时，任何在家族内的子集选择、方案比较或提前停止，仍只使用这些正确声明。因此可以选择或停止读取预定资料，而不声称选后条件覆盖率；不要求把未读取资料强行采齐。若采用按结果自适应取数，必须先证明其实际过程的保证，本轮没有默认提供这一统计构造。[D09 多轮复核策略](multiround-review-policy.md) 已将首轮自适应行动固定为完整采证/有界等待规则，使用 §3 的确定性界并逐次核验真实适用性；实质签名和资源次数不替代统计过程保证。

规则如下：

1. 看到结果前锁定总预算、家族边界和每项 $\delta_i$；等权时为 $\alpha_{\rm evid}/|\mathcal F|$。两侧区间的总失败预算已含两尾，不能每尾再用全额。
2. 点位小网格不等于连续域。只有每个事件已覆盖自己的完整子域，且 D07 的联合覆盖成立，才支持全域。
3. 相同事件的精确引用在同一统计家族只计一次；新的测量或新的现实时间不是重复事件。复制一百次不改善覆盖，也不产生独立槽。
4. 不把“未用完的编号”或未见失败当作预算返还。改变家族、域或规则须重新给出对全部相关查看及选择有效的保证；不能每次重开义务就重置同一研究主张的置信账。
5. 到资源、统计适用域或取数设计边界时，停止发起相应不合格补证，保留未决及可唤醒条件；允许处理仍在原保证范围内的新到合格材料。停止不等于物理 FAIL。
6. 任意停止置信序列属于另行验证的扩展，不能仅因其名称就用于动态净宽或未来预测。[Howard 等（2021）](https://arxiv.org/abs/1810.08240) 给出时间一致的统计覆盖方法；本轮未采用其替代物理模型。

### 5.3 一份可复算预算示例

以下只是统计接入的合成纸面示例，假设每项已具上述有效性，不是现场标定或风险授权。固定 5 个完整子域、2 个来源和 4 个预定采集时段，共 40 项测量覆盖事件；另有 4 项公共依据事件，且没有遗漏其他随机依赖。

| 项目 | 项数 | 每项失败预算 | 小计 |
| --- | ---: | ---: | ---: |
| 完整子域的测量覆盖 | 40 | 0.0003 | 0.012 |
| 公共标定、坐标、时间、保持依据 | 4 | 0.002 | 0.008 |
| 联合 | 44 | — | 0.020 |

全部事件在共同背景下同时成立的概率至少为 0.98。公共依据在两来源之间去重记账，但任何未被证成的公共前提仍是缺口。若仅有 20 个相互独立且各恰为 95% 覆盖的区间，至少一个不覆盖的概率为 $1-0.95^{20}\approx0.641514$；它是区间覆盖失败，不能直接叫误验收或事故率。未知相关性时不使用此乘法。

假设同一当前净宽读数因设备公共偏差而一起偏大：两个输出可以同时出错；即使两个边际失败概率各为 0.05，共因完全一致时同时失败仍可为 0.05，而非 0.0025。D02 的来源门禁与本节的联合保证须分别满足。

## 6. 选择、更新与跨模块交接

| 环节 | 本轮固定规则 |
| --- | --- |
| S3 状态与 Bundle | 保存证明对象、实际域、依赖与界的类型。未知前提、输入冲突、物理冲突分别记录；不能把置信数字当物理状态概率。 |
| S4 验收 | 同时查每份实际支持、联合覆盖、来源分配和全部必要公共前提。两槽规则不因联合置信预算通过而放宽；已有合格相反证据不能在选优时丢弃。 |
| S5 多轮规划 | 当前派工须有适用的产证模型与资源。新证据的可预计质量与最终读数分开；实际补证遵守同一试验的原截止和已耗账。D09 已固定动作、等待和停止策略，并记录在途取消及安全尾段。 |
| S7 条件可用性 | 绑定原请求、完整执行域及所有依赖。净宽的支持保证、风险概率上限、风险界置信及实验效果各自核验，不用某一项代替其余。 |
| S8/知识切点 | 依赖修订不可变、用途及读取资格沿现有契约。晚到撤销在新切点限缩支持，保留过去 ReadSet；不改变已暴露错误的世界评分。 |
| 地图/标定变化 | 范围、变换、误差模型或保持条件改变，先做兼容与重锚定。旧包络不能仅改 ID 后使用；统计家族也不自动扩到新域。D10 给贯通实例。 |

对确定性主线，增加合格测量不会产生统计多重比较惩罚，但可能引入新冲突或新的未知依赖，必须重评。一个具有合格界的新资料到达，不保证业务一定可确认。对统计分支，资源剩余并不证明仍有合法置信预算或适用的取数设计。

## 7. 十五项纸面边界

| 编号 | 场景 | 应有结论 |
| --- | --- | --- |
| D08-01 | 只知道平均误差的 95% 置信区间，要求当前净宽下界 | 目标不符，不能填当前状态的确定支持 |
| D08-02 | 每个断面有点界，断面间未覆盖 | 概率再高也不补几何空白，按 D07 保留未知 |
| D08-03 | 20 个独立且各 95% 的区间 | 至少一个不覆盖约 64.15%，不是整体 95% |
| D08-04 | 两设备共用偏差，重复读数一致 | 共享误差不缩小，不乘边际失败率；来源槽仍查共因资格 |
| D08-05 | 同一制品复制 100 份、同一公共前提多处引用 | 原身份/失败事件去重，不增加独立支持或置信收益 |
| D08-06 | 预实验最大残差 0.02 m，未有范围外界或尾部依据 | 不能直接宣称所有未来误差绝对不超 0.02 m |
| D08-07 | 反复以单次 95% 区间补到恰好 PASS | 有限次数本身不修复覆盖；需原过程的同时有效性 |
| D08-08 | 预定有效同时家族内选择最低风险候选或提前停止 | 保留家族保证；不宣称选后条件概率或现实零风险 |
| D08-09 | 按结果临时换测点/时间，仍使用固定设计界 | 预留编号不够；无实际取数过程保证时保留资格缺口 |
| D08-10 | 四轮机会耗尽或家族之外材料到达 | 停止不合格补证；域内有效新材料仍可核验，不由耗尽推出 FAIL |
| D08-11 | 地图重投影或标定换批，沿用旧界和统计编号 | 先重锚定并核查适用性，不能自动扩域/重置预算 |
| D08-12 | 两个合格区间对同一现实互不相容，允许集合为空 | 记录冲突；不以空真命题推出任意 PASS/FAIL |
| D08-13 | 将两份区间交集回填两独立槽 | 不准；每份见证仍须有自身全域支撑 |
| D08-14 | 证明过期/保持未知，但没有硬反证 | 正向支撑不足；S4 未决或重评，S7 PENDING，不自动 BLOCKED |
| D08-15 | 输入保证、风险界和效果分析各报 95% | 不声称整体 95%；先定联合主张、事件语义和总体预算 |

这些案例覆盖原验收要求的单点到全域、多轮选择、同源复用及适用域变化，并检查类型混用、空集合和共同前提。算例仅核对逻辑和数值，不是测量实验或系统安全认证。

## 8. 完成范围与后续

D08 已选择首轮确定性集合主线，明确联合量词、误差传播、共因依赖、有限统计家族准入、四类账本及停止规则。实际材料若只支持统计声明，应按其真实类型另核验，不能为了填槽把它改称确定性。没有任何一个 95% 数字在本轮被认定为真实设备或现场的已验证性能。

D09 已完成根据缺口选择下一动作、等待或停止的限定策略。剩余 D10 用一个通道及拆分/重投影贯通上述误差、支持、验收与 S7，并明确贡献边界；实际标定、研究效果及正式工程/治理证据另行取得。
