# D01：事件影响闭包的限定数学设计

日期：2026-11-18。状态：研究设计已收敛，含纸面推导；适用于有限、版本固定的通道场景。此处定义“哪些属性或功能要求需要重新检查”，不判断事件是否真实、功能是否失效或机器人能否通行。

本轮采用统一的有类型关系闭包。分层算法仅在“空间边为属性→属性、功能边为属性→功能或功能→功能、无功能→属性反馈，且第二阶段也遍历功能边直至稳定”时与本设计等价。报告现有“一次功能关联”不满足这个条件。统一算法便于共用候选传播、原因路径与终止证明。

## 2. 输入、类型和计算范围

一次计算固定上下文 K：Event Revision、Map/Graph Release、Cell Partition、Requirement Catalog、Propagation Policy、关联/坐标变换版本、声明的查询域 U 和有效时间窗口 J。S4 另保留触发事实及所依赖的 S3 修订；S2 消费已固定的种子、属性和适用上下文，不自行估计现场状态。

有限目标集 X 有两类元素：

- P(c,a)：空间支持单元 c 上的属性 a。c 精确绑定地图/分区；a 来自版本化属性目录。
- F(u,f,r)：功能单元 u 的功能 f 所对应的要求 r。r 精确绑定 Requirement Catalog；其空间范围由目录解析。

U 是声明范围内的上述目标集，不是整个校园的默认全集。每次计算保存 U 的来源和边界完整性依据；作用域之外出现有效依赖时，扩展到明确的新范围后重算，或记录边界未决，不能截断后仍称完整。未在源图显式存储的 P、F 可以作为计算视图节点，必须能追溯到既有对象、属性或要求；不新增权威空间实体。

以所有已知时间边界把 J 划成有限个半开区间 j。在每段内，各输入适用性固定；下文公式分别对每个 j 计算。不能把不同时间段的边串成一条同时成立的路径。时间边界未知时保留候选/未决；关键版本无法解析或 Map/Graph 不兼容时不进行有效闭包声明。

### 种子

- S⁻：几何相交/明确对象绑定、属性映射及时间适用性均已确定的直接复核目标。
- S⁺：S⁻ 加上空间、属性或时间关联尚待确认但有明确候选依据的目标。S⁻ ⊆ S⁺。
- 无定位、未知属性不能用空集合冒充“无影响”。能枚举有限候选时加入 S⁺；不能界定时记录未定位/未知属性缺口。

“确定种子”仅指在给定事件输入下绑定已确定，不证明事件真实发生。几何边界接触是否纳入种子按已固定的相交语义及误差规则决定；本设计不指定未经标定的距离阈值。

### 有向传播规则

每条规则保留源/目标类型、属性或要求映射、方向、依据关系引用、适用范围/时间、策略版本与资格判据。箭头统一从“发生变化的依赖项”指向“需要复核的依赖者”；源目录若以 depends_on 反向存储，派生视图时显式反转，不默认双向。

| 规则族 | 允许的映射 | 使用条件 |
| --- | --- | --- |
| Rₛ：空间属性影响 | P(c,a) → P(d,b) | 明确声明属性 a 到 b 的传播机制、方向与关系依据；ADJACENT、CONTAINS 或导航连接本身不足以推出该边。 |
| R𝒻：属性影响要求 | P(c,a) → F(u,f,r) | 要求 r 确实依赖该属性及其作用域，保存 SUPPORTS/CONSTRAINS 等原始关系和映射规则。 |
| R𝒻：功能要求影响要求 | F(u,f,r) → F(v,g,s) | s 依赖 r 的状态或证明有效性；允许多跳和环，按精确要求身份访问。 |

本轮不引入 F→P 的反向因果边，不从“功能待查”推导新的物理属性变化。必要时由新的领域事实触发新的事件。每条边单独映射属性，后续传播使用目标属性 b，不能始终拿事件最初属性集去过滤所有后续边。

单条规则边 ρ 的资格 gⱼ(ρ) 为 T、F 或 ?：T 表示关系、方向、属性映射、作用域与时间依据足以支持这一步；F 表示有明确不适用依据；? 表示关系/映射/适用性未决。同一对端点的不同规则分别保留；同一关系的支持与反对声明尚未裁决时为 ?，不能自行取有利声明。所有判据在本次快照中固定，不以当前已访问集合的“缺席”作条件。缺少必需目录条目是缺口，不等于 F。

AND、OR、K-of-N 在这里采用“任一被依赖项需要复核，就使父要求需要重新评价”的保守相关性传播。OR 的另一支可能仍满足要求，所以父要求被到达不代表失败。不能借此代替 S4 的验收算子。需要多个事件共同成立的因果规则、非单调规则及任意路径历史条件不在本轮单前件模型中；遇到此类规则必须暴露为未覆盖项，不能无声扁平化。

## 3. 两个闭包及排除规则

在一个时间段 j 上，把符合类型规则的 Rₛ∪R𝒻 分成：

$$
R^- = \{(x,y)\mid \exists\rho:x\to y,\ g_j(\rho)=T\},\qquad
R^+ = \{(x,y)\mid \exists\rho:x\to y,\ g_j(\rho)\in\{T,?\}\}.
$$

对固定关系 R，定义：

$$
T_{R,S}(Z)=S\cup Z\cup\{y\mid \exists x\in Z:(x,y)\in R\},
\qquad \operatorname{Cl}_R(S)=\bigcup_{n\ge0}T_{R,S}^{\,n}(S).
$$

两个结果为：

$$
C^- = \operatorname{Cl}_{R^-}(S^-),\quad
C^+ = \operatorname{Cl}_{R^+}(S^+),\quad C^-\subseteq C^+.
$$

- confirmed_scope：C⁻，表示存在一条绑定和传播依据均已确认的复核相关路径。
- candidate_scope：C⁺∖C⁻，表示只存在含未决种子/关系的候选路径，或尚无已确认路径。
- unresolved_edges：记录未决关系、未知端点、缺失目录、作用域越界及其前沿；未知种子另记于 uncertainty_summary。
- excluded_scope：只纳入有排除证明的目标。若所有可能种子和依赖均已被 U 内的有限上界覆盖，可取 U∖C⁺；否则只登记具备独立排除证明的目标，其余未到达目标保持“尚未评估/未决”。

C⁺ 只有在候选上界完整时才包住所有允许的可能传播；依赖清单缺失或端点不明时，它只是已知部分的可能可达集，不能用于证明其余区域无影响。未知关系之间可能互斥，C⁺ 仍可作为保守上界，不把其中每条路径说成已能实际共同发生。

排除一条路径不能排除目标：若另一条已确认路径到达目标，目标仍属于 C⁻。候选路径不会降低已有确定路径的结论，但未决关系记录仍须保留。分类按“空间/功能目标＋属性/要求＋时间段”，投影成一个 Cell 时不能抹掉不同属性的分类差异。

**闭包包含种子。** 这里是 S4 Event 的业务复核范围，不改写 S2 MapDelta 的静态依赖字段；后者既有 affected_refs 排除已列 roots 的契约继续有效，两者不能直接共用字段语义。该字段边界已核对 [FQ-01 §3B](https://app.notion.com/p/41480c1f02208135a40de6f1ad36ccfb)。

## 4. 与公式一致的伪代码和性质

```text
输入：固定上下文 K、目标域 U、时间窗 J、种子与规则目录
检查精确版本、类型和兼容性：硬性矛盾则停止并返回 INVALID
关键快照缺失或种子无法界定则返回 PENDING；可枚举的不确定项继续候选计算
记录候选边界、目录覆盖和未解析依赖；不能用空图补齐缺口
按已知有效时间端点划分 J
对每个区间 j：
    生成有限 Sminus ⊆ Splus，以及带原因引用的 Rminus ⊆ Rplus
    (Cminus, Wminus) = Reach(Sminus, Rminus)
    (Cplus,  Wplus)  = Reach(Splus,  Rplus)
    confirmed = Cminus
    candidate = Cplus - Cminus
    excluded = 具备候选上界完整性证明时的 U - Cplus，或独立证明的排除项
    输出分类、时间段、Wminus/Wplus、拒绝边理由和未决前沿
合并输出时保留各目标的时间区间，不把候选并入确认
S2 返回计算结果；S4 绑定事件修订并登记 ImpactClosureResult

Reach(S, R):
    seen = S; queue = 按稳定目标 ID 排序的 S
    witness = 每个种子的直接绑定依据
    while queue 非空:
        x = queue.pop_front()
        for edge (x,y) in 按稳定规则/目标 ID 排序的 R.outgoing(x):
            if y not in seen:
                seen.add(y)
                witness[y] = (x, edge 的原始关系及策略引用)
                queue.push_back(y)
    return (seen, witness)
```

分别遍历两个关系集，避免先以候选路径访问节点后漏掉已确认路径。每个被到达目标保存一条可复算的代表路径；不枚举环上的无限路径。未决、拒绝和覆盖证据单独保存，不能从代表路径反推“所有路径都已检查”。在固定排序下，代表路径也可稳定复现。

在有限 X、输入不变、局部单前件规则和未被截断的遍历下：

1. **终止：**每次只把新目标入队，每个 Reach 最多入队 |X| 次；环不会产生无限新目标。两个遍历均终止。
2. **最小不动点：**每次新增目标都有种子路径，因此不会超过可达集；反之，按路径长度归纳，每条允许有限路径的终点最终都会入队。得到包含种子的最小 R 闭集。
3. **扩张、单调、幂等：**S⊆Clᵣ(S)；固定 R 下 S⊆S′ 则 Clᵣ(S)⊆Clᵣ(S′)；Clᵣ(Clᵣ(S))=Clᵣ(S)。由 S⁻⊆S⁺、R⁻⊆R⁺ 可得 C⁻⊆C⁺。
4. **局限：**这些性质只针对本次固定模型。新版本可能删除边或改变资格，不能跨版本声称范围只增不减；候选集在未知得到消解后也可以缩小。有限图上的终止不证明现实依赖完整。

在稳定排序的邻接列表已备妥后，每个区间两次遍历的工作量为 O(|X|+|Rₛ∪R𝒻|)，规则边按保留的原始记录计数；不含排序、目录解析、几何关联、候选完备性论证及时间划分成本。若实际处理被截断，只能报告已得部分，不能使用上述“所有路径已遍历”的结论。

## 5. 完整性与结果状态

以下为现有状态的研究设计判据，不新增 Wire 枚举：

| 状态 | 本轮解释 |
| --- | --- |
| COMPLETE | 声明域、时间段、种子、关系目录及范围边界有完整性依据；适用规则均能表达；与可达范围相关的资格已定；遍历未截断。仍只证明给定事件输入下的关系计算完成。 |
| PARTIAL | 可计算部分范围，但存在候选绑定/关系、缺失依赖、越界、无法表达的规则或截断。明确已计算部分和缺口，不能对剩余范围作无影响声明。 |
| PENDING | 尚无足以开始可信计算的种子或必要输入；保留事件和待定位/待补齐事项。 |
| INVALID | 已获得的必需输入存在不兼容版本、错误类型或违反上下文约束。不得把结果用于有效闭包。 |

状态是整体摘要；具体未决原因和各目标分类仍需保留。S7 不能仅因当前请求对象没出现在一个 PARTIAL 闭包中而继续沿用可用结论，应按作用域适用性判断，无法证明不相交则保留待定。声明域外的缺口只有被证明不影响当前查询域时，才不妨碍域内完整性。

## 6. 从复核目标到验证义务

对每个功能要求目标 F(u,f,r)，S4 解析其版本化要求快照、依赖属性及证据模板，形成候选义务元组：

$$
o=(e_{rev},\ closure_{ref},\ scope,\ f,\ r_{rev},\ A_r,\ J_o,\ predicate_{ref},\ template_{rev}).
$$

Aᵣ 是本要求要核验的属性集合；Jₒ 是由事件/影响区间与要求、模板适用区间共同限定的验证有效窗口，派发截止时间另行保存。模板若要求在事件结束后验证恢复，必须显式给出该后继窗口及事件依据，不能默认照搬事件持续时间。实际证据覆盖、质量和独立性由 D02 细化。

- 确认目标：有适用模板和触发规则时生成、关联或重开义务；已有有效且覆盖完整的验收可支持不新增义务，但须保存依据。
- 候选目标：优先验证未决关联/属性，也可依据授权的保守策略生成明确标注不确定来源的复核义务；不能直接改为受阻或通过。
- 排除目标：只对本事件和本快照记录“不需要因本次传播新增义务”的理由，不取消其他事件的义务。
- 缺模板、缺要求、未知作用域或有效窗口未定：登记覆盖缺口和待决项，不能伪造完整业务闭环或静默跳过。
- 一个要求由多条路径到达时合并同一语义的义务候选，保留全部触发关联。沿用既有业务幂等身份，Event/Closure 的新修订触发既有义务的重评或修订，不仅因修订号变化重复建义务。不同属性、有效窗口无法由同一谓词覆盖时须显式拆分或修订。

闭包更新不直接修改 S3 的物理状态、管理许可或功能投影。S4 正式验收后由各模块按既有职责更新；规划 FEASIBLE 和 Task SUCCEEDED 都不是关闭义务的依据。

以下均为手算，没有运行实现或实测数据。除特别说明，种子、关系与候选域完整，输入固定，边资格为 T，时间同为 [0,10)，不存在表外规则。pA、pB、pC 为明确属性目标，qA、qB、qC 为明确功能要求目标；箭头旁 S/F 指空间/功能规则。集合逐轮增加至稳定，种子也在结果中。

| 编号 | 输入与推导 | 结论 |
| --- | --- | --- |
| C01 直接影响 | U={pA,qA,pB}，S⁻=S⁺={pA}，pA→F qA。第 0 轮 {pA}，第 1 轮加 qA，此后稳定。 | C⁻=C⁺={pA,qA}；排除 pB。qA 进入要求/模板匹配，不直接判失败。 |

| C04 环 | U={pA,pB,qA,qB}；pA→S pB→S pA，pB→F qA→F qB→F qA；种子 pA。 | 四个目标各入队一次，稳定于 U。无需因环删除依赖，也不增加无限义务。 |

| C07 另一条确定路径 | 在 C06 中增加 pA→F qB 为 T。 | C⁻={pA,qB}；C⁺=U；只有 pB 为候选。qB 使用直接确定路径，未决边仍保留，整体仍 PARTIAL。 |
| C08 缺少依赖目录 | U 声明为 {pA,pB,qB}，种子 pA；目前只读到 pA→pB，但 pB 后继目录缺失。 | 已知 C⁻=C⁺={pA,pB}，不代表上界完整。qB 不可排除；记录缺口并返回 PARTIAL，遍历结束无助于证明完整。 |
| C09 时间不重叠 | U={pA,pB,qB}；种子 pA 有效 [0,10)，pA→pB 仅 [0,5)，pB→qB 仅 [5,10)。 | [0,5) 闭包 {pA,pB}；[5,10) 闭包 {pA}。qB 在两段均不可达；不能跨段拼接。输入完整时分段 COMPLETE。 |
| C10 OR 的相关性与失败分离 | U={qA,qB,qParent}，父要求为 OR(qA,qB)，依赖 qA→qParent、qB→qParent，种子 qA。qB 另有有效通过证据。 | C⁻=C⁺={qA,qParent}，qB 不因反向依赖到达。qParent 需重评；其 OR 验收仍可能通过，闭包不输出 FAIL。 |
| C11 版本/身份边界 | 事件锚定旧 Cell A，新图引用分裂后的 A1/A2；尚无兼容的关联重评结果。 | 不能把 A 政名为 A1 后继续遍历。Map/Graph 明确不兼容为 INVALID；兼容新快照但新锚定未齐为 PENDING，有限候选锚定可用时才算 PARTIAL。 |

六类必需情形对应 C01—C06；C07—C11 检查分类替代路径、输入完整性、时间、验收算子与版本边界。以上只证明例内关系推导一致，不证明真实校园依赖目录完整或事件识别准确。
