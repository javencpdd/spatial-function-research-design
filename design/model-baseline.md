# 研究模型基线

本文件整理当前限定设计。闭包的公式与伪代码、证据质量阈值和独立性判据仍有待定事项，见[设计待办](../ROADMAP.md)。

## 空间身份与版本

空间实体以稳定身份关联几何、局部单元、功能与关系图。一次判定固定相关地图、关系图、变换、功能要求及策略版本。地图发布版本和动态状态修订分别维护。单元分割、合并或重投影后，按新作用域重查旧证据的覆盖、配准误差、时效与适用性。

## R1 双源状态维护（APCM）

管理状态 $M$ 由适用的授权记录支持。物理信念 $b(X)$ 根据现场观测以及适用的转移与观测模型更新。两者通过空间身份、版本和有效时间关联。管理开放而阻塞证据充分时产生差异候选。管理封闭而现场畅通时保留禁令。遮挡、未探测范围和未知的来源关联保留不确定性。

## R2 事件、验证义务与复核规划

事件影响分析与验证义务生成（MET）从事件几何与属性定位初始影响集合 $\Omega_0$。在固定版本的空间及功能依赖图 $G_v$ 与传播策略 $\Pi_p$ 下计算 $\operatorname{Closure}(\Omega_0,G_v,\Pi_p)$，记录传播原因并区分已确认、候选、排除和未决范围。影响范围用于提出验证目标。功能是否满足要求由证据验收确定。

验证义务固定空间单元、功能、待核验属性、有效时间、要求版本及通过谓词。证据槽检查模态、覆盖、质量、时效和来源独立性。`ALL`、`ANY` 和 `K_OF_N` 分别要求满足全部槽、至少一槽和至少 K 个不同槽。每个槽的见证份数和共享来源额度由模板确定。同一关联来源的观测按模板规定计数。证据提交结果与功能通过结果分别记录，充分且合格的阻塞证据可以得到 `ACCEPTED / FAIL`。

最小充分复核规划（Minimum Sufficient Reinspection Planning，MSRP）在限定的有限候选路线集合中，逐条核验权限、安全、时窗、资源预算及可分配的证据见证。路线包含移动、等待、采样及结束路段。已有合格证据可以分配给槽。已证可行方案按总时长、总能耗、稳定候选 ID 依次比较。

| 结果 | 判据 |
| --- | --- |
| `FEASIBLE` | 至少一条完整候选路线具备可核验的证据分配，且满足全部硬约束。成本比较未闭合时注明最优性待证。 |
| `INFEASIBLE` | 候选域完整，并能证明其中没有能够同时满足证据要求和硬约束的路线。 |
| `UNKNOWN` | 目前没有已证可行解，候选覆盖、产证资格或独立性仍不足以证明无解。 |

执行后用实际证据重做验收。充分证据支持功能通过或未通过，缺证据或实质冲突保留未决。局部恢复按单元与功能分开登记。新反证、证据撤销或关键版本变化可触发失效与重开。

## R3 任务条件下的空间可用性

读取机器人无关的功能状态投影，然后结合当前管理许可、能力配置、任务、路径和预计占用时窗判断。关键依据的适用区间须覆盖相关使用时窗。禁止、受阻、待复核、条件可用、可用分别表达不同依据。附加条件必须可以执行，软代价用于比较已满足硬约束的方案。区域聚合的 `PARTIAL` 保留在区域层级。
