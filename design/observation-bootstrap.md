# D06 安全观测启动与无告警发现

设计日期：2026-11-19。范围为一条受控通道、一个指定机器人配置、有限观测位置与动作、一次一个义务修订的规划。D06 选定“事前授权的定时核验底线＋可见线索触发的提前复核”，补齐异常尚未登记时的启动入口。这里完成的是逻辑模型与纸面推演，安全初始依据、观测质量及持续性仍须有独立材料；没有据此宣称已能在真实校园安全运行。

## 1. 采用的范围与启动事实

纯粹等待异常通知会遗漏没有人报告的变化；只靠证据过期触发，在首次没有证据或旧证据尚未过期时也不足。首轮因此采用固定周期、固定相位的核验底线，外部报告、S3 差异与适用的证据失效可在空闲窗口提前触发。首轮不按刚观测到的异常起点重置时钟，也不通过进入未知目标区寻找观测位置。

有权主体在监测开始前提交核验请求，经 S1 形成可追溯的输入事实。请求固定目标/要求、监测区间、周期与相位、可用来源、允许的观测路线和预算。缺少真实请求/来源/授权时不启动派工，按原准入规则留下缺口；试验中的请求是显式给定的条件，不冒称已有校园许可。

现有 MET 要求先有 Event 才生成 Obligation。D06 保留该链路，在现有 ADMINISTRATIVE 事件族中采用“计划核验请求到达执行时点”的领域语义：业务事实是有权要求检查，并不声称有障碍。它是本轮研究采用的目录项语义，正式 type_id、Schema 与注册签发仍由原 Owner 处理，不在此增加另一套事件主对象。

每个计划时点由 S4 对原请求和固定时钟形成一个请求 occurrence，经规则登记行政 Event，再生成该窗口的净宽验证义务。沿用已有 Requirement、D02 模板及证据验收；观测前的净宽与现场异常均未预填。请求键为

$$
K_{\rm req}=(request\_ref,\ policy\_revision,\ cycle\_index,\ target,\ requirement\_revision).
$$

同一键重放只关联同一请求/事件，不产生额外 Task；它不是新的 Wire 字段定义。Obligation 仍使用现有 Event、scope、function、requirement 及其修订构成身份。不同周期的业务窗口不同，不能为了去重把新窗口偷偷并入旧结论。同一计划批次已失败或超时，其实耗和结果随历史保留。

物理观测若满足异常规则，S3 提交差异候选，S4 再登记或关联真正的异常 Event。既有义务只有在谓词、范围、版本、业务窗口及模板确实匹配时才可复用；无关联依据时不得用行政 Event 或一次检查完成代表异常已解决。周期请求的数量不进入真实异常分母。检查任务成功、行政请求处理完成、净宽 PASS/FAIL 和异常关闭各按原判据记录；到监测期末仍未解决的义务须明确续办/转交或按有权取消政策处理，不能批量改成已通过。

请求义务所引用的范围由 S2 以本轮明确采用的“直达请求目标”策略计算，S4 保存对应范围记录：仅包含请求指定且已绑定的功能要求目标，不把计划时点当作物理变化沿图传播。该策略作为请求 Event 的 Impact Policy 进入现有范围登记流程。真正异常到达后再按 D01 的属性/功能依赖闭包重算；请求目标无法锚定时仍需先解决作用域，不能用空范围完成义务。

## 2. 安全初始依据与观测关系

### 2.1 首轮空间选择

每个场景显式给出已具备独立依据的观察站/接近区域 $A_0$、允许停留和结束位置、其支持的时间窗及当前权限。目标通道为 $X$。首轮采证路线的机器人、机械机构及必要操作扫掠范围始终留在已核验区域内；可以从边界观察 $X$，不能因为地图画出了通路就进入 $X$。

安全依据至少绑定 S2 地图/变换、S3 已有事实、S6 Profile/本地安全条件、S7 对观测用途的判断及有效窗口。依据来自独立现场确认或先前已验收的记录，不能引用本次尚待取得的净宽结果。受控观察站的存在是首轮输入假设；对从未核验的起点，模型输出缺少启动依据，而非凭名称给它安全属性。

观测和通行是两个不同请求：站在保护区外测量未知通道可以有独立依据，穿过同一通道执行运输仍可能 PENDING。观测用途的准入不得被复用为运输用途许可。

### 2.2 有限路线的三值资格

对固定知识切点 $k$、目标 $u$ 及完整采证路线 $p$ 定义：

| 项 | T 所需依据 | F 与 ? 的区别 |
| --- | --- | --- |
| $Exec(p,k)$ | 到达、等待、采样、结束与退避安排均满足相应权限、能力、风险、时窗和资源；依据不依赖本轮未得结论 | 已证禁入/能力不满足为 F；缺少或过期证明为 ?，不能据此断言物理不可达 |
| $Obs(p,u,k)$ | 实际可视/可测范围、遮挡、测量高度带、距离/分辨率、变换与来源资格可支持 S4 指定的采证目标 | 已证视线完全遮挡或量程不足为 F；仅有名义视场或定位不明为 ? |
| $Slots(p,u,k)$ | 按 D02/D03 可取得或复用足够且联合可分配的见证；包含外部来源时供给安排明确 | 已证共因/槽位不符为 F；独立性或供给未证为 ? |

令

$$
A^-(u,k)=\{p:Exec=Obs=Slots=T\},\qquad
A^+(u,k)=\{p:Exec,Obs,Slots\ne F\}.
$$

二者使用同一有限生成域；$A^+$ 仅是可能性上界。$A^-\ne\varnothing$ 支持采证可行；它不保证实测必能判到阈值一侧。只有域覆盖完整且 $A^+=\varnothing$，或有覆盖全域的共同排除证明，才能说在声明的观测手段内无可行采证路线。目录不完整或资格未知时仍为 UNKNOWN。此处无解不等于通道 BLOCKED，也不排除日后由有权人员采用域外手段。

资格按真实观测域检查；名义视场覆盖目标，不证明障碍出现后的遮挡条件仍允许全域测量。预期与实得覆盖不同要交回 S4 为未决/部分证据，不能沿用计划资格宣称 PASS。一个合格局部反例可以触发差异候选，但正式 FAIL 仍须满足两份独立见证的共同反例要求。

### 2.3 防止循环依据

派工时，安全证明的依赖图必须已落到可读的先前事实，不能含当前计划待产出的证据；对同批两个计划也不能互相假设对方尚未得到的结果。首轮只允许固定的 $A_0$ 观测域，不因本轮通道净宽 PASS 自动扩展观测可进入范围。范围变化需另行核验并形成后继监测配置，原窗口结果保留。

S6 在执行前及执行中继续独立核验本地条件。旧许可过期、位置不明或突发危险时，停止当前采证并采用既有可执行的本地安全策略；RETURN 也必须有合法路线，不能默认穿过未知区域返航。已消耗资源照记。该模型证明的是“不以待证结论为派工依据”，真实安全还取决于输入依据及本地防护是否有效。

## 3. 固定监测底线与提前复核

设监测期为 $[t_0,t_1)$，核验起点为

$$
s_n=t_0+\phi+nP,\qquad 0\le\phi<P,\quad P>0.
$$

只在监测开始前登记的有限时点尝试核验，保存周期 $P$、相位 $\phi$、预留时间 $b<P$、观测/交付延迟上界及各时段能耗预算。末端不足以完成整条路线的时点明确记为无完整机会，不补称已覆盖；真实变化仍按总体协议入组。

首轮底线采用 D02 所需的完整合格采证安排，不假定额外存在免费的廉价探测器。已存在的固定传感器或外部报告可作为补充来源，但须有准入、费用和同等对照安排。没有异常线索的时段也执行底线，并保留“有合格观测但未发现差异”与“没有合格观测”的区别。

| 可见触发 | 固定处理 |
| --- | --- |
| $s_n$ 到达 | S4 核验事前请求并生成/关联该 occurrence 的 Event 与义务；S5 在预留时段内核验完整路线，已有证据可依法复用，但首轮不取消或推迟周期观测机会 |
| 合格人工/外部报告、S3 差异 | 按 MET 准入登记或关联异常，匹配原义务或生成精确窗口义务；空闲资源允许时提前复核 |
| 当前决策依赖的证据失效 | 按原失效规则重评；满足事件规则才登记证据完整性 Event，不能把过期当作物理异常 |
| 无当前依赖的低风险过期、无观测/无消息 | 保留状态和质量缺口；无消息不证明无变化，既定周期继续 |
| 重复回执/同源重算 | 幂等关联，不产生新机会、不刷新物理证据时间 |

提前复核只能占用周期预留之外的时段；整条路线连同必要结束动作的耗时上界必须能在下一预留开始前结束，并满足原截止和预算。安全处置始终优先，但抢占或故障造成周期缺席时必须记为监测缺口，相应发现时延承诺暂停。不能一边不断处理告警，一边声称周期底线仍受保障。

同一空闲段内的多个适用请求先按既有安全优先级，再按最早截止、请求可见时刻和稳定 ID 排序；逐次调用 D03，一次只派发一条完整路线。无法安排的请求保留等待/转交原因。D09 后续处理结果未决后的多轮行动选择，不得回改本轮已固定的监测时钟。

在没有新的完整观测时，后续任务按 [D07](spatiotemporal-support.md) 的几何包络、受控保持与 E5 的完整用途门禁判断。周期小于有效期不自动说明连续覆盖；相位和支持窗不能由旧 TTL 反推。

## 4. 条件性发现时延与不可解决边界

令 $t_*$ 为只对独立评分者可见的真实变化起点，$t_c$ 为 S3 形成合格差异候选的时刻。声明以下前提：

1. 下一个 $s_n\ge t_*$ 存在，且完整观测与处理能在监测期内完成；相邻合格起点间隔不超过 $P$。
2. 对声明的挑战类别，变化在下一轮实际观测期间持续存在，满足已固定的可观测与检测分离条件。包括遮挡、误差界与相对阈值裕量；不能把任意微小变化都列为确定可探测。
3. 完整观测在 $d_o$ 内产生相应资料，接入至 S3 候选的延迟不超过 $d_c$；权限、质量、独立安全依据和资源在该轮仍成立。

则由 $s_n-t_*\le P$ 得

$$
t_c-t_*\le P+d_o+d_c.
$$

这是给定有效观测/识别前提下的推导，不是已测得的性能，也不包含 S4 正式验收与 S7 允许时间。外部可见线索可以提前触发，但不进入该无告警保证的必要假设。正式确认还需要实际证据、槽位、时态与 S4 判断。

若观测/检测资格只有统计保证，须按 [D08 联合可靠性](joint-evidence-guarantee.md) 对实际取数与整段过程建立有效同时保证，再给概率性时延主张；确定性主线也必须逐项具备真实适用依据。若变化在两次观测之间出现又消失，或只有穿过未知区才能看见，以上前提不成立。它仍可能是总体漏检，不能删出测试分母，也不能把一次没看到转换为“没有发生”。

安全侧完全不可观测的目标，先查是否有已授权且实际可用的替代来源；没有则保留未知、明确外部复核所需条件与最晚响应/截止。转交有权人员只是任务交接，人员也需自己的访问与测量依据。交接受理不等于完成复核，更不等于通道恢复。完全相同的可见输入既兼容“无障碍世界”也兼容“隐藏障碍世界”时，系统无法仅靠这些输入作确定区分；等待是该边界下的合法结果。

## 5. 三条贯通场景

以下时间为相对监测开始的分钟、能量为 Wh，均是纸面给定值。$P=10,\phi=0,b=3$，观测路线均从已独立核验的保护区出发并在 2 分钟内完成，全部采集和候选处理在 0.2 分钟内可读。观察站与未知通道空间分离；两份净宽见证的资格和独立性在相应例中作为已核验条件。任务运输用途不因此获得许可。

### 场景 A：有外部报告，提前复核

| 时点 | 已知事实及行动 | 结果与责任 |
| --- | --- | --- |
| 0 | 事前授权请求启动；行政 Event/净宽义务和周期观测按 0、10、20…登记 | 没有宣称物理异常；初始资料不支持未来全部时段 |
| 4 | 有权来源的障碍报告经过 S1，在 S4 准入，S3 尚无新净宽测量 | S4 登记/关联异常与指定验证窗口；报告不能直接成为 S4 PASS/FAIL |
| 4—6 | 独立保护区路线满足全部门禁，可在下次 10 时预留前结束；S5 选路、S4 创建 Task、S6 再校验 | 复核无需穿越未知通道，产生两份共同断面的合格反证；路耗 1.2 Wh |

## 6. 成本、公平比较与评分

总能耗以同一监测期内互不重叠的实际执行记录核算：

$$
E_{\rm total}=E_{\rm background}+E_{\rm triggered}
+E_{\rm idle/source}+E_{\rm failed}.
$$

每一焦耳只能归入一个能耗类别；失败路线从其原类别移入失败项而不再次相加。人工、固定传感器、外部取得资料及非机器人能源分项记录，不能隐去。提前复核与周期核验依法共用一份实际证据时只记一次采集成本，但并不证明对两个窗口都有效。

例如 30 分钟内三次底线采证各 1.2 Wh，额外提前采证 1.2 Wh，待机/来源 0.6 Wh，总计为 5.4 Wh。没有提前采证的 B0 若同为三次及相同待机条件，总计 4.2 Wh。方法可能更快而更费电，是否满足总体非劣界由预定协议判断，不能把主动复核定义成天然节能。

首轮集成主比较为相同 $P,\phi$、初始依据、外部信息可得性、动作能力、验收条件和总预算下，“周期底线＋提前复核”对“固定周期 B0”。B0 也能接收报告并更新判断，但主动采集按其预先固定时点进行；紧急安全处置对两者相同。两者各自获得自己实际动作的测量，不把方法刚采的新数据无成本塞给 B0。若把周期/刷新优化作为研究因素，应另预注册共同延迟约束、参数选择和预算，不能在测试后改变主比较。

新增的记录是：实际观测机会及缺席原因、首次合格线索时刻、无告警发现延迟、无变化时段成本、保护区外越权尝试、外部转交及截止未决。总体沿原始真实变化分母计首次正确确认与漏检，行政 Event 数不能增加样本量。无告警分层在测试前定义；外部报告事后到达不把该事件从无告警组移除。论文中的发现保证只适用于预先声明的可观测类别，其余事件仍进入总体效果评价。

## 7. 边界核对与完成条件

| 编号 | 反例/边界 | 必须保留的结果 |
| --- | --- | --- |
| D06-01 | 无事前请求或来源授权 | 不自发登记虚构请求或派工；记录启动缺口 |
| D06-02 | 同一周期请求重放十次 | 一个 occurrence 与义务/派工链；不增加观测、独立样本或预算 |
| D06-03 | 借用本轮待测净宽证明可到达测点，或两个计划互相担保 | 排除循环派工依据；已有独立依据不足则 UNKNOWN |
| D06-04 | 传感器名义视场完整，但新障碍遮住下游 | 实际覆盖缩小；不得借计划全域覆盖验收 PASS |
| D06-05 | 一个测量来源可用，第二份来源/独立性未证 | 可以记录合格候选；D02 正式验收仍未决，不能把发现延迟当确认延迟 |
| D06-06 | 提前任务可能越过下一周期预留；或紧急处置抢占周期 | 前者不按当前时段准入；后者记监测缺席并撤回相应有界发现承诺 |
| D06-07 | 观测安全依据执行前失效，或返航也须穿未知区 | S6 不继续依赖旧许可；采用已具依据的本地安全策略，不默认 RETURN 安全 |
| D06-08 | 变化在两轮之间出现并消失，或发生在监测结束附近 | 不满足持续/完整机会前提，仍进入总体未发现/未确认及截止口径 |
| D06-09 | 周期测量支持过去窗口，S7 请求未来通行 | 分别核验；周期观测和小 TTL 不提供未来保证，按 D07 的独立保持依据检查 |
| D06-10 | 外部受理但未交付，或外部记录仅能填一个槽 | 仍有缺口；费用与等待如实记账，不将转交当作验收 |
| D06-11 | 新计划周期与旧窗口不同，复用同一原始测量 | 仅在实际支持覆盖且谓词/版本/模板匹配时复用；身份或来源去重不改变时空适用性 |

D06 的领域选择、三值观测关系、防循环约束、调度准入、条件性时延推导、三条贯通场景、十一项边界与公平成本已在设计层给出。输入假设不满足时有明确结果及后续入口，不能以“总会有人提供证据”补足活性证明。

D07 的空间包络与受控时间支撑、D08 的联合可靠性均已完成限定设计；后续为 D09（多轮结果反馈策略）、D10（地图误差消费实例）。模型选择完成不等于已取得真实观测资格；D06 规定这些资格如何被消费和缺失时如何处理。
