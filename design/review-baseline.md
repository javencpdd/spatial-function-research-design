# 研究设计基线终审

审阅日期为 2026-11-18。范围覆盖 D01—D04 的通道类模型、跨模块语义与实验设计，按单个义务修订及一个已选能力配置展开。本文件记录三个完整场景和研究主张的验证入口。结论为本轮限定研究设计复核通过：已完成局部规则、公式、纸面场景和报告的对齐，可按设计准备后续实验。该结论不替代正式契约签发、实测标定、研究效果或系统准入证据。

## 2. 三个完整场景

以下均为纸面推演。地图 M1、图 G1、要求 R1、策略 Π1、标定 C1 相容，域 X 为完整受控通道，要求净宽至少 1.00 m，风险条件和主体能力按各步已核验输入固定。时间为示例分钟，证据有效窗口及所支持的实际状态区间均已明确。证据采集来自各自独立且适用的来源，表中修订号和水位仅作演示。S3 投影的应用证明需覆盖对应 S4 修订，不能只比较裸序号。

## 3. 跨模块边界终审

| 边界检查 | 本轮采用的判据与复核依据 |
| --- | --- |
| 部分覆盖 | 西半段合格仅支持其明确子域。D02 的全域通过模板仍需两份各自完整覆盖的见证。全路径包含缺口时为 PENDING。 |
| 独立性未知 | 确定分配排除未证独立的组合，乐观分配保留可能性。未知可导致补证或 UNKNOWN，见 D02 E02、D03 案例 12。 |
| 双端有效时间 | 必要依据的适用交集须包含实际占用窗口。例如 [10,20)∩[12,18)=[12,18)，无法支持 [11,16)。历史证据的年龄与未来状态支撑分别核查。 |
| 旧投影失效 | 相关 S4 变更未应用或必要前因覆盖未知时，旧 p4 无法支持当前用途。作用域明确不相交的变化可保留兼容结论，需保存不相交依据。 |
| 风险界 | 同一风险语义及适用时窗内，可证概率上界 0.04 与 0.05 的并集上界为 0.09。预算若为 0.08，该上界不足以证明合规，缺少其他合格依据时 PENDING。已证物理障碍或管理禁令各有自身判据。 |
| 反馈与版本 | S4 评价进入后继 S3 投影，S7 引用已经存在且已提交的修订。每次反馈固定新的知识切点，保留历史 ReadSet。 |
| 模型和实验目标 | D01 的范围是复核相关性，D02 判断实际内容，D03 规划有资格的采证路线。D04 分别设置相关性真值、采证与业务确认指标。 |
