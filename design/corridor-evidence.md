# D02 通道净宽的证据充分性与有效期

本设计供首轮受控通道研究使用。每次评价固定一个验证义务修订、一段具有明确横断面的走廊及一个任务情景。实验可选定一个 RobotProfile。S4 评价的净宽标准来自 S2 要求目录，S7 再依据具体机器人、任务和预计占用时段判定可用性。

## 1. 将 D01 的目标落实到可测要求

对于 D01 到达的功能要求目标 `F(u,passage,r)`，S4 冻结要求、义务与模板修订，确定该要求适用的 Cell、通道方向、横断面范围、测量高度带和验证窗口。`P(c,clear_width)` 可以直接关联净宽要求。障碍变化可在目录有显式映射时触发净宽复核，源观测仍需通过净宽证据门禁。若上层功能要求也被 D01 到达，按上层要求选择相应模板。未知作用域或缺少属性映射时，记录缺口并优先解决定位或要求绑定。一个通道义务只覆盖自身窗口及范围，版本变化按 D01 重锚定。

| 项目 | 冻结定义 |
| --- | --- |
| 净宽 $W(x,t)$，单位 m | 在指定横断面位置 $x$、业务时点 $t$，沿规定横向搜索范围取最大连续净空带的宽度。该带须在要求指定的高度范围内无障碍。$W$ 是物理量，观测提供其上下界 $[\ell,u]$。采用其他净宽定义的要求需另行绑定。 |
| 最低净宽 $w_{req}$，单位 m | 精确引用 S2 Requirement Snapshot。标准按机器人无关的功能要求表达。首轮仅检查净宽维度，S7 另核对实际包络、路径连续性、转弯、地面、许可与风险。 |
| 目标域 $D=X\times J$ | $X$ 是义务声明的通道位置范围，$J=[a,b)$ 是连续验证窗口。必要时按空间和时间边界细分。允许以单时点评价的模板显式声明瞬时用途，不能直接用于连续窗口。 |
| 业务谓词 $P$ | 对持续窗口，$P\equiv \forall(x,t)\in D,\ W(x,t)\ge w_{req}$。要支持成立，需覆盖全域并证明下界达标。要否定它，可以在同一适用的局部断面与时段证明上界低于要求。 |
| 采证任务范围 | 受控直通道、固定功能方向和一个任务情景，固定坐标、单位和断面定义。湿滑、承载、坡度等属性分别按自身要求复核。需要分支选路或通道高度复杂变化时，重选要求和模型。 |

一个证据即使能证明某处有障碍，也要先核实该障碍是否会使目标断面的可用宽度上界低于标准。例如，只看见障碍占据左侧而右侧未测，可能既无法判断全段通过，也无法证明存在瓶颈。

## 2. 证据槽与几何、时间资格

首轮采用一个 `2-of-3` 证据组。三个槽为可替换测量方法，分别为经标定的距离扫描、可测距的深度或多视几何、独立测量作业。每槽最少一份见证。需要证明同一结论的两个槽所用见证在声明的失效机制下相互独立。实际设备、测量作业和允许用法在实验前绑定。单张普通照片、未经尺度验证的视觉估计或原始执行回执仅可用于提示补证。

| 门禁 | 通过要求 | 缺失或不合格时 |
| --- | --- | --- |
| 身份与适用性 | 核验 Evidence/Artifact、来源授权、目标要求与用途、明确空间范围、CRS/单位及版本。保存来源、修订与追溯引用。 | 明确错对象、错单位、破损或未经授权的证据拒绝使用。需要补查的关联保留未决。 |
| 可探测性与空间覆盖 | 用实际可见、可测且误差在预算内的空间范围计算合格覆盖。通过见证需支持全域 $D$ 上所需宽度下界。失败见证需支持共同反例位置的宽度上界。 | 遮挡或配准未知时缺口保留。局部测量可用于其支撑范围。全段通过要求所选见证各自具有完整覆盖，可在一个见证内部拼接经核验的子域。 |
| 测量质量 | 首轮按 D08 以有界误差集合覆盖实际状态，保守传播标定、模型、配准及共享误差；按 D07 为整个声明子域导出内外包络。统计材料须另满足其目标与联合覆盖准入。 | 均值置信区间或经验最大残差不直接充当实际状态的绝对界；未知几何/时间/共因前提保留缺口。 |
| 时间适用性 | 使用可信的采样时点不确定区间，与标定、关联、变换、模板及证据有效期求交，记录范围与时间的联合覆盖。按用途核查时效、连续覆盖和已知失效事件。 | 缺采样时点、时钟偏移未界定、覆盖断点或过期会使相应证据无法填槽。晚到记录按真实观测及提交时点处理。 |
| 内容支持 | 质量通过后读区间和位置。$\ell\ge w_{req}$ 支持该子域达标，$u<w_{req}$ 支持该子域不达标，其余区间不足以确定方向。 | 可接受的测量质量仍可能只提供区间，保留关键阈值未决及补测需求。 |

以下证据规则分别在同一个义务上评价通过和失败两个方向。

- **通过见证。** 一个见证可由同一测量作业的多帧或分段记录组成。每个子域使用可审查的下界，合格子域在空间和时间联合域上的并集须覆盖 $D$。如果一份见证只覆盖西侧且另一份只覆盖东侧，它们可以为后续补测提供依据，但本模板仍需要两份各自覆盖全域的见证。
- **失败见证。** 先在 $D$ 内定位一个共同反例点或明确反例子域。同组所选独立见证必须在重合的空间与时间内支持同一个反例，即该点或子域的 $u<w_{req}$。不同断面或互不重合的时段分别登记并继续复核。该选择便于独立重测同一缺陷。
- **冲突。** 对适用同一范围、同一时间和同一要求的合格证据，若存在明确且实质的相反支持，保留双方及冲突依据并进入复核。不能通过丢弃相反的合格证据来允许通过。不同时间的真实变化要先分段，不自动认作同一时点冲突。

`2-of-3` 是本研究模板选择，便于替换测量方法并复算已有 MSRP 小例。独立见证只控制已声明的共因；预实验用于检查适用性，实际误差界仍须有覆盖声明域的独立依据，不能仅以样本最大残差证明。若后续改用分段覆盖或其他阈值，须冻结新模板并用同一实验口径重评。

联合可靠性按 [D08 联合可靠性](joint-evidence-guarantee.md) 核验：每槽先有自身的全域支持，共享依赖只登记一次但不消除其影响；不得把两份区间交集回填为两份独立证明。误差集合为空时按冲突处理，两份见证合格不自动允许错误概率相乘。统计覆盖、实际状态误差和实验效应的置信预算分别记录。

## 3. 槽位计数与来源独立性

对某次评价、同一内容方向及目标域，固定证据和槽之间的资格。$z_{se}\in\{0,1\}$ 表示把见证 $e$ 分配给槽 $s$，$y_s\in\{0,1\}$ 表示该槽满足。模板指定槽内见证数 $d_s$，要求 $\sum_e z_{se}=d_sy_s$，选中的每一对 $(s,e)$ 必须通过对应门禁。组内满足的不同槽数为 $\sum_s y_s$。`ALL`、`ANY`、`K_OF_N` 对非空组分别要求 $N$、$1$、$K$ 个槽，显式必填槽必须单独满足。首轮活跃组要求 $1\le K\le N$ 且 $d_s\ge1$。联合义务含多个必需组时，使用同一份分配检查所有组及跨组额度。

见证绑定原始采集链、设备、作业、位置、时间、标定/配准来源和已知共同故障。原始记录重复、裁剪或多模型重算统一关联到原采集链。不同设备若使用同一失效的标定或配准、共享遮挡条件或复用同一生成数据，仍可能具有共同原因。相同地图引用本身不证明共因，需检查该依赖是否能共同改变本结论。

- 已知共因的见证分到同一受限组。可针对多种共因分别检查额度，同一证据可属于多个约束组。共享原始项的重复提交不增加见证数。
- 首轮模板对组内同一见证和同一已知共因均设上限 1。成对独立性依据由冻结的关联策略提供，记录不同的采集与误差来源，以及对共享误差的独立检查。不同设备、模态、文件名或不同组 ID 单独使用均不足以证明独立。
- 相关性未知的组合只进入可能分配。孤立的合格见证仍可填一个槽。已知不能同时满足的组合在确定和可能分配中均排除。

对单组可算确定最大槽数 $L$，若候选清单有完整性依据，再算含尚可能合格见证和组合的乐观上界 $U$。$L\ge K$ 可证明单组数量达标，还须核查其他条件。$L<K\le U$ 保留未决。$U<K$ 只证明本次证据不足以填齐槽位。缺候选完整性依据时，上界仅描述已知输入，不能排除尚未收录的候选。多组分别达标也可能争用同一见证，验收必须展示一份同时满足各组和共享额度的分配。该计数与业务谓词的真假分开保存。

## 4. 时间、失效与职责

采样时点、业务有效时间、录入时间、证据评价时点和预计使用时段单独保存。若采样时点落在可信区间 $[t^-,t^+]$，应检查整个采样区间与各采样资格区间的一致性，以及 $t^+\le t_{eval}$。首轮验收采用属性级硬过期，以 $t^-$ 计算保守年龄。用于当前判定的期限截止不晚于 $t^-+T_{fresh}$，适用区间同时受来源、标定、配准、要求、事件及模板限制。评价时点等于当前有效截止端时已过期。晚到证据进入新的知识切点，回读旧裁决时按旧切点和原用途解释。超过可证明的状态支撑窗口时，即使证据仍新鲜，也缺少连续或未来状态依据。

把各测量的实际覆盖、可信时段和支持方向组合为对空间与时间联合域的有效证明。连续观测、经核验可保持的状态区间、或模板明确允许且已标定的预测才能支持跨时点断言。合格覆盖片段之间无间隙时可连接。证据 2 分钟加 2 分钟，中间有缺口时无法满足一个连续 4 分钟窗口。

首轮具体采用 [D07 的有限保守几何包络与受控保持区间](spatiotemporal-support.md)。外包络须包含全部可能障碍及未知体积，不能只插值已测断面；连续/未来支撑来自独立的物理保持依据，管理许可或 TTL 本身不够。采样时刻位于某误差区间，不等于该区间内每一时点都被观测。保持起止有误差时先收缩到保证区间，再检查各见证覆盖与任务结束操作。开放动态预测保留为后续分支。

S4 同时记录本次提交与业务判定。

| 条件 | 提交结果与业务判定 |
| --- | --- |
| 接收条件通过，有全域达标见证分配，且无未解决的实质冲突 | `ACCEPTED / PASS` |
| 接收条件通过，有共同反例的充分见证分配，且无未解决的实质冲突 | `ACCEPTED / FAIL` |
| 缺槽、可见范围不足、关键时态不确定，或实质冲突 | `INCONCLUSIVE / NOT_DETERMINED`。保留合格证据和未决理由。 |
| 提交违反适用的硬准入规则，且按策略需要拒收该提交 | `REJECTED / NOT_DETERMINED`。单个不合格制品按条目记录，其他证据仍按提交策略核查。 |

评价保存精确义务、要求、模板和证据策略修订，关联合格/拒用依据、覆盖区间、见证分配、冲突、具体缺口与理由。S3 管观测、证据及状态投影，S4 管验收和义务修订。读取者使用可核验的 S4 两轴记录。QBR-032 旧汇总无法还原两轴，后继候选按 FS-01 §11 使用绑定的 findings。

| 变化 | 当前处理 |
| --- | --- |
| 过期、来源撤销、Hash 或时间纠错、标定或变换不可用 | 取消受影响见证的当前适用性，对剩余证据重新分配。旧结论失去必要支撑时，S4 追加重评或重开修订，保留旧版供历史精确读取。 |
| 同域新反证、遮挡更正、来源改判为共因、新事件改变状态 | 仅对相交或适用性不确定的目标重评。真实状态变化按有效时间划分。旧通过无法继续用于受影响的当前窗口时，生成失效依据。 |
| 地图、CellLineage、变换、关联、要求或模板变更 | 验证兼容性与证据适用性。改变空间支持时重新锚定。要求版本变化按原生命周期处理旧义务及新义务，禁止把旧通过直接用于新版谓词。 |
| S7 使用阶段 | 核验投影已应用与本查询范围有关的 S4 修订。各必要依据的适用时间集合须共同覆盖含时间误差、等待与退出的完整占用窗口。内部空档、旧投影未追平或当前证据未决时，按 S7 规则保留 `PENDING`。有效禁令和已证硬障碍各按自己的判据处理。[D07 时空支持](spatiotemporal-support.md) · [E5 条件查询](../experiments/availability-e5.md) |

当前 PASS 只支持其精确要求、范围和时间。S7 的 `CONDITIONAL` 需要另有经过核验且可执行的限制条件。任务完成回执与规划中的预期产证条件由 S5/S6 提供，S4 评价实际证据。未决后的多轮处理按 [D09 多轮复核策略](multiround-review-policy.md)：不因重试而降低阈值、缩小原域或清除合格冲突；机会为零仍可直接评价新到的合格材料。

[D10 地图消费实例](map-consumption.md) 已明确跨版本复用：原采集链和时间不变，重新计算误差、保证覆盖、用途与槽分配。两端覆盖不足不能用中间达标或 Cell 重叠比例补齐；完整作业先传播再裁剪，派生文件不增加独立见证。

## 5. 参数、来源和标定

**设计前置（2026-11-20）：** D07 已选定内外包络与受控保持，D08 已选定有界误差集合的联合推导及有限统计家族准入。下表参数须服务于这些模型；一个采样间距、经验时长或样本最大误差不能替代覆盖、保持或误差界的证明。实际数值、来源资格及标定材料仍待取得。

| 参数及单位 | 来源、适用范围和取得方法 | 未定时 |
| --- | --- | --- |
| $w_{req}$、测量高度带及空间范围，m | S2 目录与经核验的现场范围。核对单位、空间版本、测量定义和标准适用域。 | 待补要求或重锚定，保留未决。 |
