# D07 空间覆盖、连续状态与未来时窗支撑

设计日期：2026-11-19。首轮采用“有限保守几何包络＋有独立依据的受控保持区间”。该选择连接 D02 的全域净宽谓词、D06 的安全观测和 E5 的完整占用窗口。离散点之间不作未经证明的平滑插值；证据未过期不等于现场未变化。这里给出条件性数学设计和纸面案例，不宣称已经取得真实几何包络或保持证明。

## 1. 首轮选择与研究范围

| 问题 | 本轮采用 | 采用理由及限制 |
| --- | --- | --- |
| 空间采样间隙 | 对规定高度带内的障碍建立内、外保守集合；未知体积进入外集合。首轮用有限个轴对齐长方体包络表达，按几何边界分段计算净宽。 | 不需要从两端读数猜测中间形状。完整包络仍需覆盖与误差依据；只有点云/断面样本而没有这些依据时，间隙保留未知。 |
| 连续与未来时段 | 在明确受控、相关物理几何保持不变的区间内传播同一几何约束。区间外不延伸。 | 与 E1 区间估计及硬过期相容，能复算保持、变化和解除后的边界。管理禁令、上锁指令或经验 TTL 单独均不构成物理保持证明。 |
| 普通开放校园 | 消费已支持的局部事实；无法取得保持依据时，不据旧测量产生连续/未来正向结论。 | 任意人员/车辆进入、突然落物等不符合本轮保持模型。开放环境预测或有界运动可达集属于后续模型分支，不能由本轮结果外推。 |
| 多次观测 | 按各自知识切点、实际支持域及来源资格组合；不同几何段可有不同界。 | 不能把“两次结果相同”当作两次之间没有变化，也不能因增加帧数获得新独立见证。 |

本轮的未来可用性主张限于受控窗口；开放校园的无约束未来保证仍不成立。可用覆盖不足应在 E5 中体现，而不是把困难查询移出分母。

## 2. 支持记录与三种时间

一个研究用支持记录至少明确以下信息，沿用现有 Evidence、Geometry、Policy/Model/Calibration 和裁决引用，不在此签发新的 Wire Schema。

| 信息 | 含义 |
| --- | --- |
| 目标与几何语义 | 目标/要求/版本，纵向域 X、横向搜索域 Y、高度带 H、坐标及单位；净宽测量与障碍包含规则。 |
| 采样定位 | 真采样时刻的可能区间、空间定位/配准误差、原始作业与见证身份；不把时间误差区间当作连续观测。 |
| 几何约束 | 确定占用内集合、可能占用外集合、未覆盖/未知体积、覆盖依据及适用形状/误差模型。 |
| 物理支持 | 保持条件、物理约束及允许扰动/操作、独立支撑来源、保证起止及已知中断。 |
| 使用资格 | 证据用途、硬过期、撤销与依赖状态、当前读取权限、评价时点及相关策略。 |
| 知识切点 | 何时资料实际可读、采用哪一份不可变修订；晚到事实和更正保留后继修订。 |

三种时间分别判断：

1. **采样时间**：本次读数究竟在哪个可能时点取得。
2. **物理状态支持时间**：哪些时点的现实几何受到这份资料及保持模型的约束。
3. **允许使用时间/资格**：在当前用途和知识切点，能否消费该证据，是否已硬过期或撤销。

使用资格通过不扩大物理支持域。物理保持较长也不能绕过当前用途的过期/撤销规则。历史观察事实不会因为今天过期而变成另一种物理状态；其当前复用、历史回读及迟到验收分别沿既有用途策略处理。

## 3. 从几何包络到全空间净宽

### 3.1 包络的条件与构造

令真实障碍集合为 O，测量见证给出的内、外集合为 $O^-,O^+$。在声明范围内必须有

$$
O^-\subseteq O\subseteq O^+.
$$

内集合表示每一种允许误差解释下都确实占用的部分；外集合包含全部可能占用。未观测、遮挡和未解析对象所在的体积 U 也必须纳入 $O^+$。没有完整性依据时，不能默认为 O 只含已检出的对象。管理物品清单或用于评分的隐藏真值不能充当方法的完整覆盖证明。

先核验坐标、单位、内外包含关系及允许现实集合非空。互相矛盾的包络或反向的外边界属于输入/证据冲突，按既有准入规则处理；不能利用空的可能世界集合推出任意 PASS 或 FAIL。

首轮正例限定为可由有限轴对齐实心长方体内外包络表示的受控直通道。若已知一个真实长方体各轴边界满足

$$
a_j\in[a_j^-,a_j^+],\qquad b_j\in[b_j^-,b_j^+],
$$

则可构造

$$
B^-=\prod_j[a_j^+,b_j^-],\qquad
B^+=\prod_j[a_j^-,b_j^+].
$$

某轴内区间反向时，$B^-=\varnothing$；不能交换端点“修复”成确定占用。多个对象的内、外集合分别取并集，并向外集合加入 U。旋转、空洞、柔性形变、未界定配准或无法控制的表面误差，不能直接套实心长方体边界公式；须另给有效内外包络，否则保留未知。协方差、平均误差或点估计本身不是确定性包络。

包络须同时包括测量、尺度、坐标变换与定位误差；共享误差不能通过两个传感器平均而消失。离散格只作为集合表达工具：把一个体积标为自由必须有覆盖整个体积的依据，格中心未命中障碍不够。具体测量方法能否产出合格包络仍按 D02 独立核验；[D10 地图消费实例](map-consumption.md) 已给出变换后的保证覆盖、净宽及重锚定算例，不替代实际输入资格；[D08 联合可靠性](joint-evidence-guarantee.md) 已规定首轮集合误差传播和统计包络的有限同时覆盖准入；均值置信区间与经验最大残差不直接充当实际状态界。

### 3.2 断面界与有限计算

沿用 D02 的净宽语义：规定高度带 H 内，一条横向净空带必须全高无障碍。对断面 x，将内、外占用集合在 H 内投影到横向轴，记为 $A^-(x),A^+(x)$。令 $g_Y(A)$ 为横向搜索域 Y 去除 A 后的最大连续净空间距，则

$$
\ell(x)=g_Y(A^+(x)),\qquad
u(x)=g_Y(A^-(x)),\qquad
\ell(x)\le W(x)\le u(x).
$$

净空间距按边界距离计；端点接触、余量及实际机器人扫掠由精确要求和 S7 另查，不能从一个宽度数值推出安全通行。

推导依据是集合包含：外集合可能多挡住空间，所以所得净宽只会更保守；内集合可能漏掉真实障碍，所以所得净宽只能作为上界。未知体积进入外集合可能使下界为零，但不能因此判定真实净宽为零。

有限长方体的横断面占用只在其纵向端点处改变；本轮未知体积也须使用有限长方体的保守外覆盖，无法取得时不声称有限分段已穷尽。计算时把内、外集合及未知体积的全部纵向边界加入切分点；逐个开区间和每个边界断面核验，取相应最小下界。开区间内结构相同，代表断面计算来自已证明的几何结构，不是根据观测采样间距作经验插值。边界点不能省略，数值舍入须向保守方向处理。

对全域 PASS，所选每份见证都须满足 $\inf_{x\in X}\ell(x)\ge w_{req}$。对 FAIL，须找到同一适用断面/子域上 $u(x)<w_{req}$ 的反例，并继续满足 D02 的独立槽位要求。总自由宽度相加不等于最大连续净空带，只有左侧障碍观测也不能排除右侧仍有足够通道。

## 4. 从采样时刻到保持区间

### 4.1 保持的物理前提

令 $\Omega=X\times Y\times H$。首轮保持模型对目标几何声明

$$
O(t)\cap\Omega=O(t')\cap\Omega\quad
\text{对同一保持区间内所有 }t,t'.
$$

它需要针对该范围的物理状态保持依据：已核验的初始状态、可引入/移动障碍的全部相关入口和操作、实际约束状态、允许的扰动/动作集合、保持期限及解除/失效条件。行政授权只决定能否执行管理措施，不证明措施已经生效，更不证明措施永不失效。

未来使用只能在当前已具依据的保持模型允许范围内推导。若任务本身会移动障碍、改变相关几何或让其他对象进入，须纳入保持证明或重新分段；不能先按恒定场景允许操作，再忽略操作对场景的改变。机器人自身扫掠及与外部障碍的相互作用继续由 S7/S6 核验。

受控正例可明确给定保持条件及其依据；开放、人车可自由进入、存在未排除的落物/形变等情形不满足此模型。没有消息、传感器正常在线、例行巡检间隔很短、S6 有急停能力，都不单独证明连续保持。独立评分者的“这段确实没变”也不能提前提供给被评价方法。

### 4.2 时间误差与可使用支持域

若保持开始时刻位于 $[a^-,a^+]$、解除时刻位于 $[b^-,b^+]$，且采用开始包含、结束排除语义，则可保证的保持区间取

$$
I=[a^+,b^-).
$$

区间为空时没有这类时间支撑。采样真时刻位于 $[\tau^-,\tau^+]$ 时，只有全部可能采样时点均落入同一有效保持区间，才能将该测量约束迁移至 I；采样横跨状态变化时不能挑一个有利时刻。曝光/扫描过程也须覆盖全部实际采集时段，不把平均读数解释成每一时刻的值。

若没有保持依据，$[\tau^-,\tau^+]$ 仅表示“测量发生在其中某时刻”，不意味着每个时刻都测得同一值。精确瞬时记录可支持其明确时点；有时间歧义的记录保留相应关联缺口。单个瞬时样本不能填满一个有正时长的验证窗口。

每份见证的物理支持域为 $X_e\times I_e$，再按当前用途的有效使用范围、撤销及依赖规则限缩。D02 仍以最早可信采样时刻计算硬过期。对未来用途，实际使用末端不能超过证据策略允许的截止；即使物理保持更长，也不能绕过这一限制。

所有支撑记录及保持证明须在查询知识切点前已可读。保持证明后来补齐，可以支持新切点对相应历史窗口的复核，但不能反向进入过去的查询。若以后得知 11.5 时已发生变化，当前判断应在新修订中限缩支持域；原查询的 ReadSet 保留，按当时可知规则与真实世界分别评分。

## 5. 组合、验收与任务窗口

对每份见证及其合格支持片段，构造达标域与反例域：

$$
D_e^{pass}=\{(x,t)\in X_e\times I_e:\ell_e(x)\ge w_{req}\},
$$

$$
D_e^{fail}=\{(x,t)\in X_e\times I_e:u_e(x)<w_{req}\}.
$$

上式只对当前用途资格通过的片段成立。一个见证内部可拼接其合格片段；跨片段的版本、坐标和语义必须相容。

- **S4 PASS：** 两个独立槽各自的达标片段并集均覆盖原 $D=X\times J$，无未决实质冲突。不能把 A 的西段和 B 的东段合成“两份全域证明”。
- **S4 FAIL：** 两个合格独立槽的反例域在 D 内有明确共同点/子域。两个不重合的坏断面或不重合时段，仍不满足本模板的共同反例要求。
- **时间拼接：** [0,2) 与 [2,4) 在端点语义一致且第二段确实覆盖 2 时可以覆盖 [0,4)；[0,2) 与 [2.1,4) 不能。起止时间存在误差时先按保证区间收缩，再判断包含，不能先拼再忽略误差。
- **共有前提：** 两份见证共用同一个保持/覆盖证明，只能算一份公共依赖，不能因重复引用增加独立性。若共同失效可能同时改变结论且未按现有策略得到独立控制，正式两槽资格保留未决；不能靠两个设备名称宣称独立。D08 已明确共享依赖与联合保证规则；独立槽资格和公共前提仍须分别有依据。
- **S7：** 对同一任务允许的所有执行，收集完整扫掠/占用集合，包含等待、进入、退出及结束操作和时钟误差。它必须被相应几何/时间支持及当前使用资格完整覆盖；路径、机器人包络、许可、风险、S4 验收和投影应用仍须分别通过。

保持截止为 b 且右端排除时，即便占用区间写成 [c,b)，发生在 b 的结束操作也没有获得支持。未来缺口、保持失效或读取未齐通常使正向结论不足；没有另外的合格硬反证，不能转成 BLOCKED。

恒定净宽支持不证明同一条净空带沿路径连续，也不证明机器人转弯、净高、地面和风险合格。D07 不把属性维度的充分证据扩张成完整任务安全证明。

## 6. 一组可复算正例与四个核心场景

以下均为合成纸面条件，宽度为 m、时间为 min，未经实测。取 $X=[0,2]$、$Y=[0,1.4]$，规定高度带全量纳入，净宽要求为 1.00。未列条件均在夹具中明确给定，D02 的独立性和公共前提资格也作为已核验输入，不据此宣称现实已获得这些证明。

**正例：受控保持内的未来用途。** 右侧实心障碍在整个 X 和高度带内连续。A 的障碍左边界位于 [1.06,1.10]，B 位于 [1.04,1.08]，右边界均确定为 1.40；实际可同时取 1.07，两个测量没有实质冲突。无未知体积时，A 的净宽界为 [1.06,1.10]，B 为 [1.04,1.08]。各自完整覆盖 X，并均支持 1.00 的要求。

保持开始误差为 [7.9,8.1]，解除误差为 [14.9,15.1]，因此保证区间是 [8.1,14.9)。A 在 [8.9,9.1]、B 在 [9.15,9.25] 采样；相应记录与保持证明在 9.5 前可读，当前用途硬过期均晚于 14.9。10 时查询未来 [11,14]，包含时钟误差后的实际占用及结束范围为 [10.9,14.1]，完整落在支持域内。若原路径、含余量包络 1.03、许可/风险及 S4/S3 应用等条件也均通过，则该请求可 AVAILABLE。净宽 PASS 本身仍只证明原属性要求。

| 核心场景 | 已知条件 | 结论 |
| --- | --- | --- |
| 采样间隐藏窄障碍 | x=0 与 x=1 的断面读数均为 1.20，中间 [0.49,0.51] 未覆盖，可存在使净宽仅 0.80 的障碍。 | 两端不能支持全域 PASS。未知体积加入外包络，相关下界不足；若补测给两个槽在 x=0.5 的共同反例上界 0.82、0.81，才可按模板 FAIL。 |
| 测后突然变化 | 查询前历史完全相同，一个允许世界在 11 时落物，另一个没有；方法没有能排除该变化的保持依据。 | 不能仅用旧测量或 TTL 对含 11 时之后的任务作正向允许。若此前给出无条件允许，应按相应世界及证明参考记错。 |
| 受控保持 | 使用上述正例的完整物理保持、包络、来源与知识切点。 | 允许在 [8.1,14.9) 内组合支持；数值界和未来结论都依赖明确前提。 |
| 超出支持窗口 | 同一正例，但实际结束操作可能发生在 14.9 或 15。 | 相关正向证明不足，PENDING；不能用解除时刻可能较晚的 15.1 绕过保证截止。 |

## 7. 十二项纸面边界核对

| 编号 | 边界 | 必须得到的解释 |
| --- | --- | --- |
| D07-01 | 两个采样断面达标，中间未观察 | 保留未知体积；不得由端点插值宣称全域达标 |
| D07-02 | 障碍包络只在某纵向边界断面产生瓶颈 | 有限分段须核查边界断面，不能仅检查开区间代表点 |
| D07-03 | 一帧测量仍在 TTL 内，无保持证明 | 可按精确瞬时用途处理，不能据此支持连续/未来窗口 |
| D07-04 | 两种未来在查询前不可区分，其中一种会落物 | 无物理保持前提时不能排除危险未来，保留待定 |
| D07-05 | 正例的保证区间、独立见证、未来占用全部适配 | 属性可 PASS，其他任务条件也齐全时才可 AVAILABLE |
| D07-06 | 结束操作恰在右开截止端，或退出时钟区间跨端点 | 正向任务证明不足，不用半开写法遗漏结束操作 |
| D07-07 | 采样时刻可能在变化前也可能在变化后 | 时间误差不等于连续覆盖；不得挑选有利采样时刻 |
| D07-08 | 两段支持间有空白，或名义接壤但时间误差收缩后有缝 | 原连续窗口未覆盖；先收缩到保证区间再拼接 |
| D07-09 | 12 时才获知 11.5 时保持已破坏 | 新切点限缩当前支持，旧 ReadSet 保留；真实世界错误不能靠迟到免责，规则符合与世界正确分别评分 |
| D07-10 | 物理保持证明失效，但没有新的障碍反证 | 撤回受影响的正向支撑，不能仅因此验收 FAIL 或返回 BLOCKED |
| D07-11 | 两个设备共用一份存在未控制共因的保持/覆盖证明 | 不能计成两次独立保证；槽位资格及整链预算待核验 |
| D07-12 | 各断面都有足够宽度，但宽带在空间不连续，或超出首轮几何模型 | 净宽信息保留；路径/模型资格不足时 S7 不允许，不能用数值宽度代替完整扫掠核验 |

这些案例验证逻辑边界，不提供总体风险概率。有限分段与区间算例可独立复算；测量模型本身是否有效，仍需独立标定和覆盖材料。

## 8. 对实验和后续设计的交接

E1 沿用区间估计和硬过期，并显式使用上述支持域；保持模型内的确定性迁移不等于概率预测。E4 恢复必须重新取得对应窗口的有效支持，旧/新保持区间之间的空白不能被关闭或重开记录填平。E5 正例固定保持前提，反例加入未受控跳变、时钟误差、截止端与迟到破坏；所有方法使用同样可见的依据和同样的入组范围。开放且不具保持条件的查询仍保留在预先定义的相应评价层；不能只挑受控正例宣称校园普适效果。

D06 的观察站/路线安全和定时核验也不能仅靠旧 TTL 延续：需要对相关范围独立取得所用支持机制及执行依据。候选发现时延与 S4 确认、S7 允许继续分别评价。

D07 已选定空间包络和受控时间保持机制、给出推导与失效规则，并完成四个核心场景和十二项边界。数据不足时保留未知的行为已定义，不能将“定义了条件”写成“现实已满足条件”。D08 联合可靠性、D09 多轮策略及 D10 地图消费实例均已完成限定设计；开放动态环境的其他持续/预测模型需要独立任务和验证。
