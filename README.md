# 验证义务驱动的空间功能状态维护研究

本仓库管理面向动态校园巡检的研究设计。在版本化地图上关联管理许可和现场证据，识别影响范围，生成验证义务，选择满足证据与安全要求的复核方案，再判断指定机器人能否在任务时窗内使用空间。

首轮以通道类空间为例，一次处理一个验证义务修订，采用一个已选定的机器人能力配置。研究重点是检验义务驱动复核能否在漏检和危险误放行风险受控的条件下减少复核代价。
