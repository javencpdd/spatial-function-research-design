# E2/E3 实验方案与总体评价

本方案使用 D01 的影响闭包、D02 的通道净宽证据模板和 D03 的有限完整路线模型。当前交付是可预先锁定的实验设计。正式测试前取得的参数、样本量与对应版本按 §8 保存。研究首先限定于受控直通道、一个义务修订和一个选定 RobotProfile。

E1 的独立细化见[双源状态维护实验](dual-source-e1.md)：采用区间与硬过期，分开世界状态和当时可见证据参考，明确错误开放/封闭、覆盖及弃权的评分。E1 是 S3 的隔离评价，不把诊断 O 当作 S4 通过或 S7 放行；E2/E3 的本文件口径保持各自作用域。

E4 的独立细化见[局部恢复与失效重开实验](recovery-e4.md)：固定子域义务与窗口、独立恢复真值及当前支撑，分别评价重开、替代、复发和投影应用。采用相同证据规则的局部周期重评主要对照，区分物理恢复、S4 恢复验收与 S3 可读三条时钟；E5 继续承担实际任务条件下的放行评价。

E5 的独立细化见[任务条件下的空间可用性实验](availability-e5.md)：固定请求、条件方案及五态证明，使用同样充分快照的基准方案判断作主要对照。评分分开危险误放行、无依据允许、正确允许覆盖、误拒与待定；CONDITIONAL 按其全部允许执行范围核验。当前为离线协议，真实执行及 Consumer 行为由 E6 承接。

## 2. 独立真值与数据分组

### 2.1 三类真值分别取证

| 真值 | 形成方式 | 核验与保留项 |
| --- | --- | --- |
| 复核相关性 $R_i$ | 为每个事件在固定目标域内标记需要重评的空间属性与功能要求。在合成场景中，从事先规定的生成机制、干预影响与目录独立构造参考答案。在受控场景中，以独立测量、设施依赖记录和专家判据判断哪些要求的既有依据受影响。 | 两位复核者先独立判断并屏蔽方法输出，再由第三方处理分歧。参考构造的原始关系、方向、属性及有效时间留痕。使用本方法的同一闭包输出生成参考标签会造成循环评价，应改用独立构造与逐项核验。 |
| 实际净宽和功能 $W_i(x,t),P_i$ | 使用独立尺寸参照与独立复测，按 D02 的断面、高度带、范围与时窗建立宽度区间及状态时间线。记录事件发生、真实恢复与后续变化的时点。 | 当真值区间也跨过要求阈值时标为未决。输入见证与用于评价效果的真值应有独立采集和误差依据，同一原记录只能按其明确角色使用。 |
| 来源与动作资格 | 记录设备、原始采集链、标定、配准、故障注入、动作可达性和资源真值，用于判断共同原因、证据资格及路线是否真实可执行。 | 模拟注入保留生成版本与种子，现场安排保留独立核查。S5 的预计产证与 S4 的实际证据各自记录。 |

确认的复核相关性可以覆盖最终仍达标的功能，所以 $R_i$ 和实际不达标集合分别计量。目标以“属性或要求＋空间支持＋时间段”标识，空间和时间的粒度在测试前冻结。功能目标与属性目标分别统计，以免通过细分单一属性改变权重。真值仍有分歧的条目保留其范围和原因，给出数量及指标可能范围，确定真值子集的结果单列。

### 2.2 分组、分层与盲测

检查物理场景、事件实例、采集作业、设备/标定批次、日期及相关地图版本之间的共享关系。共享会影响本结论的原记录或随机错误机制的样本放在同一泄漏组。固定的公共地图或模型版本在研究中作为条件明确记录，单纯版本相同不自动使所有独立事件合并。先按组划分校准集与封存测试集，再选择参数。校准内完成传感器误差、时钟、时效、预算、周期及方法超参数的确定。已有训练需求再在校准组内划出训练与验证部分。

测试包含直接影响、多跳与循环依赖、属性不适用、未知关系、局部遮挡、来源重复、证据过期、时钟偏差、预算不足和图/地图版本变化。确定无解、存在可行路线及确有信息缺口的样本事先分层。合成、受控测量、未来现场采集分别报告效果。独立测试组数量及分布在正式启动前冻结，同一原事件的多帧或多次随机重放按相关重复保存。

## 4. 评价量、分母与两种时钟

### 4.1 E2 的相关性与漏传播

对事件 $i$，令 $U_i$ 为事先冻结的目标域，$R_i\subseteq U_i$ 为独立标记的复核相关目标。方法提出的复核范围为 $A_i=C_i^-\cup C_i^+$。候选范围计入复核工作量，不能从精度分母移除。未能界定的边界缺口单独记录，未决状态本身不能充当已经覆盖所有目标的证明。

$$
Precision_i=\frac{|A_i\cap R_i|}{|A_i|},\qquad
Recall_i=\frac{|A_i\cap R_i|}{|R_i|},\qquad
Miss_i=1-Recall_i.
$$

主指标为事件级漏传播率的组内均值，再按独立组等权汇总。辅以精确率、目标数/复核范围量、错误排除数、原因路径可复算比例及完整性声明错误数。$R_i$ 为空时该事件的召回率未定义，保留于无影响事件层并报告误报目标数。$A_i$ 为空时精确率未定义，记录空输出数及该事件漏传播结果。精确率主比较需同时约束空输出比例，并用全部目标的错报、漏报计数交叉核验。微平均也报告原始计数。真值未决条目按所有允许标签计算敏感性范围，不能悄然分配为有利标签。

### 4.2 E3 与总体事件评价

以预先入组的事件/义务实例为单位，同一事件在全部方法中配对。正式主要统计按独立泄漏组汇总后等权比较，组内各事件等权，重复种子先在对应事件内汇总。相关重复及目标粒度不得增加独立样本量。

| 指标 | 定义及分母 |
| --- | --- |
| 首次可信确认 | 从独立真值的事件起点到首次具有合格 S4 双轴结论、且范围/时窗与真值一致的确定判断。错误 PASS/FAIL 另记错误事件，继续等待首次正确确认。 |
| 截止内正确确认率 | 截止 $H$ 内取得上述正确确认的事件数/全部预先入组的评价事件数。真值未决事件给出成功率界。并列报告未决、超时、执行失败和规划三值的比例。 |
| 截止计分延迟 $D_i$ | 正确确认发生在 $H$ 内取实际延迟，否则赋值 $H$。固定 $H$ 后对所有入组事件统计。它是有限期限内的延迟计分，成功确认者的延迟分布另报。 |
| 验证成本 $C_i$ | 从事件起点到首次正确确认或 $H$，累计全部复核动作的实耗能量 Wh。移动、等待、采样、结束及失败重试计入，已启动且必须完成的安全结束路段亦计入。另报总路线分钟、动作数、测量范围和计算时间。 |
| 恢复时间 | 只在实验前已定义恢复阶段的事件层，从独立真值恢复起点到针对恢复谓词的正确 ACCEPTED/PASS。该阶段另有固定截止及未完成计分。 |
| 实际不达标漏检 | 真值确定存在不达标的事件中，截止仍未正确确认该不达标状态的比例。保持 PENDING 也算尚未确认。 |
| 危险误放行 | 对预先给定的任务、路径和使用时窗，真值确定存在适用禁令或相关硬性不满足时，共同评价器输出允许使用的错误。CONDITIONAL 需按其实际限制条件核验是否仍错误允许。 |

E3 的规划状态与采证覆盖、真实业务确认分别输出。若隔离规划任务开始晚于事件起点，额外报告从规划输入齐备到采证完成的时间，不替换总体首次确认时钟。恢复起点也不替换事件起点。

E3 隔离评价的主代价固定为完整采证路线时长，遵循 D03 的时间优先顺序。实际完成全部采证资格及结束条件时取真实时长，未能在预定规划期限内完成时取该期限作为计分值，同时报告原始耗时和失败原因。能耗为次指标，并继续报告业务确认率。总体对 B0 的验证成本主指标固定为上表的实耗 Wh，不能看结果后在分钟和 Wh 之间选择有利单位。

危险查询的列表和时间网格在运行前固定，所有方法面对相同评价机会。主风险单位为独立危险试验组，每组任一次危险误放行记为 1，否则为 0。报告该组级率、逐查询错误数和原始分母。S7 采用共同的离线条件评价，首轮风险结论限于所测净宽、许可和任务情景。

成本比较同时满足最低正确确认率、漏检及风险限制。这样，停止采证或持续 UNKNOWN 所节省的资源不会单独支持效率改善。安全约束确实无法满足的场景单列为任务不可执行层，保留在总体分布与错误可行性统计中。

### 4.3 超时、缺失与故障

- 规划 UNKNOWN、没有路线、采证失败、错误结论和超时均留在对应原始分母。实际合法的 INFEASIBLE 作为规划正确性结果保留，其业务确认结果按该任务的实际输出计分。
- 方法崩溃视为该方法未确认。公共输入损坏只有符合封存前规则且与方法结果无关时，才能对整组配对样本排除。保存排除清单、理由及全样本敏感性结果。
- 缺能耗日志时记录成本区间，至少包含已知消耗和该试验预算内的所有可能消耗。主成本比较采用对缺失值最不利的界核验，无法证明改善时保持未定。禁止仅保留有完整日志的成功样本。
- 事件起止存在真值时间区间时，同时计算可行的延迟界。主结论应能承受这些界，或报告时间真值未决。真实恢复尚未被安排的事件不进入恢复层，入组后未观察到恢复的事件按预定截止记录。

## 5. 小规模最优参照与三值正确性

先在 D03 声明的相同有限生成域内，独立枚举完整路线和见证分配。保存动作/时间/终点定义、候选总数、每条排除依据、时效与资格完整性证明。独立推导或实现的参照需与方法分开核对。可用 D03 的二十例先检查口径，再构造不同位置、时间和来源组合。

若有可证最小时长 $T_*$ 和合法路线时间 $T$，报告 $T-T_*$。只有 $T_*>0$ 时才另报相对时间差 $(T-T_*)/T_*$。能耗差限于已达到 $T_*$ 的候选间比较，ID 只决定同成本稳定选择。仅有下界 $L_T$ 时标为“距已知下界”，最优性未证的候选保留其状态。大规模实例没有合格参照时，报告合法性、实际成本及可用下界。

三值正确性使用相同知识切点。在有效求解上下文中，一条完整路线及其联合见证分配已证明满足全部门禁，即标 FEASIBLE。其他候选缺项只限制最优性声明。INFEASIBLE 需要完整候选域上的乐观排除，或覆盖声明域的共同无解证明。两类证明均缺时标 UNKNOWN。按 D03 案例 13，唯一已列路线 P 的证明齐全，即使其余路线尚未查清，也应把 P 评为可行。参照可使用更完整的隐藏世界检查过度宣称，但不得把隐藏信息反向注入被评价方法。报告各真值层的输出矩阵及错误可行/错误无解数量。

## 6. 配对统计与研究判定

差值均定义为完整方法减主要对照。确认延迟差为 $\Delta_D$，能耗差为 $\Delta_C$。预先定义有实际意义的改善量 $\delta_D,\delta_C>0$、允许退化 $m_D,m_C\ge0$，以及确认率最低要求与允许退化。总体支持条件为以下两项之一成立，并且共同风险、实际漏检和确认率资格全部通过。

$$
U(\Delta_D)<-\delta_D\ \land\ U(\Delta_C)\le m_C,
\quad\text{或}\quad
U(\Delta_C)<-\delta_C\ \land\ U(\Delta_D)\le m_D.
$$

这里 $U$ 是经过预注册多重比较控制的单侧置信上界。E2 的主要比较检验漏传播率降低，并要求精确率退化在预设范围内。E3 的主要比较检验完整采证路线时长计分降低，同时要求正确确认率、实际漏检和风险符合共同限制。完整方法与 B0 的总体比较、E2 主要对照、E3 主要对照及所有用于主张改善或非劣的端点在清单中列全。

本轮选择整体一类错误预算 $\alpha=0.05$，功效目标 0.80。主张所需单侧界共 $M$ 项时，每项使用 $\alpha/M$ 的尾部预算构建界，$M$ 在看测试结果前按完整端点表锁定。配对组自助法重复次数以 10,000 为起点，至少让每个校正尾部包含约 50 次重抽结果，选择 $B\ge\max(10000,\lceil50M/\alpha\rceil)$ 并在封存前检查数值稳定性。作为补充的描述性区间标明其置信水平。额外对照、消融和分层采用明确的探索性解释，若要用于正式显著性主张则事先纳入端点家族。

效应分析以最高独立层级的泄漏组为单位，有放回重抽完整配对组，并保留组内所有方法、事件及重复的对应关系。依据事先确定的组权重重算差值与区间。独立组太少或事件率极低时，由预实验模拟核查区间覆盖和检验功效，再在正式封存前调整方案。组重抽样用于保留组内关联，其方法依据参见 [Deen 与 de Rooij 的原始研究](https://link.springer.com/article/10.3758/s13428-019-01252-y)。

设独立危险试验组中有 $k$ 组发生危险误放行、总数为 $n$，对组级概率使用单侧精确二项上界，并与预先取证的上限 $r_{max}$ 比较。对实际漏检组同样处理。方法相对对照的允许退化采用配对风险差及有效的保守界。重复查询只增加组内记录，不增加 $n$。精确二项界的计算依据见 [NIST Exact Binomial](https://www.itl.nist.gov/div898/software/dataplot/refman2/auxillar/exacbino.htm)。

当 $k=0$ 且组之间符合独立同分布条件时，由 $(1-p_U)^n=\alpha_j$ 得

$$
p_U=1-\alpha_j^{1/n},\qquad
n\ge\left\lceil\frac{\log\alpha_j}{\log(1-r_{max})}\right\rceil.
$$

其中 $\alpha_j$ 是分配给该风险上界的单侧尾部预算。相关试验、按固定比例拼接而未定义目标分布的分层样本，不能直接把全部记录当作一个二项样本。应分别报告层内上界，或按封存的抽样设计形成有效总体界。危险率与漏检率上界未满足要求时，该轮效率结果不能据此宣称总体研究假设通过。

配对风险差在稀有/全零事件时使用保守边际界交叉核验。例如以方法风险上界减对照风险下界构造差值上界，两项界共享对应端点的尾部预算。组自助法在全零样本中给出的零宽区间不承担稀有风险证明。

## 7. 评价口径的纸面核对

以下均为示例，实际改善和风险界限由 §8 锁定。

| 情形 | 应得到的评价 |
| --- | --- |
| 真值复核目标 4 个，方法提交 3 个确认目标和 2 个候选，其中 3 个是真值目标。 | 复核范围共 5 个，精确率 3/5，召回率 3/4，漏传播率 1/4。 |
| 10 个事件中 7 个正确确认，1 个执行失败，2 个 UNKNOWN，截止为 10 分钟。 | 正确确认率 7/10。后三例的延迟计分各为 10，资源消耗均计入。 |
| 方法第 2 分钟给出错误 PASS，第 5 分钟取得正确 FAIL。 | 首次可信确认延迟为 5 分钟，另记第 2 分钟的错误判断及其危险查询后果。 |
| 事件发生于 0，真实恢复于 6，恢复验收正确通过于 9 分钟。 | 恢复时间为 3 分钟。首次确认按事件起点和最早正确状态判断另算。 |
| 合法路线时长 10，独立参照已证最优时长 8。 | 时间差为 2，相对差为 25%。若 8 仅是下界，记录距下界为 2。 |
| 一组含 100 个危险查询，仅有 1 次误放行。 | 该组危险指标为 1，组级分母贡献 1，逐查询分母贡献 100。 |
| 100 个独立危险组零次失败，单侧尾部预算为 0.05。 | 上界约为 2.95%。这是假定单个界的演算，多重比较后使用实际分配的更小尾部预算。 |
| 各端点有利，但风险上界或确认率资格仍未过关。 | 记录效率变化，整体研究判定保持未获支持。 |

| 需锁定项目 | 来源与取得步骤 | 当前状态 |
| --- | --- | --- |
| 场景、分组及独立真值 | 冻结数据清单、泄漏组、来源、两位复核者的独立标注与分歧处理，确定训练/校准/测试归属。 | 待取得正式数据。 |
| D02 测量与时效参数 | 通过独立尺寸/时钟及分组预实验取得误差、覆盖、独立性和有效窗口，明确适用范围。 | 设计已给出方法，数值待标定。 |
| 方法与对照参数 | 固定周期与相位、几何对照扩展深度、贪心规则、集合覆盖权重、候选目录/网格、预算与求解截止。 | 校准集内选择，测试前锁定。 |
| 风险与退化界 | $r_{max}$、实际漏检上限、两者允许退化、正确确认率最低值及允许退化，由研究任务要求和适用的风险依据确定。 | 待取证并写入清单。 |
| 主效应和窗口 | $\delta_D,\delta_C,m_D,m_C,H$、E3 路线时长改善量、恢复阶段窗口、精确率退化界及空输出比例上限，按可解释的任务收益与容忍度确定。 | 待预实验和任务依据确认。 |
| 统计参数 | 本轮选用 $\alpha=0.05$、功效目标 0.80，主张清单确定 $M$ 及各界的尾部预算，自助次数按校正后的尾部精度规则确定。 | 方法已选，预实验核查适用性。 |
| 样本规模 | 预实验估计配对差异方差、失败比例、组内关联及各层出现率。按同一统计流程模拟不同独立组数，取满足主要效果功效、置信宽度和风险上界所需样本的较大者。零失败公式只提供乐观可达到的风险样本量下限。 | 待估计方差与风险依据后计算。 |

例如，若只检验一个 95% 单侧界，要求零失败时上界不超过 1%，至少需 299 个符合假设的独立危险组。主张家族较大或存在失败时所需数量增加，实际规模由已锁定清单计算。增加同一视频的帧数不代替增加独立组。

启动正式测试前，数据、要求和标定、端点/分母、对照、成本、分组分析、全部数值界与样本量均应有具体版本。保存方案提交、数据/标签清单、算法与参数修订、随机种子和预计输出格式。后续偏离通过新修订记录理由及发生时点，已看过结果的数据保留其探索性用途。
