# 实验设计基线

方案依据开题报告 §3.9 和 Notion 的研究验证设计整理。首轮优先细化 E2 和 E3，以下指标均为待检验项。

| 实验 | 对照及消融 | 主要指标 |
| --- | --- | --- |
| E1 双源维护（H1） | 直接覆盖、单源更新、APCM | 错误开放率、错误封闭率、冲突判定准确性 |
| E2 事件影响（H2） | 几何邻接、属性交集、完整空间与功能依赖 | 漏传播率、闭包精确率与召回率 |
| E3 最小复核（H2） | 全区域复核、贪心或集合覆盖、完整方法；消融来源独立性 | 时间、能耗、动作数、漏检与最优性间隙 |
| E4 功能恢复（H4） | 整区开闭、无状态机、完整方法 | 错误恢复率、撤销与重开正确率 |
| E5 条件查询（H3） | 固定可通行标记、仅几何判断、完整方法 | 危险放行率、误拒率、待定比例 |
| E6 互操作与反馈（H4，工程验证） | 单实现、无版本固定、两套独立实现及完整回放 | 输出一致、异常拒绝、幂等和可重放 |

固定周期巡检作为总体主对照。约定相同的机器人、观测条件、预算、证据覆盖和风险要求。首次可信确认时间从独立真值确定的事件起点计至首次 `ACCEPTED / PASS` 或 `ACCEPTED / FAIL`。恢复时间单独计量，从真实恢复起点到通过恢复验收。分别报告复核资源与危险误放行率。超时、未确认及 `UNKNOWN` 保留在分母和统计记录中，按预先约定的规则处理。

建议在正式测试前固定事件和功能真值的独立标注方法，按事件及采集批次划分校准集与测试集。校准质量、覆盖、时效和独立性条件。预先确定主指标、样本量依据、风险阈值、效率改善和允许退化的界限。统计报告保留失败案例及其适用边界。
