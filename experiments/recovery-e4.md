# E4 局部恢复与失效重开实验设计

本轮细化 S4 验收、义务修订与 S3 后继投影之间的恢复过程，沿用通道净宽、D02 的两个独立槽与逐个义务验收。交付为设计和纸面复核，未采集数据、未运行实验或开发服务。E4 的“恢复”指指定要求、空间和验证时段的有效恢复验收，不代表解除管理禁令或 S7 已允许任务执行。

研究主张记为 H4-E4，承接[总体方案](protocol.md)的恢复与重开部分。E1 评价双源状态，E2/E3 评价范围和采证，E5 再检验主体、任务、路径及时窗下的可用性；这些结果分别取得，不用一个 PASS 替代其他层的证据。

恢复证据的空间与时间支撑按 [D07](../design/spatiotemporal-support.md) 核验：新的保持区间需要自己的物理依据，旧/新区间之间的空白不能由 CLOSED_PASS、重开或投影更新填平。保持破坏事实迟到时，保留旧知识切点并按新事实重评当前支撑。

[D08 联合可靠性](../design/joint-evidence-guarantee.md) 进一步要求共享依赖与当前误差界重新核验。义务重开、重新编号及重复提交不增加独立见证，也不重置同一研究主张的统计家族或置信预算；迟到合格证据仍可按对应域及新知识切点验收。

## 1. 评价对象与职责

### 1.1 按固定验证单元恢复

测试前定义验证单元 $v_i=(scope_i,function_i,requirement_i,template_i,policy_i)$，精确绑定地图/关联、要求、模板与证据策略版本。每次 S4 评价还绑定一个不可变的 Obligation Revision、验收谓词、空间与时段 $D_i=X_i\times J_i$、证据快照及见证分配。

局部恢复使用事先登记的子域义务。例如西段和东段分别有 $o_W,o_E$，一次各验收一个义务；这不扩展为多义务联合规划。西段两份见证通过只能关闭 $o_W$ 的相应修订。若只有一个覆盖全域的义务，西段通过只是该义务的部分证据，不能把其目标缩小后标记全域通过。

区域可报告已恢复单元集合及覆盖量，`PARTIAL` 只作区域聚合。若上层功能要求有自己的 AND/OR/K-of-N 规则，仍需按其独立冻结谓词评价，不能由面积比例推出上层通过。各单元的粒度及空间权重在测试前冻结，事后拆小成功区域不增加分母。

### 1.2 各层事实分别保存

| 层次 | 权威事实和评价边界 |
| --- | --- |
| 真实物理变化 | 独立尺寸和时间参照记录何时净宽恢复、持续多久、何时再次不达标；不以维修回执或方法输出确定。 |
| S4 恢复验收 | 对当前适用的义务修订给出 `ACCEPTED/PASS` 及 `CLOSED_PASS`；必须满足 D02 的覆盖、独立性、质量、有效期和无实质冲突。 |
| S3 恢复依据可读 | 后继投影明确应用了所需 S4 变更及必要前因，正确保留其作用域、要求、证据及有效时段。投影可以继续因管理禁令显示 PROHIBITED。 |
| Event 与 Task | Task SUCCEEDED、Event RESOLVED/CLOSED 各按自己的生命周期判断，不自动构成净宽恢复；S5 继续拥有计划。 |
| S7 使用条件 | 固定主体/路径/任务及占用窗的放行由 E5 评价。E4 只检查其所需恢复依据是否已准备，不把 S3 净宽子结论当作任务许可。 |

## 2. 不可变修订与失效分流

### 2.1 历史判断与当前支撑

旧修订在旧 $D_i$、旧要求和知识切点下的 PASS/FAIL 保留原事实。证据达到当前有效截止，首先停止它对当前用途的支撑，不自动证明历史判断错误，也不产生相反物理观测。

恢复复测的窗口生成规则在测试前固定，可以是指定诊断时点、固定连续窗或预定网格上的窗口。每次窗口变化由 S4 显式冻结新的 Obligation Revision；模板须事先允许恢复复测/续期。相同事件、作用域、功能与 Requirement Revision 使用既有幂等键创建后继修订，不另造同键的并行义务。不能修改旧修订的 $J_i$，也不能看读数后选择最有利窗口。

一次性历史验收在原窗口结束后，如没有持续验证要求或新的复测请求，不因时间流逝自动重开。对于持续维护或已请求恢复复测的义务，相关事实使当前支撑不足时，S4 追加 REOPENED 后继修订，再转 OPEN/补证；旧 CLOSED_PASS/CLOSED_FAIL 修订仍按原切点可读。这是本轮的续期与恢复策略选择，不自动推翻旧历史验收。

### 2.2 先重评再选择生命周期动作

| 输入变化 | 本轮规则与状态处理 |
| --- | --- |
| 原见证过期/撤销/纠错，但另一组当前合格独立见证仍满足全部条件 | 重做完整联合分配，提交使用新依据的 EvidenceEvaluation/义务后继修订，可保持 CLOSED_PASS；不机械地产生一次 REOPENED。新依据提交前旧失效依据不得继续用于当前恢复声明。 |
| 持续验证所需支撑确实不足，来源独立性不明、出现同域实质冲突或新有效反证 | 生成失效与重评依据，按策略将相关闭合义务追加为 REOPENED，再 OPEN/补证。已证 FAIL、未决和缺证分别保存，不能用 REOPENED 直接推断物理失败。 |
| 原 CLOSED_FAIL 的窗口已结束，出现清障事实及模板允许的恢复复测请求 | 以新修订冻结恢复谓词和窗口，进入 REOPENED→OPEN 后重新采证/验收；旧 FAIL 仍可能完全正确。仅有“维修完成”不得直接 CLOSED_PASS。 |
| Requirement Revision 被替代 | 旧义务按替代策略追加 SUPERSEDED 修订，按新 Requirement Revision 建立新的 Obligation；不能在旧身份下换标准后重开。旧历史评价不改。该分流覆盖闭合、执行中及其他非 SUPERSEDED/CANCELLED 的适用状态。 |
| Map/Transform/CellLineage 变化 | 按新上下文验证锚定、覆盖及兼容性。可证兼容且当前依据充分时保留相应结论；无法重锚定则停止当前重用并重评。要求或验证单元身份确已变化时按新身份生成义务，不复制旧 PASS。 |
| 明确与验证单元及其所有必要依赖无关的变化 | 保存不相交/兼容证明，保持原当前结论。几何上不相交但共用被撤销标定等依赖时，不属于无关变化。 |
| SUPERSEDED / CANCELLED | 保持终止，不复活旧身份。新的有效要求或请求建立新的义务及关联。 |

只读适用性门禁可以先撤回旧恢复声明或将相关投影置待定，不能替 S4 写入 REOPENED、EvidenceEvaluation 或新义务。S4 只有在合格新评价提交后才能再次形成 CLOSED_PASS。要求变化期间的旧计划与执行仍引用原修订，不能把取消请求当作 S6 已停止，也不能自动把旧 Task SUCCEEDED 当作新义务通过。

当前 OPEN/PLANNED 的义务若已有合格证据，也可由 S4 直接提交 ACCEPTED/PASS 或 ACCEPTED/FAIL 并进入对应闭合状态，无需先执行一个新 Task。这是对 MET §9.6 原先只列 EXECUTING/PARTIAL_EVIDENCE 的转移表补齐；仍须核验当前修订与全部证据条件。Obligation 超过自己的截止而未完成进入 EXPIRED，与某份 Evidence 失去当前适用性分开；逾期后新增的复测/续期请求须显式登记新修订，旧到期事实及超时评分保留。

### 2.3 重开、复发与行政限制

Event 的关闭依据失效，与有效关闭后新发生的独立事件分别处理。前者按 S4 Event 策略重开；后者建立新 event_id 并关联 RECURRENCE_OF。重复投递或同一持续障碍的连续观测先幂等/关联，不创建新复发事件。

Obligation 重开不自动使 Event 重开。Event 关闭是否依赖持续有效验证，需由预先冻结的关闭策略判断；只针对历史 occurrence 的有效关闭不因后来物理变化被改写。当前复发相交范围的旧恢复依据须失效，新事件的义务另行登记。管理禁令持续存在时，净宽恢复可以正确验收，但行政关闭条件和 S7 使用限制继续有效。

## 3. 独立真值、知识切点与试验层

沿用 E1 的世界参考和当时可见资料参考，两位复核者屏蔽方法输出独立标注并处理分歧。真值未决保留允许集合，不强行归入失败或恢复。

| 参考 | 独立依据与用途 |
| --- | --- |
| 物理恢复 episode | 真实恢复起点 $r_i^*$、后继失效 $b_i^*$、完整净宽和时间范围。由独立测量与时间参照确认，不用 S4 PASS 反推恢复起点。 |
| 证据与适用性 | 已到达的原记录、实际覆盖、标定/时钟、来源及共因、撤销/替代事实。S4 输入完整并可处理的公共时点为 $u_i$，不把后来隐性故障反向注入旧规则参考。 |
| 生命周期参考 | 对 $u_i$ 前可见事实独立复算见证分配，标记必须重开、可保持通过、无需当前义务、必须替代/重锚定或仍未决。不能直接以被测状态机作答案。 |
| 不受影响单元 | 同时有空间/时间、版本和所有必要依赖不相交的独立证明，供非干扰评价。依赖清单不完整时保留未决。 |
| 后继投影参考 | 必要 S4 变更集合、原裁决上下文及前因，以精确 Ref、覆盖与适用域核验。裸序号变大或消息 ACK 不证明已应用。 |

预先分三层：恢复层、支撑失效/重开层、版本切换/复发等路由层。主恢复时钟限定同一要求与模板的预定恢复 episode；Requirement 替代不能混算成原要求的更快恢复。版本路由另报替代与新义务创建延迟、错误身份重用。

所有方法共享固定维修安排、证据到达流、初始 S4/S3 状态、S2 版本、事件/作用域及测试时点；E4 不让某方法自行多采一次证据。方法的差异只在何时、按何范围及哪些已到达依据进行重评和提交。主动采证收益仍由 E2/E3 集成评价，不宣称状态机使物理维修本身更快。

## 4. 三条时钟与当前恢复判据

### 4.1 物理恢复到 S4 正确验收

恢复层每个入组实例预定固定截止 $H_R$、窗口规约和 episode 划分。令 $c_i$ 为首次正确 S4 恢复提交时间，必须同时满足：

1. 当前目标的 `ACCEPTED/PASS` 与 CLOSED_PASS 均已提交，范围、窗口、Requirement/Template 及修订绑定正确；
2. 实际证据按 D02 可联合验收，独立世界参考也支持整个声明域，不存在应保留的实质冲突；
3. 提交发生于该真实恢复 episode $[r_i^*,b_i^*)$ 内，且在 $r_i^*+H_R$ 前。未定义后继失效时 $b_i^*=+\infty$；历史窗口的迟到 PASS 若已越过复发点，不计本 episode 的当前恢复成功；
4. 首次错误 PASS 仍记错误，后续正确提交才能成为 $c_i$。后来的真实清障不能把原错误 PASS 反算成正确的提前恢复。

这里评价预先指定恢复阶段的正式验收，不把被验收窗口自动延伸到提交时刻或未来占用时窗。若方法把旧窗口 PASS 包装成缺乏支撑的当前恢复声明，仍计入错误恢复；S3 的当前用途适用性另按 §4.3 核验。

$$
D_{R,i}=\begin{cases}c_i-r_i^*,&c_i\text{ 在上述期限内存在},\\H_R,&\text{否则}.\end{cases}
$$

这是有限期限计分。未恢复、崩溃、无法采证、仍未决及复发前来不及确认均保留失败与 $H_R$，不能用较短的复发时间给失败赋较低延迟。另报成功者实际延迟、episode 长度及未达标原因。

入组前有意不安排物理恢复的负例只评价错误恢复，不进入恢复延迟分母。已入组且安排恢复、但实际未恢复或起点无法确定的试验保留，按预定截止记未完成并给起点/延迟敏感性范围；另列“实际发生恢复”的分层结果，不事后删除维修失败实例。

连续恢复窗有必要的稳定/验证时长时，该时长在模板中预先固定并计入 $D_R$；另报从该窗口首次具备合格采证条件起算的验收处理延迟。不能先减去必需等待再与 D04 的完整恢复时钟比较。

### 4.2 失效事实可处理到 S4 正确重开

只在独立参考明确为“必须重开”的实例上，令 $o_i$ 为首个正确 REOPENED 后继修订的 S4 提交时间，固定截止 $H_I$：

$$
D_{I,i}=\begin{cases}o_i-u_i,&0\le o_i-u_i<H_I,\\H_I,&\text{否则}.\end{cases}
$$

必须有合法前态、绑定同一适用要求、正确作用域及原因；仅输出 PENDING、只生成日志或 OPEN 而无 REOPENED 因果记录不算完成重开。后续 OPEN/补证分别记录。重复输入不产生新的 $u_i$，也不增加独立实例或重开次数。

证据自然截止以可预先计算的失效端点为 $u_i$；撤销/纠错以相关事实在共同 S4 输入中可见且必要前因齐备的时点为 $u_i$。从真实故障发生到 $o_i$ 的总时延另报，不能将传输迟到都归责于状态机。起点或提交时钟有不确定区间时给出延迟界，主结论须承受最坏允许值。

### 4.3 S4 提交到 S3 恢复依据可读

令 $p_i$ 为首个含正确恢复依据、已应用必要 S4 变更及前因的 S3 后继投影提交/可读时间，测量 $D_{P,i}=p_i-c_i$，并有独立截止 $H_P$。该用途所需当前有效性、锚定和范围在 $p_i$ 时仍须成立；如果传播完成前又失效、重开或复发，不能用迟到旧 PASS 记为当前传播成功。

集成链路中只对有正确 $c_i$ 的实例描述该分解，方法各自成功子集的 $D_P$ 不直接作总体优劣比较。另设固定 S4 正确提交输入的传播隔离层，使所有方法接到相同 $c_i$ 与失效/版本流；在这层统一以 $H_P$ 为截止，无合格 $p_i$ 赋 $H_P$ 并记未完成，分母不随方法成功与否变化。

延迟分别记录提交、约定读取边界可见和实际 Consumer 可见。E4 的离线设计核验前两者的记录与因果条件，真实服务/缓存应用证据由 E6 取得。S7 放行并非 $p_i$；管理禁止时可读的是净宽已验收子结论，投影整体仍可 PROHIBITED。

## 5. 对照与消融

| 方法 | 固定行为和检验目的 |
| --- | --- |
| C-R 完整局部生命周期 | 相关变化到达即按精确依赖重评、重新分配见证，并选择保持、重开、替代或新事件；S3 以作用域应用证明提交后继投影。 |
| B-P 局部固定周期重评 | **主要对照**。同样采用 D02、不可变修订、局部义务与共同当前适用性门禁；按预先固定的周期和相位办理 S4 重评/重开/恢复提交。失效门禁立即撤回旧当前支撑，但不能代写 S4 生命周期，故不能把该撤回时间记成 $o_i$。 |
| B-R 整区同步恢复 | 保持相同局部义务及共同证据规则，区域内必需单元均具备恢复依据才统一提交各局部 S4 闭合及后继投影。事件驱动/周期另固定，先与相同调度的局部方案比较范围作用，避免将粒度与调度收益混在一起。 |
| C-global-invalidate | 保留 C-R 调度，相关局部变化使整个区域进入待定。检验对确证无关单元的额外撤回及延迟，不以更保守为由忽略代价。 |
| C-no-reopen / C-task-close | 分别保留旧 CLOSED_PASS、或以 Task SUCCEEDED 直接关闭义务。作为离线反例分析，由共同世界/证据规则评分，不取代主要对照。 |
| C-no-applied-proof | S3 只按收到消息或较大序号接受恢复，省略相关变更应用与前因证明。检验旧投影和乱序情况；不声称已实现真实消费者。 |

B-P 的周期、相位及 C-R 的处理预算在校准阶段固定；测试起点不能专门选择在周期前或后。相同流与共同门禁下比较，重评提交数、无效重复数、计算/账本更新负担另报。若要声称负担非劣，将对应端点与界限在测试前加入正式家族，不能只报告更低延迟。

## 6. 端点与统计

### 6.1 错误、完成与非干扰

| 端点 | 定义与分母 |
| --- | --- |
| 错误恢复 | 检查固定读取时点以及每次暴露的新当前恢复声明。世界不达标、证据不充分/冲突、要求/范围/修订绑定错误或必要 S4 应用证明缺失，任一项使该声明不成立。按实例“任一次错误”计一次，同时分别报告世界错误、证据错误、版本/因果错误，缺证不当作物理 FAIL。分母为预定的所有恢复挑战实例，含不修复负例；多提交声明不增加分母。 |
| 不必要重开 | 独立参考明确可以保持有效通过，或没有当前持续义务/新复测请求，却提交 REOPENED。分母为预定“明确无需重开”实例。参考仍未决的实例给出可能范围，不擅自加入负类。 |
| 正确恢复完成率 | 满足 §4.1 的实例数/全部预先入组恢复实例，保留失败和未决。局部单元各自评价后在事件/独立组内按固定权重汇总。 |
| 正确重开完成率 | 满足 §4.2 的实例数/全部参考明确必须重开的实例；替代、新复发和仅历史窗口失效分层，不混入该分母。 |
| 无关单元额外撤回 $W_U$ | 对预先登记、原结论有效且有完整不相交证明的单元/时点，统计错误撤回或置待定的加权比例。分母固定，不以方法自己宣称的影响范围选样。 |
| 当前恢复支撑暴露 | 固定时点上暴露无效旧恢复结论的次数与持续时间。更新失败但仍输出旧结论时按旧输出评分，不能仅记无返回而隐藏当前错误；完全无输出记待定/失败并降低完成率。 |
| 版本与事件路由 | 分别列 MUST_REOPEN、KEEP_VALID、NO_CURRENT_DUTY、SUPERSEDE/REANCHOR、RECURRENCE 和未决参考的输出矩阵；这些是分析标签，不新增 Wire Enum。 |

分母为零时该率未定义，报告对应原始计数，不以 0 或 1 补齐研究门槛。正式方案应具有足够的恢复、必须重开、明确无需重开及不相交单元实例；缺少某层时限缩结论，不能跳过相应主要资格界。

错误恢复与不必要重开按预定独立组形成二元挑战结果，同组多帧、单元和重复不增加独立组数；同时保留全部原始计数。对图/地图分支、同一次撤销及共享采集/故障生成的变体按组划分。恢复/重开延迟先在事件内按固定单元权重汇总，再在独立组间等权；两方法配对保持相同世界过程。

### 6.2 七项主要置信界

首轮 H4-E4 以恢复计分延迟对 B-P 的改善为主，重开时延允许的退化及正确性/局部性为共同门槛。取差值为 C-R 减 B-P，预先锁定七项单侧界：

$$
U(\Delta D_R)<-\delta_R,\quad U(\Delta D_I)\le m_I,\quad
U(p_{WR})\le r_{WR},\quad U(p_{UR})\le r_{UR},
$$

$$
L(s_R)\ge s_{R,min},\quad L(s_I)\ge s_{I,min},\quad
U(\Delta W_U)\le m_U.
$$

$\delta_R>0$ 为有实际意义的恢复延迟改善；$m_I,m_U\ge0$ 为允许退化；其余为错误上限及最低完成率。$p_{WR},p_{UR}$ 是上述组级错误，$s_R,s_I$ 是固定权重的完成率。七项均通过才支持本轮主张；始终待定或从不重开的方案不能仅靠零错误通过。其他对照/消融为预定描述性结果，如用于额外显著性主张须事先增加端点家族。

统计方法承接[总体方案 §6](protocol.md)与 [E1 §5.3](dual-source-e1.md)：整体一类错误预算 0.05、功效目标 0.80，单侧尾部预算按联合主张清单分配；E1/E2/E3/E4 联合宣称时使用完整家族 M。延迟和完成率使用保留组内配对的区间方法，独立组不足或退化时使用预先锁定的有界均值保守界；稀有/全零组级错误用适用的精确二项界，不能用零宽 Bootstrap 证明零风险。对延迟先按固定 $H_R,H_I,H_P$ 归一到有界范围，再使用保底方法。

世界恢复起点、输入切点、episode 结束或标签未决时，联合计算允许的时钟、标签与配对差范围，主张使用最不利界。条件分母发生变化时连同分母计算，不能分别挑有利数值。所有数值界、目标场景混合、周期/相位、截止、独立组规模与区间方法在正式测试前锁定。若只有纸面规则正确或只优于错误关闭消融，不宣称优于 B-P 或实际恢复效果成立。
