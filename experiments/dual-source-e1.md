# E1 双源状态维护实验设计

本轮细化管理许可、物理净宽与证据可判定性的分离评价，延续 D05 的受控通道、单义务与单能力配置范围。交付为实验协议和纸面复核，尚未采集或运行实验。E1 不执行复核动作，也不评价 S4 正式验收或 S7 任务放行；后两者分别由 E4/E5 及总体实验承接。

本文件的主张记为 H1-E1，对应开题报告的双源维护假设；APCM §F-01 的总体时延/成本主假设另按[总体评价方案](protocol.md)检验，避免混用两个 H1 的含义。

## 1. 研究问题与首轮方法选择

给定完全相同的管理指令、观测到达流、地图版本及评价机会，检验分开维护管理许可和物理证据、保留矛盾与缺口，能否减少错误的开放断言，同时使错误封闭、正确确定输出及覆盖保持在预先规定的界内。主要对照采用分离双轴并只取最近合格测量的方法，防止仅与单态覆盖相比就宣称完整方法优越。

首轮采用 APCM 已允许的 `INTERVAL_ESTIMATE` 与属性级 `HARD_EXPIRY`。净宽定义、误差、空间/时间覆盖与来源资格沿用 [D02](../design/corridor-evidence.md)；有限有效区间外不作预测。Bayesian Transition、BBA/Yager、EIG 和不同年龄处理模式保留为后续分支，旧笔记中的 0.55 等初值不作为本轮阈值。本轮没有概率输出，不计算 Brier、ECE 或 NLL，也不把区间宽度、BBA 质量或覆盖率当概率。

### 1.1 评价单元与三条独立时间线

一个固定评价机会为

$$
q=(entity,attribute,X_q,J_q,t_q,k_q,K_q,U_q),
$$

其中 $X_q$ 为通道范围，$J_q$ 为声明的诊断时段，$t_q$ 为业务时点，$k_q$ 为可用输入的知识切点，$K_q$ 为地图/图、要求、关联/变换、策略、标定与来源版本元组，$U_q$ 为固定用途及管理条件。首轮允许明确标注的瞬时评价；连续时段需另有完整状态支撑，不能用一帧加有效期推断整段现实状态。此处不是 S7 的未来任务占用窗。

- **现实时间线**保存真实净宽变化和有权管理指令的生效/撤销/替代时间。
- **输入到达时间线**保存每个方法在 $k_q$ 前实际可见的记录、来源水位和故障。所有方法获得同一流，禁止提前读取迟到记录。
- **评价与纠错时间线**保存何时输出何结论；纠错后产生新的知识切点，旧结果不按后来知识重写。

评价网格、事件窗口、作用域粒度与时间不确定区间在测试前固定。重复帧、重复投递和追加候选都不新增评价机会。场景/采集组先划分校准与封存测试，组内的版本分支、故障变体及时间序列一起保留；具体分组沿用总体方案 §2.2。

## 2. 参考答案独立于方法输出

### 2.1 世界状态与当时可知条件分别核验

| 参考项 | 独立形成方式 | 不能替代它的材料 |
| --- | --- | --- |
| 管理适用性 $M_q^*$ | 合成试验使用封存的授权角色、辖区、用途、指令生效及撤销/替代账本；受控试验由独立复核者据有权来源和固定解析策略判定。保留原始枚举与条件，再归约为对 $U_q$ 的 ALLOW、DENY 或 UNRESOLVED。同级冲突和未决条件单列原因。 | 不能直接用被测管理解析器的结果作标签；物理测量不证明管理许可。 |
| 物理谓词 $P_q^*$ | 以独立尺寸参照、独立复测及时间记录建立 $D_q=X_q\times J_q$ 上的净宽范围。全域下界达标标记 MEETS；存在适用位置/时段的上界低于 $w_{req}$ 标记 VIOLATES；否则保留两种可能。 | 不能复用作为算法输入的同一测量或 D02 的验收结果作唯一真值；看见障碍不直接证明净宽不达标。 |
| 输入资格与冲突 $A_q^*$ | 对实际到达的记录，独立核查真实可测范围、时钟误差、标定/配准、来源与共享原记录，标记合格、明确不合格或未决。冲突必须有相同要求及重合时空支持中的实质反向证据。 | 不以方法给出的质量分、Bundle ID 或冲突标签直接决定参考答案。 |
| 规则处理 $C_q^{K}$ | 只使用 $k_q$ 前可见的记录及独立资格核验，按 §3 冻结的规则手工推导应有的双轴状态、候选与弃权理由。 | 不能把未来真值、迟到禁令或后验纠错注入当时的规则参考。 |

两位复核者先屏蔽方法输出独立判断，再处理分歧；保留原标注、分歧原因、裁决修订、证据和时间范围。无法裁决的标签保持未决。标注一致性及真值未决比例单列，不能先删去难例再报告准确率。

世界参考用于评价实际错误，规则参考用于评价当时是否正确使用了可见证据。用于规则参考的资格证明、失效事实及来源完整性依据也受 $k_q$ 限制，后来才发现的隐性标定错误另入后验失效层。若在 $k_1$ 后才收到对较早时点生效的禁令，$k_1$ 的开放断言可在世界状态评价中为错，但不能仅凭后来记录判其违反当时的输入规则；$k_2$ 已收到且适用时仍保留开放断言则两项均需计错。

### 2.2 E1 的开放断言只是一项诊断量

定义世界参考集合 $Y_q^*\subseteq\{0,1\}$：管理允许且全域净宽达标时为 $\{1\}$；有效禁令或已证净宽不达标时为 $\{0\}$；其他情况保留 $\{0,1\}$。RESTRICTED 仅在其明确用途条件经独立核验后归约；条件未决不直接视为禁止或允许。

把方法输出归一为 $\widehat Z_q\in\{O,N,A\}$：O 为“管理与净宽条件支持开放”的断言，N 为基于适用禁令或物理反例的明确否定，A 为无法给出确定断言。O 不包含正式 S4 验收、其他物理属性、机器人能力、风险或未来时窗条件，不能写成正式 `AVAILABLE`，也不用于实际执行。

物理冲突、证据不足、管理冲突及无观测属于判断依据或缺口，不是物理世界的第三、第四类状态。它们可导致 A；若同时存在确定适用的禁令，则仍可由禁令支持 N，并保留物理未知或冲突。世界真值尚不能唯一确定时，不把 A 当成一次正确世界分类。

## 3. 冻结可复算的首轮规则

### 3.1 管理轴

按 APCM §4 的授权、辖区/用途、显式撤销/替代、来源单调版本及有效时间解析。物理观测不得改写管理记录；同级有效指令不能仅按接收顺序选胜者。保存原始管理状态及对 $U_q$ 的归约，缺授权依据、未决条件、冲突或必要来源完整性缺口保留 UNRESOLVED 和具体原因。

对声明的全域用途，ALLOW 需覆盖其必要空间和时段；可证适用的局部禁令足以否定该全域用途。只覆盖部分区域的许可不能扩展为全域允许。采用其他用途量词时重新冻结参考定义和归约规则。

### 3.2 物理轴

1. 按原始采集链去重成 Bundle。拒用错对象、错单位、Hash 损坏、明确不适用的标定/变换；覆盖、时钟、关联或资格未决时仅保留可证子域。到达时间不改变原采样时间和有效期。
2. 同一 Bundle 内只拼接已经核验的联合空间/时间子域。在 $D_q$ 上有完整下界支撑才支持 MEETS；有适用局部上界低于要求才支持 VIOLATES。区间跨阈值仅表示未决。达到有效截止端即不能再支持当前判断。
3. 若合格证据在同一要求和重合时空内有实质相反支持，输出物理 CONFLICT 并保留双方，不按多数或最新一条覆盖。不同时间发生真实变化先分段，不能自动计为冲突。
4. 有 VIOLATES 的合格反例且无实质冲突时可形成该物理断言；有全域 MEETS 支撑且无实质冲突时可形成该物理断言；其余为 UNKNOWN，保留各缺口。

该规则是本轮的区间推断选择。一份具有独立质量与覆盖依据的 Bundle 可以支持 S3 的物理量断言；重复 Bundle 不提高其强度。多个来源存在未知相关性时不作独立乘积、不增加见证数或概率；单独不能达标的片段不能因此升级。发现共享的失效标定时取消受影响支撑。正式 S4 仍按 D02 的两个独立槽验收，S3 的这一断言不产生 `ACCEPTED/PASS`。

### 3.3 协调、候选与归一输出

| 管理归约 | 物理判断 | E1 归一输出 | S3 的说明与候选规则 |
| --- | --- | --- | --- |
| ALLOW | MEETS | O | 双轴条件支持；不宣布正式功能恢复。 |
| ALLOW | VIOLATES | N | 产生 PHYSICAL_BLOCKAGE_UNDER_PERMISSION 差异候选。 |
| ALLOW | UNKNOWN / CONFLICT | A | 保存缺证或冲突；本轮对安全相关净宽缺口发布待核查候选，诊断随记录保留。 |

上述诊断和参考标签是实验分析用表达，不新增 Wire Enum 或 ReasonCode。候选绑定现有对象的范围、版本、证据及原因，S4 继续独占 Event/Obligation 登记。评分分别检查双轴、协调输出和候选类型；不同诊断可并存，不能把管理与物理不一致都归为证据冲突。

所有方法使用相同冻结数据流、初始事实、图/要求、独立质量事实、评价网格、预算及输出截止。E1 不允许方法自行增加观测，否则需作为 E2/E3 集成另做比较。硬准入均拒用明确伪造/损坏输入；只有已声明的移除机制在相应消融中改变。时效消融不能偷偷重新加入同一时效门禁。单态覆盖方法 B-O 的到达顺序比较属于其定义；B-L 与 C-MX 在相同知识切点内均按可信采样时间及精确版本判断。

区间分支没有独立证据置信累积，去重/来源相关性消融可能不改变最终物理标签；此时如实记录零效应，并以重复不改变支撑强度的性质检查其作用。不能为了得到增益而给该分支临时编造概率融合。以后若增加 Bayesian/BBA 分支，需另冻模型、相关性假设、概率评分及共同覆盖下的对照。

## 5. 指标、分母与研究判据

### 5.1 主比较和覆盖约束

对预先入组的 $G$ 个独立组，第 $g$ 组含 $n_g$ 个固定评价机会。首轮各组等权、组内机会等权，令 $w_q=1/(Gn_g)$。若用分层目标混合权重，须在封存前替换为完整权重清单，不能观察结果后改构成。世界标签确定时有

$$
R_O=\sum_qw_q\mathbf1[\widehat Z_q=O,Y_q^*=\{0\}],\qquad
R_N=\sum_qw_q\mathbf1[\widehat Z_q=N,Y_q^*=\{1\}],
$$

$$
C=\sum_qw_q\mathbf1[\widehat Z_q\in\{O,N\}],\qquad
A_{correct}=\sum_qw_q\mathbf1[\widehat Z_q=O,Y_q^*=\{1\}\ \lor\ \widehat Z_q=N,Y_q^*=\{0\}].
$$

$R_O$ 与 $R_N$ 是所有固定机会中的错误开放/错误封闭发生率，不能称为按危险或安全样本条件化的错误率。另在确定世界参考子集上，明确报告

$$
F_O=\frac{\sum_qw_q\mathbf1[\widehat Z_q=O,Y_q^*=\{0\}]}{\sum_qw_q\mathbf1[Y_q^*=\{0\}]},\qquad
F_N=\frac{\sum_qw_q\mathbf1[\widehat Z_q=N,Y_q^*=\{1\}]}{\sum_qw_q\mathbf1[Y_q^*=\{1\}]}.
$$

分母为零时记未定义并报告原始计数。A 不计作明确错误封闭，也不计作正确世界分类；另报告总弃权及各原因。输出确定值越少不自动证明越好，必须同时检查 C 与 $A_{correct}$。选择性错误率只在确定断言中计算，C=0 时未定义；风险—覆盖曲线仅在预先设定且校准过的参数点上作补充，不在测试集挑最佳阈值。

主张 H1-E1 要求 C-MX 对 B-L 的 $R_O$ 至少改善预定 $\delta_O>0$，同时 $R_N$、覆盖 C、正确确定输出 $A_{correct}$ 的退化分别不超过 $m_N,m_C,m_A$，且后两者达到预定最低量 $c_{min},a_{min}$。以方法减对照的配对差记 $\Delta$，采用

$$
U(\Delta R_O)<-\delta_O,\quad U(\Delta R_N)\le m_N,\quad
L(\Delta C)\ge-m_C,\quad L(\Delta A_{correct})\ge-m_A,
$$

并检查 C、$A_{correct}$ 最低界，以及错误开放的绝对上限 $r_{O,max}$。这些是净宽/许可诊断约束，不能替代 E5 的实际危险误放行资格。界值、来源、目标人群/场景混合及样本量均需在正式测试前具体锁定。若只比 B-O 有收益而对 B-L 未通过，应如实报告双轴保留的作用，不能宣称完整证据处理优于强对照。

### 5.2 双轴、候选、缺口与故障

| 指标族 | 固定评价方式 |
| --- | --- |
| 分轴状态 | 对 M 的原枚举及用途归约、P 的 MEETS/VIOLATES/UNKNOWN/CONFLICT 分别列矩阵。世界物理标签只用 MEETS/VIOLATES 及未决集合；UNKNOWN/CONFLICT 的处理另与规则参考比较。未输出的分轴字段不推测。 |
| 规则符合 | 与 $C_q^K$ 比较管理解析、证据拒用/保留、覆盖及时效处理、同域物理冲突和候选多标签。管理冲突与物理冲突分别计数。各候选类型按固定机会给出 TP/FP/FN，空正类时召回未定义。 |
| 未决与正确弃权 | 参考可见输入确实不足时，记录是否弃权及原因；世界已明确但方法弃权仍降低确定覆盖，不补记成一次正确分类。报告规则应弃权却确定断言、规则可判断却弃权两类。 |
| 时间与更新 | E1 状态更新延迟从新的合格相关输入或失效事实实际可见起算；另报从真实变化起算的含接入延迟版本。故障变体共享固定截止，错误判断不停止计时。它们不替代 D04 的 S4 首次可信确认或 E4 恢复时钟。 |
| 失败与审计 | 在固定 q 读取本实验声明的状态输出；更新失败但仍暴露旧 O/N 时，主评分按该 O/N 及当前世界参考计算，另记失败与失去支撑。只有该评价边界完全无输出才按 A/执行失败保存，不算正确弃权；故障不移出全机会分母。缺少必要版本/依据属于审计失败。 |

真值为 $\{0,1\}$ 时，在同一固定机会与权重下，对所有允许标签给出 $R_O,R_N,A_{correct}$ 的最佳/最差范围，并受同一事件时空约束限制，不能把互相关联的未知格点随意赋成有利组合。确定子集的 $F_O,F_N$ 单列；如需全体条件率范围，须连同分母共同优化，不把独立算出的分子/分母界直接相除。预注册真值未决上限，未满足时不支持主张。

### 5.3 统计承接

采用总体方案 §6 的独立组配对重抽、统一一类错误预算 0.05、功效目标 0.80 和预先锁定的单侧界家族。主比较上述七项界（改善、三项非劣、两项最低量、一项绝对上限）均进入同一主张清单；E1 与既有 E2/E3 总体主张共同发布时重算总家族 M，不能每个实验重复使用未校正的 0.05。稀有/全零错误不能只依赖普通组自助零宽区间。

预实验检验各端点区间的覆盖与退化情形，封存前固定使用方法。保底方法采用独立组有界均值的 Hoeffding 单侧界：组内端点均值 $V_g\in[0,1]$ 时半径为 $\sqrt{\log(1/\alpha_j)/(2G)}$，配对组差 $D_g\in[-1,1]$ 时半径为 $\sqrt{2\log(1/\alpha_j)/G}$；上下界为样本均值加减相应半径并截于合法值域。它们约束声明抽样设计下的组期望均值，不能用于彼此相关的“伪独立组”。真值未决时按允许标签的最坏端点或配对差取界，不将两方法的未知真值分别向有利方向赋值。该保底法可能需要较多独立组，应在预实验据此估算可行样本规模；若无法得到合格区间或数量不足，结论为证据不足，不用零宽 Bootstrap 代替。公式依据见 [Hoeffding 原文](https://www.cs.rpi.edu/academics/courses/spring06/random/hoefding.pdf)，分层改权时需重新推导或使用各层分配后的保守界，不能原样沿用等权公式。

补充按固定危险挑战清单统计“本组任一次错误 O”的二元指标，只有预定目标分布下独立同分布的组才使用单侧精确二项上界；真实错误世界标签未决时给出组级可能取值及最坏上界。该组级指标与逐机会 $R_O$ 的绝对界分别报告，不能相互替代。样本量由预实验方差、配对关联、退化/最低覆盖界和各稀有错误层共同决定。精确二项界依据见 [NIST](https://www.itl.nist.gov/div898/software/dataplot/refman2/auxillar/exacbino.htm)，组重抽方法背景见 [Deen 与 de Rooij](https://link.springer.com/article/10.3758/s13428-019-01252-y)；本研究的具体端点、权重及门槛按上述协议冻结并核查适用性。
