# 受控直通道研究资料规格

本规格用于领取和审阅首个场景的资料。研究对象是一条受控直通道、一个净宽义务修订和一个选定的机器人配置。E2 检验应重评的空间属性和功能，E3 检验完整采证路线。E1、E4、E5 分别检查双源状态、恢复和任务使用。记录以独立监测组为单位，可以用台账、测量原件及其索引交付。下述数值例为合成材料，实际场地、来源资格、误差界及独立组数均待取得。

## 一组资料怎样交付

每组给出稳定组号、场景与采集作业号、数据层（合成／回放／实测）、记录类型、原件编号或受控位置、修订及文件摘要（有文件时用 SHA-256）、产生者角色、有效范围、单位和时间基准。原件更正保留前后修订、原因、发布及可见时刻。派生裁剪、坐标重表达、重复帧与重复投递标回同一原件。公开目录仅保存设计和可公开样例，现场记录按其授权位置引用。

| 材料及提供者 | 必填内容 | 收件时怎样核对 |
| --- | --- | --- |
| 监测计划与授权 · 场地管理方／计划制定者 | 起止、周期、相位、允许站位和动作、安全结束、预设预算、管理指令的生效／替代／可见时刻、适用范围 | 计划先于隐藏事件，事前可用的既有权限足以到达独立安全观察位。预留无初始线索、晚线索、有线索及无变化时段，记录缺席或不可观察。 |
| 几何与版本 · 地图或测量资料提供方 | 原目标、实体与 Cell、要求修订、坐标系、轴向、m、边界归属、高度带、版本变换及误差来源、生效和可见时刻 | 精确原点变换与原测量配准更正分项，先在原始完整作业上传播误差，再裁剪。记录未映射范围与未知体积。 |
| 方法可见观测 · 采集人员 | 原始作业、采样时刻及误差、系统接收与可读时刻、可见水位、传感链、槽、共享标定及配准、原覆盖、遮挡与质量 | 可在知识切点重建同一到达流。每槽核验完整时空支撑、内外包络及共同误差。允许迟到、丢失、撤销和替换。 |

| 世界参考 · 独立测量与标注人员 | 独立尺量或扫描的范围、标定、尺寸区间、变化／恢复时刻或区间、原因或干预记录，另附授权方的管理事实 | 参考链与方法输入的共享来源逐项登记。先屏蔽方法输出，两人独立判断，保存原标签、分歧、裁决修订与仍未决的集合。参考无法区分阈值两侧时保留范围。 |

| 路线及资源 · 作业／计量人员 | 每段移动、等待、采样、安全结束、预留与实耗、外部供证承诺及到达／失约、取消与已耗、耗能表读数或积分依据 | 确认延迟从独立真实起点计秒，恢复另起时钟。总体按完整监测期计机器人 Wh，共用段只计一次。另记外部作业及其单位，避免把外部成本记为零或与 Wh 混加。 |

## 读取权限与分组

1. **给方法。** 按知识切点只交付当时已可读的观测、许可、地图与策略修订、事前核验安排，以及当时已承诺的外部供证。各方法共用同一到达流、评价机会和资格规则。
2. **给评分。** 屏蔽的世界参考用于判断真实变化、恢复与任务危险，独立规则参考用于判断当时能否作出肯定或否定结论。评分另存各方法在各切点的原始输出与耗费。后来获得的参考可以修订标签，旧输出、原标签和首次错误仍保留。
3. **给校准和封存。** 共享原始作业或可能影响结论的共同误差连成同一组，先分组再派生。地图分裂、参数更正、相邻帧或同一事件的多轮查询均不增加独立组数。登记分集、分配日期、理由、标注盲态与解封时刻。预实验估计配对变异和稀有层频率，再决定效应界、样本量与可支持的主张。

## 按实验验收

| 用途 | 最小独立参考与判读 | 缺项如何记账 |
| --- | --- | --- |
| E1 双源 | 同时有授权管理事实、物理净宽参考和当时输入资格。主对照为分离双轴、只取最近合格测量。 | 阈值跨越、管理依据缺失或来源冲突保留未决，分别统计错误开放、错误封闭与正确确定覆盖。 |
| E2 影响 | 固定目标目录、干预前后依赖依据，由独立复核者标记“需／无需／未决重评”及理由。含无影响目标与缺边挑战。 | 保留未决真值的评分范围，记录错误排除、空输出和候选工作量。 |
| E3 路线 | 相同有限域、完整动作目录、槽位资格、共同验收与预算。以计入完整路段的贪心作主对照。小域由独立枚举给参照。 | 只有下界时报告距下界，派工超时、无确认和安全结束计入成本。多轮停止派工仍可按原生命周期接收合格证据。 |
| E4 恢复 | 独立的恢复／复发时刻、原义务范围、失效可见时刻、S4 验收及 S3 后继投影可读时刻。包括未恢复负例。 | 拆分后的局部支持照实记录。地图更正导致失去证明的时刻与实际阻塞或恢复时刻分别保存。 |
| E5 使用 | 明确配置及任务允许域、独立扫掠和时空支持、许可与风险参考。记录每次正向声明及其条件是否可执行。 | 世界可用但证据不充分仍可按规则待定。危险标签未决时给评分范围，不能据此宣称可放行。 |

## 一条合成资料怎样使用

取组 `SYN-D10-01` 的一个换版挑战。原义务是旧坐标 [0,4] m、指定机器人高度带与验证时窗内净宽至少 1.00 m。记录 B 原作业范围 [−0.01,4.01] m，纵向配准半宽由 0.01 更正为 0.03 m。用旧坐标展示，B 新保证范围为 [0.02,3.98] m，中段净宽下界 1.02 m。A 的完整覆盖仍有效，下界 1.04 m。只将 B 登记为部分支持，原全域义务失去第二份完整见证。

在新切点加入独立全段作业 C，下界 1.06 m。A、C 支持 S4 对原要求给出 PASS。S3 应用该修订后，S7 对 1.03 m 宽的指定机器人另查扫掠、许可、风险及含钟差的 [11.9,14.1] s 占用。受控保持为 [8.1,14.9) s，内部断档须另记并阻止正向用途。拆分的两个 Cell、B 的更正与 C 的到达属于同一世界过程，本例只演示字段、缺项和读法。完整几何、观测及知识切点见 [D10 §4](../design/map-consumption.md)。

## 首个实际场景的交付判据

已对现有项目资料做第一轮来源核对。平台监控和前相机画面可说明观测接入，设备手册可定位标称能力，离线契约包及其 CSV 记录可复查合成输入的结构判定。在已查资料中，尚未找到一组能把同一通道的地图修订、独立全段净宽测量、真实变化时刻、保持控制和管理授权对应起来的原件。目前可复算上面的纸面例，实际监测组的来源资格仍待补齐。

先取得场地允许的研究范围、一个可追溯地图修订、可独立复测的净宽及变化时钟，再核查误差、保持和各来源的共同依赖。用同一材料回建一个“当时可见”的判断和一个屏蔽参考，同时记录最早缺项及受影响的实验。满足相应用途后才纳入该实验的预实验组。完整抽样、风险预算和封存条件见[跨阶段准备清单](readiness.md)，具体计分见[总体协议](protocol.md)、[E1](dual-source-e1.md)、[E4](recovery-e4.md)和[E5](availability-e5.md)。
