# E5 任务条件下的空间可用性实验设计

本轮检验 S7 能否在指定机器人、任务、路径与时窗下作出有依据的五态判断，承接 E1 的双轴状态和 E4 的恢复/重开。首轮限受控通道净宽、许可及已明确的能力/风险条件，使用离线查询和合成/受控参考，不执行真实放行。纸面 AVAILABLE/CONDITIONAL 只是给定夹具下的预期判断；正式读取绑定、真实 RobotProfile、ACL/Consumer 和 S6 执行许可仍各自取证。

主张记为 H3-E5。检验在危险误放行和无依据允许受控的条件下，可验证附加条件是否提高正确可执行允许的覆盖，同时不过度增加误拒。E5 不单独证明总体巡检时延/成本改善，也不把 S7 结论当作 S6 已执行或已停止。

## 1. 固定查询与允许的执行域

### 1.1 查询单元

$$
q=(scope,function,robot,task,path,J_q,k_q,K_q),
$$

$J_q$ 是请求允许的使用时域，$k_q$ 是输入知识切点，$K_q$ 精确绑定 Map/Graph/Transform/Requirement、S3 State/Projection、相关 S4 修订、Policy/Model/Calibration、RobotProfile、TaskRequirement、上下文和读取角色。每个查询只用一个明确的能力配置；配置变化作为预定版本分支，不临时换用更小机器人。

请求必须说明时间是固定日程还是可调整窗口，以及可调整的速度、载荷、姿态等参数域、必须完成的任务和结束条件。几何路径保持原请求绑定；改走另一条路应新建查询，不能把原路径不可用悄悄改成一次成功。

### 1.2 基准执行与条件方案

每个查询预先登记基准方案 $v_0$ 和有限条件方案目录 $V(q)$。一个方案 $v$ 定义允许的执行集合 $\mathcal E(v)$、机器人扫掠几何、各段占用区间 $J_j(v)$、等待/结束时间以及执行约束。所有方案必须仍满足原任务与 $J_q$；固定时窗不允许平移，载荷上限不能通过减少必送载荷来“满足”。

每个方案的证明要覆盖其允许的全部执行范围，不能只证明一个代表速度或采样点。首轮小例可以采用有限执行白名单；更一般的连续速度/时间区间需另有全域界。目录不完整时，不能仅因已列方案全部失败就断言原请求无解；适用于整个请求域的共同硬反证可以独立支持否定。

CONDITIONAL 绑定一个非空、具体且可执行的方案及其约束、范围、时窗和所需能力依据。已验证执行器能施加的限速等约束必须进入决定及 NavigationConstraint 的同一精确关联。只有“注意安全”“再次确认”或未知是否能实施的条件不能支持放行。限制导致占用变长时，重新核验整个时窗及任务期限。

## 2. 两类参考与三个评价边界

### 2.1 独立参考

| 参考 | 形成方式和保留范围 |
| --- | --- |
| 世界任务条件 | 独立核验适用管理指令、净宽及其他声明为必需的物理条件、实际机器人包络/载荷、路径连通与占用时间、执行约束能力。按每个允许方案保存“满足/不满足/未决”，不用 S7 输出作答案。 |
| 风险参考 | 合成层使用封存的联合生成机制或有限概率表，直接计算同一任务/路径/时窗/方案的风险；受控数据使用独立校准的有效范围。一次执行没有事故不等于风险为零。无法确定风险是否达标时保留区间及标签集合。 |
| 当时可知规则 | 仅使用 $k_q$ 前可见记录、有效角色与用途、来源水位、原裁决上下文、证据适用性及必要应用证明，独立推导五态及原因。迟到禁令/撤销不反向注入旧切点。 |
| 请求与方案适配 | 独立检查 $v\in V(q)$、$\mathcal E(v)$ 非空且不改变原任务，核查全执行范围证明及约束可执行性。方案自己报“可行”不构成参考。 |

两位复核者先屏蔽方法输出独立判断，保存分歧、裁决修订及未决集合。世界中可能可用但当前证明不足时，PENDING 可符合规则，却不算一次正确允许或完成的确定判断。标注数据、输入测量和用于校准风险/能力的记录按原始来源及共享误差分组，不能重复承担输入与唯一答案。

### 2.2 协议、业务与执行分别评价

1. **读取/协议。** 沿 FS-01 §12 核验精确 Owner、角色、决定路径、Context 关联、Schema/Hash、知识截止和当前访问权限。COMPLETE 只证明读取合同成立；历史原文可完整返回，但当前用途仍需重评。未登记/未采纳或依赖未齐保留相应缺口，不由实验宣布正式采纳。
2. **S7 业务。** 在有合法业务结果的响应中评价 PROHIBITED、BLOCKED、PENDING、CONDITIONAL、AVAILABLE。读取拒绝或内部失败且无合法业务结果时，不臆造一个五态；记协议/完成失败并保留不允许使用。若响应同时暴露 AVAILABLE/CONDITIONAL 等允许声明，仍计无依据允许/合同违例，不能靠外层错误掩盖正向声明。
3. **S6 执行。** E5 评价查询决定和约束，不宣称命令生效、真实机器人遵守条件或实际消费者已拒用错误响应。真实执行与缓存/Consumer 行为由 E6、MI-0 及运行阶段取得证据。

## 3. 首轮五态判据

### 3.1 任务硬谓词与证明资格

对 $v$ 区分任务硬谓词 $H_j(v)$ 与正向证明资格 $Q(v)$。前者包含管理许可、固定要求/净宽、机器人包络、任务期限、路径连续性、完整占用时段及风险条件；只有适用且合格的正反证才能使对应谓词取 TRUE 或 FALSE，否则为 UNKNOWN。已知证据过期、角色不符、S4 验收缺失或 S3 应用证明未齐，属于证明资格失败或未决，不能因此把现场或任务谓词置为 FALSE。

正向方案合格要求全部必要 $H_j(v)=TRUE$，且 $Q(v)=TRUE$；$Q$ 核验相应证据资格、必要 S4 验收、S3 应用与原裁决读取证明。$Q$ 为 FALSE/UNKNOWN 仅阻止该正向结论。排除方案必须另有自身权限、来源、时态及作用域均合格的语义硬反证，不能用正向证明失败代替。证明之间存在尚未裁决的实质冲突时，按既有冲突规则保留未决，不挑有利一侧。协议不能合法返回业务结果时仍按 §2.2 处理，不强行转换为五态。

全段功能净宽达标不保证特定机器人能沿原路径通过。直通道的简化宽度检查采用要求净宽与含余量机器人包络的较大值，还须验证该净空带与原路径扫掠范围连续相容；逐断面“各有一条宽带”不能替代连通性。其他必需属性如净高/地面条件只能在夹具中明确给定并取证，缺少时不默认 TRUE。

必要依据对方案的每段占用集合都必须有效，包括时钟不确定性、等待和退出段。核验完整区间包含关系与内部缺口，不仅检查开始时点；统一依据可用区间为交集时，需包含完整占用时窗。半开有效截止端不属于有效域。不同段可有各自适用依据，但不能把其他段证据挪来补缺口。

首轮将退出/结束操作的时点及其时钟误差范围也纳入必要支持；不能仅把窗口写成半开区间就省去结束操作。其他端点语义须由模板明确冻结，并按同一语义核验全部方法。

首轮的空间和时间支撑采用 [D07](../design/spatiotemporal-support.md)：有限保守几何包络加有独立依据的受控保持区间。未知体积不得当作自由空间；采样时间误差不等于连续观测；物理保持、硬过期及读取资格分别核查。对开放且无法排除未来变化的查询，不用旧测量或管理指令补出保证，仍保留在预先定义的评价范围内。

### 3.2 风险语义与不确定性

所有风险界绑定相同不利事件定义、机器人/载荷、执行方案、路径/时窗、模型与适用域。目标量 $p(v)=\sup_{e\in\mathcal E(v)}P(\text{不利事件}\mid e,q)$ 是方案允许范围内的真实最坏执行风险，不能把某个偏松上界本身当成 $p(v)$。$[L(v),U(v)]$ 是对该目标量的合格界，任务预算为 $\epsilon_q$：

$$
U(v)\le\epsilon_q\Rightarrow RiskOK=TRUE,\qquad
L(v)>\epsilon_q\Rightarrow RiskOK=FALSE.
$$

其余为 UNKNOWN。只有上界超过预算时，不足以证明实际风险超标，更不能证明物理障碍；缺少额外依据时保持待定。有可信下界已超过预算，且该风险约束是当前任务硬条件时，可以证明该方案的整个允许合同不合格，不等于其中每条执行都高风险；这叫任务风险硬门禁失败，不生成“已观测物理阻塞”的事实或事件。只有允许的全部方案均有确定失败依据，才能否定整个请求；另选更窄执行范围须是请求允许且已核验的新方案。

没有适用联合模型时，对同一方案各段合格概率上界可用

$$
U(v)=\min\left(1,\sum_j U_j(v)\right).
$$

不默认段间独立，也不把风险上界相加超预算称作风险的下界。只有证明是同一风险事件的重复引用才能去重；共享设备或同一 Cell 本身不证明事件相同。适用且经校准的联合模型可提供更紧界，禁止看测试效果后切换模型。

风险预算 $\epsilon_q$ 与概率界的置信失败预算 $\alpha_{cert}$ 分开。若根据数据在多方案中选择，风险界须对允许的选择规则有效：采用同时覆盖全部候选的界、预分配候选置信预算，或对已冻结选择策略独立验证。逐候选各有一个 95% 界，不自动使挑选后的方案仍有 95% 保证。模型/参考校准与实验效应检验的失败预算分别列账；联合概率性主张须预先分配总预算，不能把效应检验的 0.05 当作所有输入证明的置信保证。

同时覆盖的概率控制依据见 [NIST Bonferroni 方法](https://www.itl.nist.gov/div898/handbook/prc/section4/prc473.htm)。将候选方案列为预定家族是本协议的应用选择；这种抽样覆盖保证不等于已选方案的条件覆盖率，也不等于任务事故概率，且不证明风险模型本身已经校准。

### 3.3 输出规则与否定证明

先核验请求与当前访问权限；无权读取的事实不能借业务状态泄露。对可返回的业务结果采用以下规则：

| 状态 | 首轮判据 |
| --- | --- |
| PROHIBITED | 有完整、自身依赖已核验的管理证明，表明原请求的全部允许执行都受禁止。仅因部分候选时段有禁令，不能否定查询原本允许的其他合法时段。 |
| BLOCKED | 在没有覆盖全部请求的管理禁止判据时，有自身证明完整的共同语义硬反证覆盖整个允许域；或候选域已证完整，且每个方案均被合格的语义硬反证排除。可为物理、能力/任务或有可信下界的风险硬失败，原因分别保存。全部正向证明失效不构成这种排除。 |
| AVAILABLE | 基准方案 $v_0$ 的全部必要条件和允许证明已通过，无需原请求之外的附加限制。它只适用于精确请求、ReadSet、方案与有效窗口。 |
| CONDITIONAL | 基准方案不能无条件允许，但存在请求允许、全范围已证合格且可执行的非空条件方案，绑定原任务及其约束。不能用该状态跳过关键证据/风险/投影缺口。 |
| PENDING | 尚无已验证可用方案，也没有覆盖整个请求域的有效否定证明，包括关键证明未齐、候选域不完整或风险区间跨预算。 |

AVAILABLE/CONDITIONAL 与整个允许域被否定不能同时成立。实现推导时先查覆盖全域的合法管理禁止，再查基准/条件合格方案，最后以完整候选排除或共同硬反证作 BLOCKED，其余 PENDING。基准方案的单项失败不能提前否定尚有合法条件方案的请求。

缺少与某个否定无关的正向输入，不必抹掉已经具备完整自身证明的否定。例如有效且覆盖全用途的禁令，不依赖未知机器人宽度即可支持 PROHIBITED；但禁令自身的权限、Scope、时态或决定关联未证时，不能如此使用。

## 4. 快照、失效与非干扰

S7 保存精确 ReadSet、ScopedCausalCut、SourceVector、原裁决上下文及其决定关联，核验 S3 投影已应用该查询需要的全部 S4 修订和前因。S4 已重开而 S3 仍引用旧 PASS、较大裸水位但无法证明过滤覆盖、或同 Context ID 对应错误原决定，都不足以支持当前允许。

相关 Map/Graph/Transform、S3、S4、Profile、Task、Policy/Model/Calibration 或上下文变化后，按相交与兼容证明选择失效重建或保留。不能证明不相交时保留待定；已有完整不相交及必要依赖证明的其他区域变更，不强制全域失效。记录新的知识切点，历史决定仍可按原切点回读，不能把历史完整性当作当前许可。

区域 PARTIAL 不能证明原路径可行。路径只查其全部扫掠范围、依赖和占用时段；相邻未使用区域受阻也不自动否定已证不相交的路径。S7 的失效只撤回自己的结论和约束，不代替 S6 STOP 责任。

## 5. 对照与公平条件

| 方法 | 行为及比较职责 |
| --- | --- |
| C-A 完整条件判断 | 按上述证明、有限条件方案、完整占用窗与作用域快照推导五态。合格条件多于一个时按预先固定顺序选择，不宣称条件方案最优。 |
| B-S 充分快照的基准方案判断 | **主要对照**。使用相同当前权限/快照、许可、几何/能力、风险与 D02/S4 规则，验证 $v_0$，不产生附加条件方案。$v_0$ 不合格但查询仍允许尚未核验的条件方案时保持 PENDING，不能冒称全域 BLOCKED。 |
| B-G / B-F 仅几何或固定标记 | 分别只用几何包络，或把既有通行/功能标记直接作为许可。作为补充展示遗漏任务、时窗或权威输入的后果，不替代 B-S。 |
| C-no-condition | 对合格性规则与输入不变，仅不生成条件方案；与 B-S 重合时不当作额外独立方法。 |
| C-start-only / C-latest | 分别只查时窗起点、或以各域 latest 代替精确 ReadSet/应用证明；离线分析错误允许及旧投影。 |
| C-independent-risk / C-soft-override | 分别无依据假定段间独立，或让低代价抵消硬失败；作为反例分析，由共同参考评分。 |

所有方法面对相同固定查询、输入流、请求允许域、方案目录、能力/风险依据和截止。只有声明的机制改变，不额外为某方法采数据或解除禁令。条件方案的完整执行范围、约束能力和时效均由共同独立参考重验，不能让方法自报“可执行”成为评分依据。

主比较检验条件推导带来的正确允许覆盖，非当前架构软件集成收益。对只优于 B-G/B-F 的结果限缩解释。真实 Consumer 是否采纳约束与真实运行风险需额外证据，不由本次离线比较外推。

## 6. 评分、分母与主要主张

### 6.1 允许集合与正确性

输出 AVAILABLE 解释为允许精确基准方案；CONDITIONAL 解释为允许其约束中所有执行，而非仅挑一个安全代表。条件不适配原任务、无可执行解释或允许域为空时，记无依据允许/请求违例，不算正确允许；物理危险若无法确定仍保留最坏允许范围，不能因为条件模糊而把危险率压成零。

| 指标 | 固定定义 |
| --- | --- |
| 危险误放行 | 方法允许的执行域中存在独立参考明确不满足管理、物理、能力/任务或任务风险硬条件的执行。CONDITIONAL 也按其全部允许域核查。另分许可/物理/能力/风险原因，不把未证上界直接当作实际危险。 |
| 无依据允许 | 暴露 AVAILABLE/CONDITIONAL，但必要证据、当前权限/上下文、S4 应用、方案全范围证明或条件可执行性不成立；即使后来世界恰好安全也计规则违例。含不合法协议响应中暴露的正向声明。 |
| 正确允许覆盖 $A_S$ | 在全部固定查询中，合法、非空、适配原请求且被世界和当时证明共同支持的允许比例。无依据条件不能增加此值。 |
| 误拒发生率 $R_R$ | 返回 PROHIBITED/BLOCKED，而独立参考已证明原请求至少有一个合法可用方案，在全部固定查询中的比例。PENDING 不算明确误拒，但会降低确定及正确允许覆盖。 |
| 条件误拒率 $F_R$ | 在独立参考明确存在合法可用方案的查询子集中，上述明确误拒所占比例；与全机会 $R_R$ 分开。 |
| 正确否定率 $s_N$ | 在当时可知参考已具有完整否定证明的固定查询中，正确返回相应 PROHIBITED/BLOCKED 并保留原因的比例。世界危险但证据尚未齐的查询不强迫判为确定否定。 |
| 正确确定覆盖 $A_D$ | 在全部固定查询中正确允许或有完整正确依据的明确否定比例；PENDING、无结果和协议失败均不算正确确定判断。 |
| 待定与失败 | 分开统计证据、时态、风险、版本、角色/关联、候选完整性等缺口与协议/内部失败。未输出不自动记为一次正确 PENDING。更新失败但当前仍暴露旧允许时按旧声明评分。 |

先按预定采集/场景/故障独立组分组，组等权、组内固定查询等权，权重不随输出方案数改变。危险和无依据允许同时报告逐查询发生率 $R_D,R_U$，以及每独立挑战组“任一次错误”的 $p_D,p_U$；同组多帧/新方案/多次重放不增加独立样本数。逐查询发生率仅取固定查询网格，每次机会按当时暴露的输出计一次。组级指标另覆盖预定挑战过程中的每次新暴露允许声明，含两次查询之间已撤回的声明。同组同类错误出现多次仍计 1。每条声明按请求、版本和时窗归入预定挑战组，以暴露时的世界及可知参考判定。组内观察不全时保留可能错误范围。

分母为零时记未定义，不能补成门槛通过。世界、方案域或风险真值未决时，按同一标签、时态与候选约束联合计算允许范围；两方法共享同一参考，不能各取有利赋值。$F_R$ 等条件率范围需连同分母计算。真值未决占比有预定上限，未满足时不支持主张。

### 6.2 七项单侧界

首轮主张要求 C-A 对 B-S 提高正确允许覆盖，同时通过危险、证明、误拒和正确否定资格。令差值为完整方法减对照，预注册

$$
L(\Delta A_S)>\delta_A,\quad U(p_D)\le r_D,\quad
U(\Delta p_D)\le m_D,\quad U(p_U)\le r_U,
$$

$$
U(\Delta R_R)\le m_R,\quad L(s_N)\ge s_{N,min},\quad
L(A_D)\ge a_{D,min}.
$$

$\delta_A>0$ 为实际改善量，$m_D,m_R\ge0$ 为允许退化，其他为错误上限和最低有效判断要求。始终 PENDING 或只输出模糊条件不能通过。七项界进入整体主张家族；联合 E1—E5 的研究声明时计入完整清单，不每轮另花一个未校正的 0.05。

效应分析沿用[总体方案 §6](protocol.md)与 [E1 §5.3](dual-source-e1.md)的独立组配对统计、功效目标 0.80、预先锁定区间及有界均值保底。稀有/全零组级错误按有效抽样假设求精确上界，配对风险差用适用的保守界交叉核验；零宽 Bootstrap 不证明零风险。统计家族、模型/参考置信预算和候选选择保证分开登记，若给出联合置信主张须事先分配总预算。实际数值、风险依据、目标场景混合和独立组规模在封存前锁定。

## 7. 二十三项纸面复核

以下均为合成推演；未列缺口的必要条件已在夹具中明确通过，不代表现实系统已取得这些证据。宽度以米、时间以分钟计，风险为同一任务事件概率。

| 编号 | 场景 | 预期与评分 |
| --- | --- | --- |
| E5-01 基准全部通过 | 原路径与完整占用窗内许可、净宽、能力、风险、S4 及应用证明均通过。 | AVAILABLE，绑定精确 $v_0$、ReadSet 与有效窗口。 |
| E5-02 禁令与畅通 | 全部允许方案都经过有效禁区，净宽达标。 | PROHIBITED；低风险、物理畅通和 S4 PASS 不解除禁令。 |
| E5-03 功能通过但机器人过宽 | 净宽要求 1.00 已 PASS，实际净空上界 1.08，机器人含余量需 1.10，所有允许方案都需该断面。 | BLOCKED，能力/几何硬失败；不能从机器人无关 PASS 推出可通行。 |
| E5-04 能力未证 | 净宽合格，但当前 Profile 的包络或标定不明。 | PENDING，不把未知能力当作不适合，也不默认可用。 |
| E5-05 重开未应用 | S4 相关义务已重开，S3 仍引用旧 PASS 或只有较大裸序号。 | PENDING；必须核验相关变更应用及前因，不能输出 AVAILABLE。 |
| E5-06 无关变化 | 新变更与路径、时间及所有必要依赖均有完整不相交/兼容证明，原依据仍有效。 | 可保留 AVAILABLE；不能仅因全局水位变化就全域待定。 |
| E5-07 覆盖末端不足 | 必要证据支持 [10,18)，占用 [14,20)。 | PENDING，不能只核验 14 时有效；若另有可靠禁止/硬反证则按自身判据否定。 |
| E5-08 时钟不确定 | 证据截止 20，实际退出时间可能在 [19.9,20.1]。 | 缺少覆盖全部可能占用的依据，PENDING；不选有利的 19.9。 |
| E5-09 有效限速条件 | 请求允许限速，方案约束和全部执行范围可验证，降低速度后的占用仍在请求窗内，执行能力可强制该限制。 | CONDITIONAL，限制、方案和证明同时绑定；不称无条件 AVAILABLE。 |
| E5-10 条件无法实施 | 仅建议限速，实际约束能力未证，其他条件不足以支持基准方案。 | PENDING；若仍输出 CONDITIONAL，计无依据允许。 |
| E5-11 限速超出期限 | 基准方案已证不合格，所有允许限速方案都会超出固定任务期限，目录完整。 | BLOCKED，任务时间硬失败；不能以“减速即可”绕开截止。 |
| E5-12 改道冒充原请求 | 原路径已证不合格，返回另一条未经请求允许的路径作为条件。 | 原查询不得因此通过；需新查询。正向旧查询响应记请求违例/无依据允许。 |
| E5-13 合法时间限制 | 请求允许在 [10,15) 选择执行时段，禁令只覆盖 [10,12)，已验证的 13 时方案满足全部条件。 | 可 CONDITIONAL 绑定允许时段，不撤销 [10,12) 禁令。固定 10 时任务不能如此平移。 |
| E5-14 上界不足与更紧模型 | 两段风险上界 0.04/0.05，预算 0.08，只有这些上界；另一个独立分支有已冻结适用联合模型上界 0.06。 | 仅并集界 0.09 时 PENDING，不称物理 BLOCKED；联合界 0.06 且其他项通过时可 AVAILABLE。 |
| E5-15 已证风险硬失败 | 所有允许方案有同语义可信风险下界 0.09，预算 0.08。 | BLOCKED，原因是任务风险硬约束被否定，不生成物理阻塞事实。 |
| E5-16 无依据独立假设 | 方法仅有边际上界 0.04/0.05，预算 0.089。独立世界参考表明两事件互斥、总风险 0.09。 | 不能以 $1-0.96\times0.95=0.088$ 放行；无联合依据时并集界 0.09 只支持待定，错误放行同时记危险与证明违例。 |
| E5-17 区域 PARTIAL | 区域多数单元通过，原路径穿过确证瓶颈；另一预定查询只经过已恢复且依赖不相交的西段。 | 前者 BLOCKED，不能按面积放行；后者可按自己的完整依据 AVAILABLE。 |
| E5-18 历史读取完整 | 原 Owner 返回 COMPLETE 且 Hash/关联正确。目录完整且含两个方案，两者仅有的历史净宽依据均已过期，无当前硬反证；独立世界参考证实至少一个方案满足全部任务条件。 | 可合法返回的当前业务结果为 PENDING。不能把两个证明都失效推成全部方案受阻；返回 BLOCKED 在本例构成误拒。旧决定仍可按旧切点解释。 |
| E5-19 角色或关联不符 | 原决定错 Context/父路径、无当前权限或 Hash 不符。 | 按既有读取合同拒绝/报告缺口，不制造可用业务结果；暴露正向声明另记无依据允许，不能据此声称实际 Consumer 已放行。 |
| E5-20 全部待定 | 方法对所有固定查询均返回 PENDING。 | 危险可能为零，但 $A_S=A_D=s_N=0$（相应参考分母非空），主要门槛失败。 |
| E5-21 固定分母与未知 | 单组 10 个查询：4 个明确可行，输出允许/误拒/待定=2/1/1；4 个世界及当时可知参考均明确不可行，输出错误允许/正确否定/待定=1/2/1；2 个未知，输出无依据 CONDITIONAL/待定=1/1。错误允许已违反合格反证，其他允许均有证明。 | 原始允许 4/10；$A_S=2/10$、$A_D=4/10$、$R_R=1/10,F_R=1/4,s_N=2/4$；$R_U=2/10$、$R_D\in[1/10,2/10]$。同组任一次错误指标为 1，不把 1/10 当独立组危险率。 |
| E5-22 多方案挑选 | 根据同一数据从多个候选中选择最小风险界，每个界仅逐点覆盖，未有选择有效性保证。 | 不能直接沿用单候选置信承诺放行；保留风险证明缺口。经同时界或独立策略验证后再评，不事后补保证。 |
| E5-23 失败后暴露旧允许 | 更新失败时，当前输出仍提供已过期或错版本的旧 AVAILABLE。 | 例设 0 和 2 分钟的固定读取均为 PENDING。仅在第 1 分钟暴露过期允许且独立参考证实其危险，随后已撤回。两次逐查询的危险及无依据允许计数均为 0，该组两类任一次错误指标均为 1。 |
