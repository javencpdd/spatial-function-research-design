# MSRP 纸面案例

以下案例用于手算核对 [D03 完整路线模型](../design/msrp-model.md)。除特别说明，规划针对同一义务修订和能力配置，未列出的硬约束与产证资格均通过。每槽需要一份见证，计入的来源已证独立，产证覆盖按冻结目标核查。净宽模板的实际内容验收见 [D02](../design/corridor-evidence.md)。规划 FEASIBLE 表示存在符合采证要求的路线，实际测量随后交 S4 评价。时间、能耗均为示例值，候选完整性按每例声明。

| 案例 | 输入 | 推导与预期 |
| --- | --- | --- |
| 1 | `2-of-3`。第三槽不可达，前两槽各有一份已证独立见证。 | 已证满足两个不同槽，`FEASIBLE`。 |
| 2 | `2-of-3`。声明域及产证上界完整，每条完整路线都只能覆盖一槽，或只能用同一受限来源组覆盖两槽。 | 每条路线的乐观上界最多满足一槽，`INFEASIBLE`。 |
| 3 | `2-of-3`。已有一槽满足，第二槽来源独立性未证。 | 已证下界为 1，可能上界至少为 2，`UNKNOWN`。 |
| 4 | 一个义务中的两组均为必需。候选全集只有两条完整路线，每条只满足一组，所声明截止内不允许完成两条的串联。 | 不存在同时满足两组的候选，`INFEASIBLE`。若要允许串联，须扩展候选域并重新核验。 |
| 5 | 已有合格独立证据在预计验收时满足 `2-of-3`，起点已是允许终点，其余要求通过。 | 零动作候选 `FEASIBLE`，成本为零，由 S4 对实际证据裁决。 |
| 6 | 声明域完整且只有两条路线，均已证可行，完整时长为 8 和 10。 | 首选时长 8，并可在该域内证明时间最优。若时长相同再比能耗，最后按稳定 ID。 |
| 7 | 候选清单未证明完整，现有路线均未证可行。 | 缺少排除其余候选的依据，`UNKNOWN`。 |
| 8 | 来源 A 可满足槽 1 或 2，独立来源 B 仅可满足槽 2，要求 `2-of-3`。 | 分配 A 到槽 1、B 到槽 2。见证数为 2，硬约束通过时 `FEASIBLE`。 |
| 9 等待和采样 | 唯一完整候选包含移动 2、等待 3、采样 4、结束路段 2，时间预算 10。目录完整。 | $T=11>10$，`INFEASIBLE`。只加移动时间会得到错误结论。 |
| 10 结束路段不可达 | 从起点能到采样点并取得两槽。允许终点是起点，而所有可能返回方式均已证明不可行，目录完整。 | 缺少完整的结束路线，声明域 `INFEASIBLE`。若返回资格尚未知，结果为 `UNKNOWN`。 |
| 11 验收时过期 | 只有一条路线，时间终点为 5，预计传输和验收延迟为 2。计划使用的已有见证有效截止为 6，且无替代见证。 | 验收时点为 7，见证无法填槽，`INFEASIBLE`。只检查出发时有效会误判。 |
| 12 可行且最优未证 | 完整域含 P 和 Q。P 已证可行，时长 10。Q 时长 8，但见证独立性未知，乐观条件仍可能满足。 | 返回 P 为 `FEASIBLE`，最优性待证。不能从确定候选中只有 P 推出 P 最优。 |
| 13 候选有缺口 | 当前仅有 P，已证可行、时长 10，候选生成覆盖未证明。 | `FEASIBLE`，可称当前已证清单中最佳。相对于声明生成域的最优性待证。 |
| 14 跨组争用 | 唯一路线能提供一份见证 e。义务内两组各需一个槽，模板允许 e 填任一槽，但跨组共享额度为 1，无其他可能见证。 | 各组单独最大值均为 1，联合最多满足一组，`INFEASIBLE`。 |
| 15 动作顺序 | 两个采样动作 A、B 均在同一测点，各耗时 2，无旅行时间，时间域 [0,6]。A 需在 [0,2) 完成，B 需在 [4,6) 完成。域允许等待。 | A[0,2)、等待[2,4)、B[4,6) 可行，总时长 6。B→A 无法满足 A 的时窗，同一动作集合不能抹掉顺序。 |
| 16 内容仍未决 | 路线对全域产证资格和独立性已证，实得两个测量区间均为 [0.98,1.04] m，要求 1.00 m。 | 采证规划可 `FEASIBLE`，S4 为 `INCONCLUSIVE / NOT_DETERMINED`，按策略补证。 |
| 17 安全输入未知 | 完整域只有一条路线，槽位可满足，但必要路段的当前安全资格未知。 | 无已证完整可行路线，乐观分支未排除，`UNKNOWN`。 |
| 18 同时间成本顺序 | 全部候选已证可行，成本 (时间,能耗,ID) 为 A=(8,5,A)、B=(8,3,B)、C=(8,3,C)，ID 顺序 A<B<C。 | 选择 B，同时间先比能耗，再按稳定 ID。 |
| 19 不确定成本 | P、Q 均已证可行，时长均为 8。P 能耗为 4，Q 能耗只知位于 [3,5]，二者均在预算内，比较对象为实际能耗。 | P、Q 的实际能耗排序未定，保留最优性待证。若改用上界成本，须声明该比较口径。 |
| 20 离散域边界 | 只有一个动作，网格步长为 1，完成用时 1，动作有效窗为 [0.25,1.75)，其他时点均不可用。 | 网格出发时点没有完整合法动作，网格域内 `INFEASIBLE`。连续域可在 0.25 出发并于 1.25 完成，需新域另算。 |

案例 1—8 保留原预期，并补齐原有简述中的完整候选、终点及验收时点前提。案例 9—20 是 D03 增补。候选完整、资格完整和最优性分别举证。实际观测的覆盖、质量、独立性和安全边界需另行标定与验证。

案例 1—7 摘自[逻辑架构 §6.1](https://app.notion.com/p/41280c1f02208119a944debf8b5ca294)，案例 8 采用 S3→S4→S7 数学复核的 M08 槽位分配例。三值判据参见[系统级架构与研究验证 §E-05](https://app.notion.com/p/41280c1f02208133947fcd37c92e8289)。

## 机械狗复核策略算例

沿用 [D10 通道](../design/map-consumption.md)的几何条件。原义务要求 4 m 通道全段在指定时窗内净宽至少为 1.00 m。旧见证 A 完整覆盖，下界为 1.04 m。地图更正后 B 只覆盖 `[0.02, 3.98]` m，两端各缺 0.02 m。中段记录继续有效。当前需要另一份独立、完整的见证才能支持整段通过。单独拼接 A 和 B 的范围仍只得到一个完整槽。

下面另设一个合成动作目录说明如何派工。O 是基地，也是唯一允许终点。S 是有独立安全依据的侧方观测站。N 是更近的观测站，初始往返通行资格未知。两个站的测量作业 C 均假定已有完整可见性、标定、保持和与 A 独立的依据。规划时尚无 C 的读数。每次比较固定起点 O、时间 0 到 5 格、能耗上限 1.0 Wh，验收延迟取零。资料覆盖原业务时窗且在本例验收时有效。没有预定外部供给或与本例相交的周期预留，本次最多派一条路线。

| 目录中的动作 | 用时（格） | 能耗（Wh） | 约束 |
| --- | ---: | ---: | --- |
| O 到 S，或 S 回 O | 2 | 0.4 | 两个方向按侧路核验 |
| O 到 N，或 N 回 O | 1 | 0.2 | 两个方向均须具备独立通行依据 |
| 在 S 或 N 执行测量作业 C | 1 | 0.2 | 在所在站观测整段。本例每条路线至多采集一次 C |
| 在所在点等待 | 1 | 0.1 | O、S、N 均可等待 |

以上是全部动作。在任意格回到 O 均可结束，包括 0 格直接结束。按动作展开并保留时长、能耗均在预算内的完整序列，共 54 条，其中 18 条含一次 C。下表各行只改变往返安全资格。待核实的路线保留在可能集合，派工只从确定集合选择。

| S 往返 | N 往返 | 确定 / 可能的完整采证路线数（后者包含前者） | 系统决定 |
| --- | --- | ---: | --- |
| 已证 | 未知 | 1 / 18 | `FEASIBLE`。派 S，5 格、1.0 Wh。N 有 3 格的可能方案，整个声明域的最短时长仍待证。 |
| 已证 | 已证 | 18 / 18 | `FEASIBLE`。派 N，3 格、0.6 Wh。两段往返和一次采样给出 3 格下界，所选序列达到该下界。 |
| 已证 | 已否定 | 1 / 1 | `FEASIBLE`。派 S，5 格、1.0 Wh，域内最优。 |
| 已否定 | 未知 | 0 / 17 | `UNKNOWN`。保留 N 的通行依据缺口，当前无外部承诺，停止新增派工。 |
| 已否定 | 已否定 | 0 / 0 | `INFEASIBLE`。完整目录内无法取得第二槽，通道实际净宽仍待验收。 |

首行受理的任务可逐步回放。

| 格点 | 执行动作或回传 | 对当前义务的影响 |
| --- | --- | --- |
| 0 | 为完整路线预留 5 格、1.0 Wh。S4 受理计划，S6 校验能力、控制授权和往返安全条件。 | 绑定原义务、当前地图、槽 A 与待补作业 C，在受理时扣一次派发机会。 |
| 0–2 | `NAVIGATE_TO` 沿获准侧路从 O 到 S。 | 只确认到站，目标通道仍待复核。 |
| 2–3 | `OBSERVE_REGION` 在 S 按作业 C 的配置测量 4 m 原域。 | 记录实际观测范围、采集时间、原始数据与标定来源，供 S3/S4 核验。 |
| 3–5 | `RETURN_TO_SAFE_POINT` 从 S 回 O。例中读数及结束记录在格点 5 可读。 | 记录实际结束与消耗，按收到的内容验收。 |

- 若 C 的合格区间为 `[1.06, 1.12]` m，A 和 C 各自支持全域下界达标，且无冲突，S4 给出 `PASS`。S7 另查具体任务的授权、扫掠范围和时窗。
- 若 C 的合格区间为 `[0.98, 1.08]` m，区间与 A 相容，却跨过阈值。仍只有一个完整通过槽。S4 保留未决，本例机会及时间已用完，停止追加采证。若新事实在后续切点到达，按原过程关联重评。
- 若独立、完整且达标的 C 在派工前已可读，则 S4 直接验收，机械狗在 O 待命，派工次数为零。若执行中侧路资格失效，则由 S6 依据当时条件安全处置，记录中止或位置未确认；未取得可核验结束前不派第二条路线。

图上点位、动作耗时、能耗和模拟读数均为合成输入。该例可检查策略从选路到停止的行为，实测覆盖、资源成本与相对全量复测的收益需分别验证。
